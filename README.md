# 人工智能 · 系统学习

一套**为设计 / 产品背景学习者裁剪**的中文 AI 课程库。46 章讲义、9 个动手实验、7 个项目、32 份题库，
外加一个按症状查的排障台。**全部是离线可看的单文件 HTML**，下载下来双击就能读，不需要装任何东西、不需要联网。

> 做法不是重写全网已有的好教程，而是**把该读的挑好、排好序、和一张清晰的骨架图对应上**。
> 目标是打透不会变的底层逻辑——底子扎实了，再新的模型出来也看得懂。

---

## 从哪开始

克隆或下载之后，**双击 `index.html`**。就这一步。

```bash
git clone https://github.com/yunmin311/ai-systematic-notes.git
```

想跑实验里的代码，两种办法：页面里点「▶ 运行」（浏览器内的真实 Python，需要联网下载运行时），
或者用本机 Python 跑 `实验室/code/` 下的同名脚本。

## 三个可能和别处不一样的地方

**一、外链策展，不重写教程。**
每一章都挂着外部资源卡，四栏写清：*是什么 / 为什么选它 / **精确看哪段** / 对应本章*。
讲义负责搭骨架和串联，血肉交给全网已有的好材料——这样过时的只是链接，不是正文。

**二、实验里的「应该看到」全是真跑出来的。**
9 个实验、17 个运行器的预期输出，都是在无头浏览器里真跑一遍抓回来的，不是编的。
比如 [数据泄露现场](实验室/lab-05-数据泄露现场.html)：纯噪声数据、随机标签，
诚实做分数 0.400，把一步顺序搞错就冲到 0.867。

**三、写法本身也一起开源了。**
[`skill/`](skill/) 放着写这套笔记实际用的两个 skill：`learning-notes-html`（单文件离线 HTML 怎么写、
设计系统、外链策展法、交付前自检）和 `course-authoring`（讲义与题目的内容标准）。
想用同一套方法写自己的笔记，拷进 `~/.claude/skills/` 就能用。

**四、题库有校验脚本挡着。**
出题很容易出现「不读题也能蒙对」的系统性偏差。这套题曾经就是——正确答案 86% 压在 B、
93% 是最长的那个选项，闭眼蒙能得 188/222 分。现在有脚本卡着：

```
node _工具/题库自检.mjs
→ 答案位置 A/B/C/D = 25.3 / 25.3 / 24.7 / 24.7 %
  正确项均长 / 错误项均长 = 1.00×
  蒙题策略得 70/222，随机基准 70.5 → 过
```

`_工具/` 下还有另外三个：全站体检（死链与锚点）、口吻自检（不许对读者说话、不许发号施令）、
题目对正文（题目考的知识点在不在本章范围内）。

## 已知的坑

- **D14 第 12 节**写「代码跑出来应该正好是 `[6.65, 3.45]`」，实测是 `[6.6008, 3.3992]`。
  第 9 节的手算没错（权重取两位小数），错的是「代码跑出来正好是」这句。
  [lab-07](实验室/lab-07-手算注意力.html) 里把这个差别讲清楚了。
- **第 1 章第 23 节**的资料表里，PyTorch 教程标着「D03 章」、Hugging Face 标着「阶段二 D04 起」，
  按现在的编号应为 D07 和 D12 起。
- 46 章共用同一副章节骨架，这把不同性质的知识压平了（手感类、推导类、跑通类长得一样）。
  新的「AI 使用」板块已经不套这副骨架。
