AI Course 从零到 AI 应用开发 为设计背景定制

人工智能 · 系统学习

一套为设计 / 产品背景学习者定制的 AI 课程库。做法是领读 + 索引 + 外链策展:不重写全网已有的好教程,而是把该读的挑好、排好序、和一张清晰的骨架图对应上。目标是打透不会变的底层逻辑——底子扎实了,再新的模型出来也看得懂。

课程构成

五个阶段,共 46 章讲义 + 7 个项目 + 32 份题库。基础课程 8 章是一条线:数据 → 学习 → 模型;深度课程 17 章把每个机制拆到底;应用工程 7 章讲怎么造东西;项目 7 个出产出;AI 使用 7 章讲怎么指挥 AI 干活。

每章的结构相同:图解骨架 → 章内外链策展(配一套外部主线)→ 自查清单 → 对应题库。四条线互不阻塞。

Stage 1 / 基础课程建立全景与地基

读完后,AI 领域的常见名词能放进同一张地图;本机能跑通 Python、NumPy、Pandas。每章约 1~2 小时阅读 + 1 小时动手。

  • 01人工智能全景与学习环境✓ 可学AI / 机器学习 / 深度学习 / 生成式 AI 的关系;装好并验证学习环境
  • 02Python 基础:为 AI 准备的最小集✓ 可学变量、列表与字典、循环、函数、读报错;外链策展该读哪几篇
  • 03NumPy:数组与形状✓ 可学数组、形状、索引、向量化、广播——一切张量操作的地基
  • 04Pandas:表格数据处理✓ 可学Series/DataFrame、读写、选取、清洗、分组统计
  • 05机器学习核心概念✓ 可学监督/无监督、三大任务、训练/验证/测试、过拟合、评价指标
  • 06训练的本质✓ 可学损失函数、梯度下降、学习率、训练循环——模型怎么一步步学出来
  • 07神经网络入门✓ 可学神经元、层与网络、前向、激活、反向传播——现代 AI 的地基
  • 08大语言模型鸟瞰✓ 可学Token、Embedding、注意力、Transformer、预测下一词
Stage 2 / 深度课程把每个机制拆到底

基础是骨架,深度填血肉。分三条线:先补齐经典机器学习,再进深度学习,最后钻进大模型内部。每章「问题 → 直觉图 → 手算/手写 → 库写法 → 对照」。

A · 经典机器学习
  • D01线性回归全拆解✓ 可学模型-损失-训练三件套最干净的示范;手算 → 手写梯度下降 → scikit-learn 一行
  • D02逻辑回归与分类边界✓ 可学线性回归 + sigmoid + 交叉熵 = 分类;决策边界、softmax(LLM 预测下一词的最后一步)
  • D03决策树、随机森林与梯度提升✓ 可学树怎么分裂、为什么过拟合;森林(投票)vs 提升(接力);表格数据之王 XGBoost/LightGBM
  • D04聚类与降维✓ 可学无监督学习:K-Means/层次聚类分堆;PCA/t-SNE 压维可视化——通向 D13 Embedding
  • D05评价指标与验证深挖✓ 可学准确率的陷阱、混淆矩阵、精确率/召回率、ROC/AUC、交叉验证、超参搜索、数据泄露
  • D06特征工程与数据预处理✓ 可学缺失值、one-hot 编码、缩放、特征选择/构造、防泄露流水线——喂模型前的关键功夫(Track A 收官)
B · 深度学习
  • D07PyTorch 与完整训练循环✓ 可学张量、自动求导、Dataset/DataLoader、训练循环五步落到代码——Track B 的底盘
  • D08卷积神经网络 CNN✓ 可学卷积、池化、感受野、参数共享——机器怎么「看」图像;可动手做 P3
  • D09序列模型:RNN 到注意力✓ 可学RNN 带记忆逐个读、两堵墙,以及注意力为何取代它——通向大模型的转折
  • D10优化器、正则化与训练技巧✓ 可学看曲线诊断、Adam、Dropout、BatchNorm、早停、学习率调度——把模型训好
  • D11迁移学习与微调✓ 可学站在预训练模型肩上,冻结/微调、按数据量×相似度选策略——Track B 收官
C · 大模型内部
  • D12Tokenizer 与词表✓ 可学子词切分(BPE)、词表大小取舍、为什么中文更费 token、模型为什么数不清字母
  • D13Embedding 与向量空间✓ 可学含义如何变成位置、余弦相似度、位置编码——RAG 语义检索的底层
  • D14注意力机制逐步手算✓ 可学Q/K/V、四步算术、多头与因果掩码——拿三个词的例子从头算到尾(核心章)
  • D15Transformer 完整结构✓ 可学块的四件套、前馈层、残差归一化、堆成模型;40 行写出 GPT 骨架
  • D16预训练、微调与 RLHF✓ 可学三阶段各在做什么、成本差五六个数量级、LoRA 与「该不该微调」的判据
  • D17推理、量化与部署成本✓ 可学自回归、KV cache、量化、算一笔真实的账——Track C 收官
Stage 3 / 应用工程做出能用的 AI 应用

从「懂原理」到「做出东西」。这一段和「把 AI 用起来、把 agent 治理好」最相关——尤其 A05 直指 AI agent 的底层框架。

  • A01提示词工程与上下文窗口✓ 可学提示词骨架、上下文窗口、few-shot、分步思考、迭代——把任务讲清、让输出稳定
  • A02结构化输出与函数调用✓ 可学让模型稳定吐 JSON、调用工具——把「聊天」升级成「驱动程序」,Agent 的地基
  • A03RAG:检索增强生成✓ 可学向量检索、切块、拼上下文、检索质量——给模型一个随身可更新的资料库,少编
  • A04Agent 基础:工具、记忆、工作流✓ 可学模型-工具-状态循环(ReAct);什么时候该用 Agent、什么时候用固定工作流
  • A05AI Agent 的 harness / 底层框架✓ 可学agent loop、上下文管理、工具调用协议 MCP、多 agent 编排——AI 治理与安全的底层知识(旗舰章)
  • A06评估、幻觉、安全与成本✓ 可学怎么知道应用「变好了」;评测集+模型当裁判、幻觉三道防线、注入防护、成本控制
  • A07工程化与部署✓ 可学后端封装与密钥安全、流式输出、缓存限流、上线与监控四块表——从 demo 到能用的产品(收官)
Stage 4 / 项目从练习到完整应用

每个项目产出一个能给别人看的东西。前几个不需要 GPU 和付费 API,后面进入大模型应用开发。

  • P1数据体检报告✓ 可做六步体检真实脏数据(规模/缺失/类型/分布/异常/关系),导出可交付的 HTML 报告(学完 04 可做)
  • P2第一个预测模型✓ 可做防泄露流水线 → 交叉验证比模型 → 混淆矩阵评估 → 特征重要性解释(学完 D05 可做)
  • P3手写数字识别✓ 可做PyTorch + CNN 训到 99%,看训练曲线与错例;CPU 十分钟可跑(学完 D08 可做)
  • P4命令行 AI 助手✓ 可做调用 LLM API、多轮对话、流式输出、错误处理——一百行做出终端版助手(学完 A02 可做)
  • P5个人知识库问答✓ 可做把自己的笔记做成 RAG 问答——从零手写切块/向量/检索/带出处生成(学完 A03 可做)
  • P6一个小 Agent✓ 可做工具调用 + ReAct 循环 + max_steps 兜底,手写一个会自己调工具的 agent(学完 A05 可做)
  • P7完整 AI 应用✓ 可做前端 + 后端(密钥/限流/缓存/日志)+ 引擎 + 部署监控,把 P4–P6 拼成能上线的产品(收官)
Stage 5 / AI 使用指挥一群 AI 干活,这件事本身的学问

前四个阶段讲 AI 是什么、怎么造。这个阶段讲第三件事:面对一个跑几十步、带工具、有记忆、还会自作主张的 agent,要它干几小时的活。每章前半讲机制、后半讲技巧;出了事现查去排障台。

  • U01它到底在干什么✓ 可读六个怪现象一个根因:说「已完成」文件没动、自贬漏报、编造、默认脸、MVP 倾向、前提错还往下做
  • U02上下文经济学✓ 可读越聊越笨与烧钱是同一件事;缓存前缀失效、中段衰减;压缩 / 开新对话 / 落成文件怎么选
  • U03指令为什么不生效✓ 可读复述得出 ≠ 照着做;三层失效与规则的五级强度阶梯;把规则改造成机械机制
  • U04派活与成本✓ 可读一份活的三个属性;子 agent 真正的用途;「小改」变大工程的机制与裁范围的做法
  • U05让它照着参考做✓ 可读映射表 → 核心样本先行 → 每轮回归对照;把「像不像」变成能被判定的事
  • U06多对话协作✓ 可读按可写面判不按身份判;编号池也是一个面;交接失真三形态与转发块三条硬规矩
  • U07验收 AI 的产出✓ 可读四级证据、假绿灯三来源、形式全绿 ≠ 内容正确、待验单;附一张可直接用的自查清单

Machine / 环境自检在任何一台电脑上核对(换机也不用改这张表)

工具跑这条命令看看期望 / 说明
Python 3.10py -3.10 --version打印 Python 3.10.x 即可——本课程统一用它建虚拟环境,AI 库兼容性最好(最关键的一条)

Gitgit --version能打印版本 = 已装;到项目阶段才用
