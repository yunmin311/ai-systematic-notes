# 定制窗口 · 换皮而不动骨(配色 / UI / 动效)

这套系统的**结构**(6 级字号、一条左边线、框只有 3 类、图的分工)是打磨很多轮的定盘星,**不要随便动**。
但**皮**(具体颜色、圆角、间距、动效)是可以随需要换的——这一层就是"定制窗口"。原则一句话:

> **换皮不动骨:改 token 和动效层,别改结构和纪律。** 重定颜色后,那三条不变量必须仍成立——正文字号仍 = 7 种、整页仍只有一个强调色、正文左边缘仍在一条线上。

## 一、配色:唯一入口是 `:root` 的 token

`template.html` 顶部 `:root{}` 就是配色的总开关。**换一套个性化配色,只改这几个变量,别去正文里改颜色。**

- `--acc` —— 唯一强调色。换品牌色只改这一个(连带 `--acc-soft` 跟着调透明度即可)。
- `--bg / --surface` —— 页面底 / 卡片底。
- `--ink / --ink-soft / --ink-faint` —— 墨色三级灰(正文 / 次要 / 更淡)。
- `--rule` —— 分隔线 / 描边。
- 行内代码底色(正文里那条 `background:#dbe2ef`)—— 换底色时记得让它和新 `--bg` 拉开、但仍浅。

**换色纪律(照做才不塌)**:①仍然只有一个强调色,别趁机加第二个彩色。②三级灰要拉够对比(ink 深、faint 淡),否则层级糊掉。③深色主题也从这里做——把 `--bg/--surface` 调暗、`--ink` 系调亮即可,结构一行不用改。

示例(暖褐替换群青蓝,其余不动):
```
--acc:#9a5b2e; --acc-soft:rgba(154,91,46,.07);
```

## 二、UI 微调:能动的旋钮

这些可安全调,不破系统:
- 圆角:卡片/代码块/图的 `border-radius`(现 4–6px)。
- 呼吸:`--gap-block`(块外距)、`--pad-block`(块内距)、读栏宽 `--measure`。
- 字体:`--sans / --mono` 换字体栈(保持"正文无衬线 + 等宽"两套的对比;中文别挂 CDN,给系统回落)。

**别动的**:字号阶梯的 7 个值(动了就破"字号只有 6 级")、说明块的悬挂竖线做法(`margin-left:-18/padding-left:15`,动了就破"一条左边线")、"框只有 3 类"。

## 三、动效:一个专门的图层,想加就往这加

现有动效很克制:章首和骨架清单淡入(`@keyframes fi`),加上链接/按钮/目录的 `transition`。要引入更多 motion,**集中加在样式表末尾的动效区**,守两条:

1. **必须尊重 `prefers-reduced-motion`**——所有非必要动效包在 `@media (prefers-reduced-motion: no-preference){…}` 里(现有淡入已经这么做),让晕动症用户和低性能设备自动关掉。
2. **动效服务于"读"**——只做帮助理解/引导视线的:小节滚动进入时轻微上浮淡入、图在进入视口时描边/连线渐显、`.handoff` 过渡句轻推、当前目录项平滑高亮。**别做**跳动、闪烁、长时间、抢注意力的花活(违背极简总纲)。

可选的落地方式(按需选):
- 纯 CSS:给 `article > h2 / figure` 加 `@keyframes` + `animation`,或用 `@media(prefers-reduced-motion)` 包住的 `transition`。
- 进入视口触发:复用模板里已有的 `IntersectionObserver`(现在只用来高亮目录),再加一个 observer 给元素挂 `.in` 类、CSS 里 `.in{…}` 播放一次。
- 若将来要更强的编排(时间线、序列),可引入一个轻量库,但**必须内联进单文件、离线可用**(和 Shiki/Mermaid 一样构建期处理),不挂 CDN。

## 四、把定制固化下来

调好一套新皮后,别只改一个文件——把新的 `:root` token 和动效区**同步回 `assets/template.html`**,这样以后新章节直接带上。若要长期维护多套皮(如亮/暗、不同学科不同强调色),可以在 template 里留几组注释掉的 `:root` 备选,用时切换。
