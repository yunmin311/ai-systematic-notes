# 内容方法 · 外链策展法

这套方法写的是「为自己裁剪的学习笔记」,不是「从头讲一遍」的讲义。核心信念:

> **缺的从来不是教程,缺的是「替你从全网挑好该读的、排好序、标清读哪一段」的领读人。**

所以每篇笔记的角色是 **领读 + 索引 + 外链策展 + 收口**,不复述知识。能外包给全网高手的(讲解)就外包;不能外包的(心智地图 + 收口 + 练习题)才是这篇的价值。

---

## 一、骨面分工

- **MD 为骨**——唯一真相源。纯文本、可 git、十年不腐。内容先在 MD 里活。
- **HTML 为面**——复习看板 / 成品。**从 MD 长出来,单向流**:改内容只改 MD,HTML 是导出或对照物。**绝不两头维护同一段字**。
- (若只交 HTML 也行,但心里要清楚哪份是真相源,别让两份漂移。)

## 二、每篇固定六段(缺一不可)

1. **定位**——这篇解决哪个真问题、学完能干哪三件事、**明确不学什么**(把用不到的列进「以后」栏,给读者卸包袱)。3–5 句。
2. **心智地图**——一张图 + 一张「地基清单」讲清它和上下游的关系。**这是外链替代不了的,必须亲手写。**
3. **外链策展(主体)**——精选 2–5 条一流外部资源,见第三节硬规则。
4. **收口**——读完外链后,用自己的话把这篇焊成几条结论 + 一张「常见误区 · 实际情况」表。**唯一不可外包的部分。**
5. **练习题**——**出题走 `course-authoring` skill 的标准**(它是出题标准的正本):题型混合;干扰项是真实常见误解(禁一眼假);答案位置打散;解析要拆穿干扰项。本方法只管把答案放折叠区(HTML 用 `<details>`),不另写一套出题标准。
6. **实例**——一个照着做能跑起来的真东西,把本篇所有地基在一个真任务里串起来;给代码 + 预期输出 + 一个「改改看」小挑战。

## 三、外链策展三件套(命根)

选进来的每一条外链,**必带三样,少一样不许收**:

1. **为什么选它**——它凭什么进名单;必要时说清「为什么没选那篇更火的」。
2. **只读哪一部分**——精确到章节;**明确叫读者跳过哪些**,和「读哪段」同等重要。绝不甩整站。
3. **读完要能回答的一个问题**——用来自检真读进去了没有。

补充硬规则:
- **数量克制**:3 篇精挑 > 30 条罗列。策展的价值是排序 + 批注 + 筛掉次品,不是数量。
- **标明取用关系**:哪几条是「三选一的主线」、哪条是「桥」(以后再读)、哪条是「字典」(随时查),写清楚。
- **防链接腐烂**:每条存「标题 + 出处/作者 + 核实日期」。篇尾注明「所选外链均于 YYYY-MM-DD 核实在线」。
- **必须真核实**:写进去前用工具确认链接是活的、定位到的章节确实存在。不许凭记忆写 URL。

## 四、两种读法,一套文件

同一份内容伺候两种状态,不做两套。篇首放读法提示:

> 第一次学:从「一」顺着读到「六」。
> 复习:只看「二 心智地图」+「四 收口」+「五 练习题」。

## 五、声音与配图

- **书体,不用第一/第二人称**。像写书,不像对话:说「这一章的目标是……」,不说「你将学会……」。练习题直接抛问题,不用「你来做」。
- **零连续比喻;术语首现给白话**(标准名 + 一句人话)。
- **配图宁多勿少**:每篇至少一张心智地图。图少是历史教训,别再犯。

## 六、新增一篇的清单

1. 写内容(六段齐全,外链三件套齐全,先核实链接)。
2. 出 HTML(套 design-system + template,加可视化与折叠交互)。
3. 篇尾登记外链核实日期。
4. 自检:六段不缺;每条外链三件套齐;所有链接可达;心智地图在场;答案能折叠。
5. 更新总索引(MOC):把这篇挂上去,标好和前后篇的顺序关系。

## 七、为什么这么定

- **入门态 ≠ 参考态**:密度过高、默认读者都懂、图少的笔记,是复习手册不是入门带路。用「定位卸包袱 + 双读法 + 心智地图」把入门态补回来。
- **能外包 vs 不能外包**:讲解外包给全网高手(第三段外链);**心智地图 + 收口 + 练习题**是为这个人裁剪的,永远自己写。做好这三样,它就不是书签堆。
- **参照范式**:roadmap.sh(路线 + 节点资源)、teachyourselfcs / OSSU(课程 = 一串精选外部材料)、Obsidian MOC / 常青笔记(索引笔记链接出去取代文件夹)。本方法是它们在「单人、双语言、MD+HTML」场景下的落地。
