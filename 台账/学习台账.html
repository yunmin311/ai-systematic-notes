学习台账

项目里原来的台账记的是「哪一篇写完了」——那是写作进度。这一页记的是另一件事:读过哪几篇、做没做题、错了哪几道、哪个概念回头查过第二次。数据由页面自动采集,不需要手工填表。回查次数是掌握度最诚实的指标:一个概念被翻回去看第三次,说明它还没真正立住。

存储不可用

这个浏览器禁止本地文件使用 localStorage,所以采集不到数据。两条出路:①换 Chrome 或 Edge 打开;②用下面的「导入」把之前导出的 JSON 贴回来查看。

换机器怎么办

数据存在浏览器本地,换机器或换浏览器就不跟着走。导出会下载一个 JSON 文件,把它放进项目文件夹带走;到新机器上用导入贴回来即可。
