8环境安装与验证

好消息:我这台电脑的基础工具已经装齐了(2026-07-29 实测)。这一节只做两件事:逐项验证,以及建一个「虚拟环境」。每一步都有预期输出,对不上就看排错表。

终端(Terminal / 命令行)

一个用文字跟电脑对话的窗口:我输入一行命令,它执行并把结果打印给我。后面所有安装、运行都在这里进行。

  1. 验证 Python 主版本。在终端输入:

    python --version
    Python 3.14.6

    版本号和我机器上略有出入没关系,能打印出 Python 3.x.x 就算通过。

  2. 验证 Python 3.10 可用。我的电脑上还装了 3.10,通过 py 启动器调用:

    py -3.10 --version
    Python 3.10.x
    为什么不用最新的 3.14? AI 生态的很多库(尤其 PyTorch)对最新版 Python 的支持通常滞后几个月到一年。 3.10 是目前 AI 教程和库兼容性最稳的版本之一。本课程所有实验统一用 3.10 建环境,避免我在第 7 章装 PyTorch 时撞墙。

  3. 建课程工作目录。建议用纯英文路径(中文路径偶尔会让某些库报奇怪的编码错误)。 命令里的 ~ 在 PowerShell 中代表「当前用户的主目录」(形如 C:\Users\你的用户名), 所以这条命令在任何一台 Windows 电脑上原样可用——本笔记会跟着我换电脑,命令不写死具体机器:

    mkdir ~\ai-lab
cd ~\ai-lab
    (无输出即成功;第二条执行后,提示符变为 PS C:\Users\你的用户名\ai-lab)

  4. 创建虚拟环境。

    虚拟环境(virtual environment)

    一套与系统隔离的独立 Python 运行环境:在这里装的库只属于这个项目,不影响系统,也不和其他项目冲突。删掉 .venv 文件夹就等于彻底卸载。

    py -3.10 -m venv .venv
    (等待约 10 秒,无输出即成功;目录下多出一个 .venv 文件夹)

  5. 激活虚拟环境。PowerShell 里输入:

    .venv\Scripts\Activate.ps1
    (.venv) PS C:\Users\你的用户名\ai-lab>

    行首出现 (.venv) 就代表已进入这个隔离环境。以后每次做实验,先 cd 进目录、再激活。

  6. 最终验证。激活状态下:

    python --version
    Python 3.10.x

    注意:同一条命令,激活前打印 3.14,激活后打印 3.10——这就是虚拟环境在起作用。看到这个变化,环境部分就全部通过了。本章实验只用标准库,暂时不需要 pip install 任何东西。

10核心概念 What / Why / Where

四个概念,每个都按同一套问题拆:是什么(输入→输出)、为什么需要、位于系统哪一环,再加上游下游、怎么观察、容易误解什么。读的时候对照第 6 节的地图。

概念一 · 人工智能(AI)

让计算机完成过去认为「需要人类智能」的任务,这是一个目标,不是一种具体技术。

What
一个总称/目标。输入:某个任务(识别图片、翻译、下棋、写文案);输出:机器给出的完成结果。实现手段可以是人写规则,也可以是机器学习。
Why
很多任务(比如「认出照片里的猫」)人类一眼就会,却写不出明确步骤。传统编程要求把每一步写死,这类任务写不动,所以需要「另一种造程序的方式」。
Where
它是整张地图的最外圈,不对应具体代码。当产品页写着「AI 驱动」,我应该追问:里面用的是规则、经典机器学习,还是深度学习?
上游是什么人类的任务需求(「我想让机器帮我做 X」)。
接收什么数据取决于任务:图片、文字、声音、表格都可能。
内部做了什么取决于实现路线:规则系统在执行人写的判断;机器学习系统在执行「学出来的参数运算」。
输出给谁用户或下一个程序环节(比如识别结果交给推荐系统)。
如何观察生效看任务完成质量:识别对了多少、翻译通顺程度。第 5 章会给出正式的「评价指标」。
最易误解把 AI 当成一种「有意识的存在」。它是一类技术的统称,和「交通工具」一样,不是某台具体的车,更没有意识。

概念二 · 机器学习(Machine Learning,ML)

不由人写规则,而是给程序看大量「例子」,让它自己找出输入和输出之间的规律。

先补两个马上要用的词:

模型(model)

一个内部含有若干可调数值的数学函数:输入进去,输出出来。这些数值没调好时输出是乱的,调好后输出接近正确答案。

参数(parameter)

就是模型里那些可调数值本身。训练(training)= 用数据自动调整参数的过程。GPT-4 级别的模型有上千亿个参数,本章实验的模型只有 1 个。

What
输入:一批例子(数据 + 正确答案,如「1000 封邮件 + 每封是否垃圾邮件」);输出:一个调好参数的模型,能对没见过的新输入给出预测。
Why
规则写不完。垃圾邮件的花样每天在变,人手写 if…else 永远追不上;让程序从最新数据里自己学,规则才能跟着数据更新。
Where
地图第二圈。在代码里的典型形态是三行套路:model = 某算法() → model.fit(数据, 答案)(训练)→ model.predict(新数据)(预测)。第 5 章我会亲手写这三行。
上游是什么数据收集与清洗环节(第 3–4 章的 NumPy / Pandas 就干这个)。
接收什么数据整理成表格/数组形状的样本。每行一个例子,每列一个特征。
内部做了什么反复三步:用当前参数做预测 → 度量预测和正确答案差多远 → 朝着差距变小的方向调参数。第 12 节我会手工完整走一遍。
输出给谁训练好的模型交给应用程序调用;预测结果交给用户或下游逻辑。
如何观察生效拿一批模型没见过的数据测它,看预测对不对。「没见过」三个字是重点,第 5 章展开(训练集/测试集)。
最易误解以为机器学习是「把答案背下来存进数据库,预测时去查」。错:它学的是规律(参数),不是答案本身,所以才能应对没见过的输入。

概念三 · 深度学习(Deep Learning,DL)

神经网络(neural network)

一种特定结构的模型:把大量简单的「乘加计算单元」一层一层叠起来。「深度」= 层数多。

What
机器学习的一个子类:模型专指多层神经网络。输入:数字化后的图片、文字、声音;输出:分类结果、生成的内容等。和上一个概念的关系是「深度学习 ⊂ 机器学习」,只是模型换成了层数很多的神经网络。
Why
经典机器学习处理表格数据很强,但面对图片、语音、自然语言,需要人先手工设计「特征」(告诉模型看什么),效果封顶。深度网络能自己从原始数据里逐层提炼特征:浅层看边缘,中层看纹理,深层看整体——这是 2012 年之后 AI 爆发的直接原因。
Where
地图第三圈。代码形态在第 7 章和 D03 出现:用 PyTorch 定义 nn.Linear、nn.ReLU 等层再堆叠。我现在只需记住:层叠结构 + 从数据学参数。
上游是什么同机器学习,外加更苛刻的要求:更多数据、更强算力(GPU)。
接收什么数据一切都先变成数字数组(张量):图片→像素数值,文字→Token 编号(见概念四)。
内部做了什么数据逐层做「乘加 + 非线性变换」向前流(前向传播);训练时误差反向流回来修正每层参数(反向传播)。第 7 章手算,现在不必懂细节。
输出给谁同机器学习;在大模型场景里,输出的是「下一个词的概率表」(见第 11 节)。
如何观察生效训练时看损失曲线是否下降;训练后拿没见过的数据测。D03 会让我亲眼盯着损失一轮轮变小。
最易误解「深度学习和机器学习是两个并列流派」。错,是包含关系;另一个误解是「层数越多一定越好」——层数多也带来更难训练、更易过拟合(第 6 章)。

概念四 · 生成式 AI 与大语言模型(LLM)

生成式 AI(Generative AI)

输出不是「选一个类别」,而是「产出一段内容」(文字、图片、音频)的深度学习模型。

大语言模型(Large Language Model,LLM)

生成式 AI 里专管文字的那类:读入一段文字,反复预测「下一个词最可能是什么」,一个词一个词地把回答续写出来。GPT、Claude 都是。

What
输入:一段文字(我的问题 + 之前的对话);输出:续写出来的文字(回答)。本质是一个「超大号的下一词预测器」,由几十上百层 Transformer 网络构成(D05 拆)。
Why
以前每个语言任务(翻译、摘要、问答)都要单独训练一个模型。LLM 用「预测下一个词」这一个任务在海量文本上训练后,竟然一个模型就能做所有语言任务——这是范式变化,也是我要学它的原因。
Where
地图最内圈的高亮区。代码形态:调 API(发文字、收文字,D07 起写)或本地跑开源模型。作为设计师,我日常用的 ChatGPT / Claude 界面,就是包了一层聊天 UI 的 LLM。
上游是什么训练阶段:互联网规模的文本语料;使用阶段:我的输入和应用拼好的上下文(D07)。
接收什么数据文字先切成 Token(词块)再转成编号和向量,详见第 11 节的数据流图。
内部做了什么对输入做几十层 Transformer 运算,得到词表中每个词作为下一个词的概率,按概率抽一个,拼回输入,再预测下一个……循环到回答结束。
输出给谁聊天界面、或调用它的程序(Agent、RAG 系统等,阶段二全是这个)。
如何观察生效最直接:去 ChatGPT/Claude 打一句话。工程上则要正式评估(D10):准确率、幻觉率、成本。
最易误解「它在网上检索现成句子拼出回答」。错:不联网时它不检索任何库,每个词都是现场按概率生成的——这也解释了它为什么会一本正经地编造(幻觉,D10)。
四个概念一句话串联 人工智能是目标;机器学习是实现路线(从数据学参数);深度学习是这条路线里当前最强的模型家族(多层神经网络); 大语言模型是这个家族里专管文字生成的明星成员。

11数据流与执行流程

用我最熟悉的场景——问 ChatGPT 一句话——把「文字进去、回答出来」的黑箱拆成六站。每一站后面章节都会专门拆,这里先记住顺序。

Token(词块)

模型处理文字的最小单位,通常是一个词或半个词。「人工智能」可能被切成「人工」+「智能」两个 Token。切完后每个 Token 用一个编号表示。

推理(inference)

用训练好的模型做预测的过程(参数不再变动)。与之相对,「训练」是调参数的过程。我每次用 ChatGPT,都是在触发一次推理。

训练和推理是两条不同的流程

🏗️ 训练(在模型厂商那边发生)

海量文本 → 模型不断做「预测下一个词」练习 → 每次预测错就微调参数 → 重复万亿次。产物:一大包调好的参数。耗时数月、成本数千万美元起。

⚡ 推理(我每次提问时发生)

我的文字 → 走一遍上面的图 → 输出回答。参数全程不变。耗时几秒,成本按 Token 计费。我和 ChatGPT 聊天并不会「教会」它什么(D06 细讲)。

12最小代码实验:规则 vs 学习

这是全课程第一个实验,也是最重要的一个:用一个只有 1 个参数的模型,完整走一遍「机器学习」四个字的全部含义。GPT 有上千亿参数,但原理和这 1 个参数完全同构。

12.1 具体问题

我有三条快递记录(重量 → 实付运费):

重量 x(kg)123
运费 y(元)4.27.912.1

任务:预测 5kg 要多少钱。

两种做法:

  • 规则法:拍脑袋定「每公斤 4 元」,写死在代码里。数据变了(比如涨价),人要回来改代码。
  • 学习法:定一个含未知参数的公式「运费 = w × 重量」,让数据自己告诉我们 w 该是多少。数据变了,重跑一遍就自动更新。

学习法就是机器学习。下面把它拆到底。

12.2 数学表达(逐个符号讲)

模型:ŷ = w · x

  • x:输入,这里是重量。形状:一个数(标量)。
  • w:参数,整个实验就是在找它的最佳取值。形状:一个数。
  • ŷ:读作 “y hat”,模型的预测值。戴帽子是为了和真实值 y 区分。形状:一个数。

损失函数:L(w) = (1/n) · Σᵢ (yᵢ − w·xᵢ)²

损失函数(loss function)

给「当前参数的预测有多离谱」打分的函数:预测越差,分数越大;训练的目标就是把这个分数压到最小。

  • n:样本个数,这里 n = 3。
  • i:样本编号,从第 1 条数据取到第 n 条。
  • yᵢ − w·xᵢ:第 i 条数据上,真实值减预测值 = 误差。
  • (…)²:平方。两个作用:①正负误差不会互相抵消;②大错误被加倍惩罚。
  • Σᵢ … / n:全部样本的平方误差加起来取平均。所以 L 叫「均方误差」(MSE),第 5 章还会见到它。

运算前后数据的变化:进:一个候选 w(标量)+ 三对数据 → 中间:3 个误差、3 个平方 → 出:1 个平均数(标量)。数字进,数字出,没有任何神秘步骤。

12.4 最少量 Python 实现

下面 17 行就是完整的「机器学习程序」。先通读注释,然后去实验 01 分步敲一遍(实验页可以直接在浏览器里运行)。

# rule_vs_learn.py —— 规则 vs 学习:最小机器学习实验
weights = [1, 2, 3]          # 数据:重量(kg),长度为 3 的列表
prices  = [4.2, 7.9, 12.1]   # 数据:实付运费(元),与上面一一对应

def loss(w):
    """算参数 w 的损失:预测得越离谱,返回值越大"""
    total = 0
    for x, y in zip(weights, prices):  # 每次取一对 (重量, 运费)
        error = y - w * x                # 公式里的 yᵢ − w·xᵢ
        total += error ** 2              # 公式里的平方与求和 Σ
    return total / len(weights)          # 公式里的 ÷ n

# “学习”= 在候选参数里挑损失最小的(最笨但最直观的方法)
best_w, best_loss = 0, loss(0)
for i in range(20001):                  # 试遍 0.000, 0.001, …, 20.000
    w = i * 0.001
    if loss(w) < best_loss:
        best_w, best_loss = w, loss(w)

print(f"学到的参数 w = {best_w:.3f},损失 = {best_loss:.4f}")
print(f"预测 5kg 运费:{best_w * 5:.2f} 元")
学到的参数 w = 4.021,损失 = 0.0179
预测 5kg 运费:20.11 元

12.6 成熟库的标准写法(对照,暂不运行)

等第 5 章装好 scikit-learn(经典机器学习的标准库)后,同一个问题的标准写法是:

from sklearn.linear_model import LinearRegression

X = [[1], [2], [3]]        # 注意形状:3 行 1 列 = 3 个样本 × 1 个特征
y = [4.2, 7.9, 12.1]

model = LinearRegression(fit_intercept=False)  # 选定模型形式 ŷ = w·x
model.fit(X, y)                        # 训练:相当于我们的整个搜索循环
print(model.coef_)                     # 学到的 w ≈ [4.0214]
print(model.predict([[5]]))           # 预测 ≈ [20.107]
我们的手写版scikit-learn 版说明
weights / prices 两个列表X, y库要求 X 是「样本 × 特征」的二维形状,所以 1 变 [1]
loss() 函数藏在库内部同样是均方误差
8001 次搜索循环model.fit(X, y)库用公式直接解,不用暴力搜,快得多
best_w * 5model.predict([[5]])都是拿学到的参数算新输入

请记住这个感觉:库没有做任何我们没手算过的事,它只是做得更快、更通用。整个课程会反复使用「手写版 ↔ 库版本」的对照法。

12.7 修改参数,观察变化

做完实验 01 后,回来试这三个改动(每个都只改一行),观察输出如何变:

  • 把 12.1 改成 50(相当于数据里混进一条错误记录)→ w 会被拉到多大?这就是「脏数据毁模型」。
  • 把搜索范围 range(20001) 改成 range(3001)(只搜到 w=3.0)→ 学到的 w 卡在边界 3.0。搜索范围不覆盖正确答案,再多数据也没用。

15常见误解

❌ 「必须先精通数学才能开始学 AI」

✅ 顺序反了:先像本章这样用小例子建立直觉,数学在每次需要时补一小块。我今天已经用小学数学理解了损失函数。

❌ 「机器学习就是把答案存起来,用时去查」

✅ 学的是参数(规律),不是答案。本章实验里模型没存过「5kg=20 元」这条记录,却能预测 5kg——因为它学到了 w。

❌ 「深度学习是和机器学习并列的另一门技术」

✅ 是包含关系:深度学习 ⊂ 机器学习。它只是把模型换成了多层神经网络。

❌ 「ChatGPT 在网上搜现成句子拼给我」

✅ 默认情况下它不检索任何库,每个词都是按概率现场生成的。这既是它能写出全新内容的原因,也是它会一本正经编造(幻觉)的原因。

❌ 「必须先精通数学才能开始学 AI」

✅ 顺序反了:先像本章这样用小例子建立直觉,数学在每次需要时补一小块。我今天已经用小学数学理解了损失函数。

❌ 「损失降得越低,模型就一定越好用」

✅ 损失只衡量「在见过的数据上」的表现。死记硬背训练数据能把损失压得极低、却对新数据一塌糊涂(过拟合,第 6 章重点)。

18参考答案

练习 1 · L(5) 的完整计算

预测:5×1=5,5×2=10,5×3=15。误差:4.2−5=−0.8;7.9−10=−2.1;12.1−15=−2.9。 平方:0.64、4.41、8.41。求和 13.46,除以 3 ≈ 4.487。 对照 12.3 的表:L(5)≈4.49 远大于 L(4.021)≈0.018,说明 w=5 是个差参数——「每公斤 5 元」明显收贵了。

练习 2 · 新增预测行 
print(f"预测 0.5kg 运费:{best_w * 0.5:.2f} 元")

输出 预测 0.5kg 运费:2.01 元。注意:模型敢对任何输入给出预测,哪怕 0.5kg 在训练数据范围(1–3kg)之外——预测值是否可信是另一回事,这个问题叫「外推」,第 5 章讨论。

练习 3 · 脏数据的破坏力

新的最优 w = Σxy ÷ Σx² = (56.3 + 3×50) ÷ (14 + 9) = 206.3 ÷ 23 ≈ 8.97,对 5kg 的预测变成约 44.8 元——翻了一倍多。 一条脏数据(占比仅 25%)就把模型拉偏成这样,因为平方损失对大误差极其敏感,模型被迫向离群点妥协。 结论先记住:数据质量 ≥ 算法聪明程度。这也是为什么课程把 Pandas(数据清洗)排在所有模型课之前。
