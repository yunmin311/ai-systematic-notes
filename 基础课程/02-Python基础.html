7变量与类型

变量variable:给一份数据起的名字。起了名之后,后面用这个名字就能取到那份数据。

最贴切的画面:变量是贴在盒子上的标签。x = 5 不是「x 等于 5」,而是「把标签 x 贴到装着 5 的盒子上」。所以 = 读作「赋值 / 贴标签」,判断相等要用 ==。

每份数据都有类型(type),决定它能做什么运算。AI 代码里最常见这几种:

float 小数带小数点的数4.2、3.14价格、权重、概率
str 字符串一段文字,用引号包住"阿岩"名字、文本、Prompt

最常见的低级 bug · = 和 ==

= 是赋值(贴标签),== 才是判断相等(第 10 节)。x = 5 是「让 x 指向 5」,x == 5 是「问:x 是不是 5?」写错这一个字符,是新手第一大坑。

8容器一 · 列表 list

列表list:一排有顺序的数据,用方括号 [] 括起、逗号隔开,靠位置编号取里面的元素。

关键规矩:编号从 0 开始,不是 1。第一个是 [0],也能用负号从末尾倒数,[-1] 是最后一个。

9容器二 · 字典 dict

字典dict:一组「键 → 值」的对应,用花括号 {} 括起。不靠位置,靠键(key)去取对应的值(value)。

列表适合「一串同类的东西」(一排分数),字典适合「一条有多个字段的记录」(一个人的名字、年龄、分数)。取值时,列表用编号 [0],字典用键 ["名字"]。

字典基本操作python
student = {"名字": "阿岩", "分数": [95, 85]}
print(student["名字"])       # 按键取 → 阿岩
print(student["分数"][0])    # 值是列表,再取第一个 → 95
student["城市"] = "北京"       # 加一个新键值对

列表 vs 字典,一句话记牢:问「第几个?」用列表(按位置);问「哪一个?」用字典(按键)。第 1 章那份 {"name":..., "scores":[...]} 就是「字典里套列表」——现在我能完全读懂它了。

10控制流一 · if 分支

if 让程序分情况走不同的路:条件成立走一条,不成立走另一条。Python 靠缩进(通常 4 个空格)划定「哪几行属于这个 if」——缩进是语法,不是排版,错了直接报错。

score = 72
if score >= 90:
    print("优秀")

11控制流二 · for 循环

for 循环:把一堆东西挨个拿出来,对每一个做同样的事。处理「一列数据」的标准手段,AI 代码里到处是它。

for 循环 + 累加器python
scores = [88, 92, 79]
total = 0
for s in scores:      # s 依次是 88、92、79
    total = total + s # 每轮累加进 total
print(total / len(scores))  # 平均 → 86.33...

三个常配 for 的小工具:range(5) 生成 0–4(定次数循环);zip(a, b) 把两个列表配对(第 1 章的 zip(weights, prices) 就是它);enumerate(lst) 每轮同时给「编号 + 元素」。

会用 for 处理一列数据后,把这段常用的活打包起来、起个名字反复调用——这就是函数。

12函数 def

函数function:把一段会反复用的活打包起来、起个名字。以后要用,报名字并递进材料(参数),它算完把结果返回给我。

画面:函数是一台进料出料的机器。原料从参数进,机器内部按定义处理,成品从 return 出来。用的人不必知道内部,只管递料、接结果。

定义与调用python
def average(numbers):       # 定义一台叫 average 的机器,收参数 numbers
    return sum(numbers) / len(numbers)

print(average([88, 92, 79]))  # 调用 → 86.33...
print(average([100, 60]))       # 再调一次 → 80.0

定义 ≠ 执行:写下 def 那几行,机器只是造好待命,里面代码并不运行;只有调用 average([...]) 时才执行一次。这正是第 1 章执行链里「先定义、后调用」的意思。

15实战:把第 1 章那 17 行读懂

五块地基学完,回到第 1 章那段「看得懂却写不出」的代码,逐行标注它用了本章哪块——读完应该能合上页面自己默写。

rule_vs_learn.py · 逐行对应本章python
weights = [1, 2, 3]              # 列表(第 8 节)
prices  = [4.2, 7.9, 12.1]      # 列表(第 8 节)

def loss(w):                        # 函数定义(第 12 节)
    total = 0                       # 变量(第 7 节)
    for x, y in zip(weights, prices): # for + zip(第 11 节)
        error = y - w * x            # 算术(第 7 节)
        total += error ** 2          # 累加平方(第 11 节)
    return total / len(weights)      # 返回 + len(第 8、12 节)

best_w, best_loss = 0, loss(0)     # 调用函数(第 12 节)
for i in range(20001):              # for + range(第 11 节)
    w = i * 0.001
    if loss(w) < best_loss:          # if + 比较(第 10 节)
        best_w, best_loss = w, loss(w)
print(f"学到的 w = {best_w:.3f}")     # f-string(第 13 节)

19参考答案

练习 1 · 列表与字典取值 
student = {"名字": "阿彩", "分数": [88, 92, 79]}
print(student["名字"])        # 阿彩
print(student["分数"][0])     # 88
print(sum(student["分数"]))   # 259

要点:字典按键取,列表按位置取;「字典套列表」两步连写。

练习 2 · for 求平均 
nums = [70, 85, 90, 95]
total = 0
for n in nums:
    total = total + n
print(total / len(nums))     # 85.0

「累加器」套路:循环外归零,循环内每轮吃进一个。

练习 3 · 默写第 1 章代码

对照第 15 节。评判不是一字不差,而是:两列表建对了?loss 里 for...zip 累加了平方误差?主循环用 if < 记住了更小的损失?跑出来 w ≈ 4.021?能跑通、逻辑对就算过。

练习 4 · 读一个报错

最后一行 KeyError: 'b':向字典要键 "b" 的值,但字典里只有 "a"。修法:先确认键存在,或用 d.get("b")(查不到返回 None 而不报错)。
