NumPy:数组与形状

上一章的列表能装一串数,但一次只能挨个算,上万个数就慢得没法用。这一章把它升级成 NumPy 的 数组(ndarray):一整块规整数据,一条命令就能整批运算——这是后面一切「张量」操作的地基。

图解骨架约 40 分钟,外部精读 + 动手约 3~5 小时。全程只用到加减乘除和「求平均」,概念都用第 2 章的列表作对照。每出现一个新词,当场用白话解释。

4一句话本质

NumPy 把「一堆同类型的数」打包成一块规整的、带形状的内存,于是能用一条命令对整块数据高速运算——这就是向量化。

列表是一个个格子松散地串在一起,每个格子还能装不同类型;数组是一整块对齐的方阵,类型统一、形状明确。正因为规整,底层才能一次性批量处理,比 Python 循环快几十上百倍。AI 里的图片、特征、权重,本质都是这种规整的数(张量),NumPy 就是操作它们的地基。

7ndarray:数组是什么

ndarrayn-dimensional array:一块规整的、同类型的、带形状的数据。用 np.array([...]) 从列表造出来。

和列表的关键区别:列表里每个格子松散独立、还能各装各的类型;数组是一整块对齐的内存,所有元素同一类型、排成规整的方阵。正因为规整,底层才能一次性批量算——这就是它快的根。

造数组 · 看属性python
import numpy as np

a = np.array([88, 92, 79, 100])   # 从列表造一维数组
print(a)          # [ 88  92  79 100]
print(a.dtype)    # int64  —— 全体统一的类型
print(type(a))    # <class 'numpy.ndarray'>
print(a * 2)      # [176 184 158 200]  —— 整批乘 2,没写 for
去精读

官方 absolute basics 的「What is an array / Array fundamentals」;np.zeros、np.ones、np.arange 几个常用造法读那一段顺带就会。

数组有了,下一步得会说它「几行几列」——这就是 shape。

8shape 与维度

shape:数组的形状,一个元组,像 (2, 3) 表示「2 行 3 列」。reshape 换形状但不改数据本身。

一维数组只有长度;二维数组有行有列;再往上是三维、更高维(图片就是「高 × 宽 × 颜色通道」的三维数组)。.shape 给出每个维度多大,.ndim 给出有几个维度。同样一批数,可以 reshape 成不同形状——数字没变,只是排布变了。

shape 与 reshapepython
b = np.arange(6)        # [0 1 2 3 4 5]
print(b.shape)          # (6,)   一维,长度 6
c = b.reshape(2, 3)     # 排成 2 行 3 列
print(c.shape)          # (2, 3)
print(c.ndim)           # 2      两个维度
print(c)
# [[0 1 2]
#  [3 4 5]]
reshape 元素数要对得上

reshape 前后元素总数必须相等:6 个数只能排成 (2,3)、(3,2)、(6,) 这些,排 (2,4) 会报错。填 -1 让 NumPy 自己算那一维:b.reshape(2, -1)。

会说形状之后,要能精确取出数组里的某行、某列、某块——这是索引与切片。

9索引与切片

二维数组用 a[行, 列] 取值:逗号前挑行、逗号后挑列;: 表示「这一维全要」。还能用条件(布尔)一次取出满足要求的元素。

一维索引和列表一样(a[0]、a[-1]、a[1:3])。二维多了个逗号:a[0, 1] 是第 0 行第 1 列;a[0, :] 是整个第 0 行;a[:, 0] 是整个第 0 列。最有用的是布尔索引:a[a > 90] 直接取出所有大于 90 的数,一行顶一个筛选循环。

索引 · 切片 · 布尔python
a = np.array([[88, 92, 79],
              [95, 60, 85]])
print(a[0, 1])     # 92         第 0 行第 1 列
print(a[1, :])     # [95 60 85] 整个第 1 行
print(a[:, 0])     # [88 95]    整个第 0 列
print(a[a > 90])   # [92 95]    所有大于 90 的数(布尔索引)
a[a < 61] = 61     # 把不及格的一次性抬到 61(整批赋值)
去精读

官方 absolute basics 的「Indexing and slicing」;布尔索引在那一页叫 “Boolean indexing”,是 AI 数据清洗里最常用的一招。

取值会了,再看 NumPy 最核心的本事:不写 for,整批一起算。

10向量化:整批一起算

向量化vectorization:对整个数组直接做 + - * / 或 sum/mean,一条命令算完所有元素,不写 for。

第 2 章求平均要写循环累加;NumPy 里 a.mean() 一步到位。两个数组 a + b 是逐元素相加;a * 2 是每个都乘 2。聚合运算还能按维度:a.sum(axis=0) 沿「行」方向压下去得到每列的和,axis=1 得到每行的和。axis 指的是「哪个维度被压掉」。

向量化 vs 循环python
scores = np.array([88, 92, 79, 100])

# 第 2 章的写法:循环累加
total = 0
for s in scores:
    total = total + s
avg = total / len(scores)

# NumPy 的写法:一行,整批算
avg = scores.mean()          # 89.75
top = scores.max()           # 100
norm = scores / scores.max() # 每个数除以最大值,整批完成

a = np.array([[1, 2, 3],
              [4, 5, 6]])
print(a.sum(axis=0))   # [5 7 9]  每列的和(压掉行)
print(a.sum(axis=1))   # [6 15]   每行的和(压掉列)
想一想

a.sum(axis=0) 和 a.sum(axis=1) 为什么一个得到 3 个数、一个得到 2 个数?

看答案

a 是 2 行 3 列。axis=0 压掉「行」这一维(2 消失),每一列剩一个和,共 3 个 → [5 7 9]。axis=1 压掉「列」这一维(3 消失),每一行剩一个和,共 2 个 → [6 15]。记住:axis 是被压掉的那一维。

为什么非要向量化

不只是少写字:向量化把循环交给底层 C 批量执行,处理上万个数比 Python 的 for 快几十上百倍。AI 里动辄百万级数据,循环根本跑不动——这就是 NumPy 存在的理由。

最后一块,也是最容易懵的一块:两个形状不一样的数组,凭什么能相加。

11广播 broadcasting

广播broadcasting:形状不同的数组做运算时,NumPy 按规则把小的那个自动「铺开」到大的形状,再逐元素算——省得手动复制。

最简单的广播:数组 + 单个数,那个数被铺到每个元素上(a + 10)。进阶:一个 (3,) 的行,和一个 (3,1) 的列相加,NumPy 把行按列数铺、把列按行数铺,得到一个 (3,3) 的方阵。规则一句话:从右往左对齐每一维,某一维要么相等、要么其中一个是 1(1 的那个被铺开)。

广播python
a = np.array([10, 20, 30])   # shape (3,)
print(a + 100)               # [110 120 130]  单个数铺到每个元素

row = np.array([[10, 20, 30]])       # shape (1, 3)
col = np.array([[1], [2], [3]])      # shape (3, 1)
print(row + col)             # 广播成 (3, 3)
# [[11 21 31]
#  [12 22 32]
#  [13 23 33]]
去精读 · 往后连

精读:官方 absolute basics 的「Broadcasting」,规则细节看 Broadcasting 专页。往后连:PyTorch 的张量运算沿用同一套广播规则,这里搞懂了那里直接省事。

12实战:把一批分数标准化

「标准化」是喂数据给模型前几乎必做的一步:把每个数减去平均值、再除以标准差,让整批数据变成「以 0 为中心」。下面这段就用到本章全部五块——数组、shape、索引、向量化、广播:

standardize.pypython
import numpy as np

# 3 个学生、4 门课的成绩,shape (3, 4)
scores = np.array([[88, 92, 79, 100],
                   [95, 60, 85,  70],
                   [70, 75, 90,  88]])

col_mean = scores.mean(axis=0)   # 每门课的平均(压掉行)→ (4,)
col_std  = scores.std(axis=0)    # 每门课的标准差 → (4,)

# 广播:(3,4) 减 (4,) 再除 (4,),每门课各自标准化
z = (scores - col_mean) / col_std

print(z.shape)          # (3, 4)
print(z.mean(axis=0))   # 约 [0 0 0 0]  每列已以 0 为中心
print(scores[z > 1])    # 布尔索引:挑出明显高于本门平均的成绩

读一遍:mean(axis=0) 和 std(axis=0) 是向量化聚合,一步得到每门课的均值和标准差;(scores - col_mean) / col_std 是 (3,4) 和 (4,) 的广播,每门课各自标准化;z > 1 是布尔索引,挑出突出的成绩。全程没有一个 for 循环——这就是 NumPy 的日常。

14常见误区 · 实际情况

表 3 · 五个新手误区
可能以为实际情况
数组和列表差不多,能混用数组同类型、连续内存、能向量化;列表松散、能混类型、只能循环。AI 数据一律用数组。
reshape 会改变数据只改「形状」,数字和顺序都没动;元素总数必须对得上,否则报错。
a[:, 0] 是「第 0 个」逗号前是行、后是列;a[:, 0] 是「所有行的第 0 列」,即整个第 0 列。
axis=0 是「按行算」axis 是被压掉的维度。axis=0 压掉行,得到每列的结果。
广播是我要手动复制数据NumPy 自动按规则铺开,不真的占那么多内存;只要保证每一维「相等或有一个是 1」。
