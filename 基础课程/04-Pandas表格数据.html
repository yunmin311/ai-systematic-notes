Pandas:表格数据处理

4一句话本质

Pandas 在 NumPy 数组之上,给行和列都贴上标签,于是能按「列名」和「条件」来操作数据——这就是一张能用代码处理的表。

数组只能按位置 a[0, 1] 取值;表可以按名字 df['分数'] 取一整列,或 df[df['分数']>90] 按条件筛行。多出来的这层「行列标签」,正是真实数据分析需要的:数据带列名、有缺失、要按类别分组统计。底层的数还是 NumPy 数组,Pandas 只是给它套了个好用的壳。

7Series 与 DataFrame

DataFrame数据框:一张带行标签(index)和列标签(columns)的二维表。它的每一列是一个 Series——带标签的一维数据。

把数组想成没抬头的方阵,DataFrame 就是给它加了列名(columns)和行号(index)的 Excel 表。一列叫一个 Series,同一列类型统一;整张表放一起就是 DataFrame。有了列名,才能用 df['分数'] 这种一眼看懂的方式取数,而不是背第几列。

造一张表 · 看属性python
import pandas as pd

df = pd.DataFrame({
    '姓名': ['阿岩', '小林', '阿彩'],
    '分数': [88, 95, 72],
    '城市': ['北京', '上海', '北京'],
})
print(df.shape)     # (3, 3)  三行三列
print(df.columns)   # Index(['姓名', '分数', '城市'], ...)
print(df.dtypes)    # 每列的类型:object(文字)/ int64(数)
print(df['分数'])   # 取「分数」这一列(一个 Series)

官方 intro tutorial 01「What kind of data does pandas handle?」;df.head()、df.info()、df.describe() 这几个「看表」的方法读那一篇顺带就会。

8读写数据

读写:pd.read_csv('文件.csv') 把一个文件读成 DataFrame,df.to_csv('新文件.csv') 把处理完的表存回去。Excel 换成 read_excel。

这是 Pandas 最日常的入口:数据分析十有八九从 read_csv 开始。读进来第一件事是体检——df.head() 看前几行长什么样,df.info() 看有多少行、每列什么类型、哪里有缺失,df.describe() 看数值列的均值和分布。先看清楚,再动手。

读文件 · 先体检python
df = pd.read_csv('scores.csv')   # 从 CSV 读成表
df.head()        # 看前 5 行,先认清列名和样子
df.info()        # 行数、每列类型、缺失情况
df.describe()    # 数值列的均值/最大/最小/分位数

df.to_csv('cleaned.csv', index=False)  # 处理完存回,不写行号
读中文 CSV 乱码

Windows 下 CSV 常是 GBK 编码,直接读会乱码或报错。加参数指定编码:pd.read_csv('文件.csv', encoding='gbk');若还不行试 encoding='utf-8-sig'。

表读进来了,接着要从一大张表里挑出想分析的那部分——选取子集。

9选取子集:挑行挑列

选列用 df['列名'];选行用 df.loc[标签] 或 df.iloc[位置];按条件筛行用 df[df['列'] > 值]。

三种最常用:一是选列,df['分数'] 取一列、df[['姓名','分数']] 取多列;二是选行,df.loc[0] 按行标签、df.iloc[0] 按位置(和数组一样从 0 数);三是条件筛选,df[df['分数']>90] 直接留下分数大于 90 的行,和上一章的布尔索引是同一招。loc 认标签、iloc 认位置,是最容易搞混的一对。

选列 · 选行 · 条件python
df['分数']                 # 选一列(Series)
df[['姓名', '分数']]        # 选多列(小 DataFrame)
df.loc[1]                  # 按行标签取第 1 行
df.iloc[0]                 # 按位置取第 1 行
df[df['分数'] > 90]        # 条件筛选:分数大于 90 的行
df.loc[df['城市']=='北京', '姓名']  # 北京学生的姓名列
想一想

df.loc[1] 和 df.iloc[1] 什么时候结果不一样?

看答案

当行标签(index)不是默认的 0,1,2 时。loc[1] 找标签叫 1 的那行;iloc[1] 永远是第 2 行(位置从 0 数)。如果我把某列设成了 index(比如用姓名当行标签),loc['小林'] 用名字取行,而 iloc[1] 还是取位置。记住:loc 认标签、iloc 认位置。

真实数据总有脏的地方——缺失、类型不对、列名难认。下一块是清洗。

10清洗:缺失值与类型

清洗:找出缺失值(NaN),决定填补还是丢弃;顺手把类型改对、把列名改清楚。

真实表里常有空格子(缺失值,显示成 NaN)。df.isna().sum() 一眼看出每列缺多少;df.dropna() 丢掉有缺失的行,df.fillna(值) 用某个值(如该列平均)填补。到底填还是丢,看数据——缺得少可丢,缺得多、又不能丢就填。另外常做的:df.rename() 改列名、df['列'].astype(int) 改类型。

找缺失 · 填或丢 · 改python
df.isna().sum()            # 每列有多少缺失值
df.dropna()                # 丢掉含缺失的行
df['分数'].fillna(df['分数'].mean())   # 用该列平均填补缺失
df.rename(columns={'分数': 'score'})   # 改列名
df['分数'] = df['分数'].astype(float)  # 改类型
很多方法不改原表

df.dropna()、df.fillna() 默认返回一张新表、不动原表。想让改动生效,要么接住返回值 df = df.dropna(),要么(不推荐)用 inplace=True。忘了接返回值,是新手最常见的「代码没报错但表没变」。

最后一块,也是数据分析的核心动作:按类别把数据分组,each 组各算一个统计。

11分组统计 groupby

groupby:按某一列的取值分组,对每一组各算一个统计(平均、计数、求和)——「拆开 → 各算 → 合并」三步。

这是从「一堆明细」得到「一张汇总」的标准动作,对应 Excel 的数据透视表。df.groupby('城市')['分数'].mean() 读作:按城市把行拆成几组,每组算分数的平均,再把结果合并成一张小表。三步一句话:split(按列拆开)→ apply(每组各算)→ combine(合并结果)。

分组统计python
df.groupby('城市')['分数'].mean()     # 每个城市的平均分
df.groupby('城市').size()             # 每个城市几个人
df.groupby('城市')['分数'].agg(['mean', 'max', 'count'])  # 一次算多个
去精读 · 往后连

精读:官方 intro tutorial 06「How to calculate summary statistics」。往后连:准备训练数据时,常先 groupby 看各类别的分布是否均衡——这是第 5 章挑数据集的第一步。

12实战:一张成绩表从读到汇总

下面这段是数据分析最常见的开头:读进来、体检、清洗、筛选、分组汇总。用到本章全部五块:

analyze.pypython
import pandas as pd

df = pd.read_csv('scores.csv')      # ① 读:文件 → 表
print(df.info())                    #    体检:看行数、类型、缺失

df = df.dropna(subset=['分数'])     # ② 清洗:丢掉分数缺失的行(接住返回值!)
df['分数'] = df['分数'].astype(float)

top = df[df['分数'] >= 60]          # ③ 选取:只看及格的
by_city = top.groupby('城市')['分数'].mean()   # ④ 分组:每城市平均分

print(by_city.sort_values(ascending=False))    # 从高到低排

读一遍:read_csv 是读写;dropna、astype 是清洗;df[df['分数']>=60] 是选取子集;groupby(...).mean() 是分组统计;整张 df 从头到尾是一个 DataFrame。真实数据分析,开头几乎都是这套。

14常见误区 · 实际情况

表 3 · 五个新手误区
我可能以为实际情况
DataFrame 和 Excel 表一样,能随手改格子它是代码里的对象;改动靠方法(选取、赋值、groupby),不是鼠标点。好处是可复现、能自动跑。
loc 和 iloc 差不多loc 认标签、iloc 认位置。index 不是 0,1,2 时结果不同,是最常见的坑。
df.dropna() 会直接改原表默认返回新表、不动原表。要 df = df.dropna() 接住,否则「没报错但表没变」。
缺失值一律删掉最省事缺得多就删,会丢大量数据。看情况:能填(平均/众数/前值)就填,不能填再删。
groupby 很玄就是「拆开 → 各算 → 合并」三步,等于 Excel 透视表。想清楚「按什么分、每组算什么」就会写。
