神经网络入门

上一章讲了模型怎么用梯度下降「学」。这一章看清一种最重要的模型:神经网络。它把一个极简单的单元(神经元:加权求和再压一下)堆成一层层、连成一张网,靠上一章那套下山循环来调。理解它,后面的大语言模型就有了骨架。

图解骨架约 40 分钟,外部精读 + 动手约 4~6 小时。全程用「一层层传递」的直觉,不推导公式。这一章的最佳主线是 3Blue1Brown 的动画——神经网络这东西,动着看比读着看清楚十倍。每出现一个新词,当场用白话解释。

读完这一章,我脑子里会立起来的骨架

  • 神经元——加权求和 + 激活,一个最小的计算单元
  • 层与网络——神经元排成层,一层喂给下一层,连成一张网

4一句话本质

神经网络:把一个极简单的单元(加权求和 + 压一下)重复成千上万次、连成多层,就能拟合几乎任意复杂的规律——复杂,是「简单单元 + 很多层」堆出来的。

单看一个神经元,平平无奇:把几个输入各乘一个权重加起来,再用一个函数压一下,输出一个数。神奇之处在规模:成千上万个这样的单元分层连接,前一层的输出当后一层的输入,整张网就能表达极复杂的输入—输出关系。而这上万个权重,全靠第 6 章的梯度下降一点点调出来。这就是深度学习——「深」指的就是层多。

7神经元:一个最小单元

一个神经元做三步:把各输入乘上各自的权重再加起来(加权求和)、加一个偏置、然后用一个激活函数压一下,输出一个数。

权重表示「这个输入有多重要」,偏置是个可调的起点。加权求和其实就是第 3 章的向量点乘。压一下(激活)让输出落进某个范围、并引入「非直线」的能力。整个神经网络的成千上万个参数,就是这些权重和偏置——全靠训练调出来。

一个神经元太弱。把它们排成层、连成网,能力才出来。

8层与网络

把神经元排成一层,一层的输出全部喂给下一层。最左是输入层(数据),中间是隐藏层(层数越多越「深」),最右是输出层(预测)。

每一层的每个神经元,都接收上一层所有神经元的输出作为自己的输入(这叫全连接)。数据像水一样从左流到右,每过一层就被「加工」一次。隐藏层越多、每层越宽,网络能表达的规律越复杂——这就是「深度」学习的深。手写数字识别里,输入层是像素、输出层是「0~9 哪个数字」,中间的隐藏层自己学会了识别笔画、圆圈等中间特征。

数据从左流到右得到预测,这个过程有个名字:前向传播。

9前向传播

前向传播forward pass:把输入数据从输入层一层层往右算,每层做一次「加权求和 + 激活」,最后从输出层得到预测。

这就是网络「用」的过程:给一张图,像素从左边进,逐层被加工,右边吐出「这是数字 7」。没有魔法,只是一连串的乘加和激活。训练时,前向传播先算出预测,再和答案比出损失——然后才轮到反向传播去调参数。

中间那个「压一下」的激活函数,看着不起眼,却是整张网的命门。

10激活函数:为什么缺它不可

激活函数:神经元里那个「压一下」的非直线动作(如 ReLU:负数变 0、正数不变)。没有它,再多层也会塌成一条直线,学不了弯的规律。

关键在「非直线」。如果每个神经元只是加权求和(直线),那么一层套一层,合起来还是一条直线——一百层等于一层,白搭。激活函数在每层之间插入一个弯,层与层才不会互相抵消,网络才能拟合曲折复杂的关系。最常用的 ReLU 简单粗暴:小于 0 的都拍成 0,大于 0 的原样通过,却出奇地好用。

一句话记牢

权重和层数给网络「容量」,激活函数给网络「拐弯的能力」。抽掉激活,深网络退化成一条直线;这就是为什么它必不可少。

最后一块:预测错了,怎么把这上万个权重各自该调多少算出来——反向传播。

11反向传播

反向传播backpropagation:把输出端的误差从右往左一层层传回去,高效地算出每个权重「该往哪调、调多少」(也就是第 6 章说的梯度)。

它不是新的学习方法,而是第 6 章梯度下降里「算梯度」那一步的高效实现。前向传播得到预测和损失后,反向传播利用链式法则,从输出层往输入层倒推:每个权重对最终误差「贡献」了多少,就该按比例调整多少。算出所有权重的梯度后,再用梯度下降各挪一小步。前向算预测、反向算梯度、更新参数——就是第 6 章那个训练循环,只是套在多层网络上。

12实战:手算一个神经元

不用任何深度学习库,就用 NumPy,把「加权求和 + 偏置 + 激活」这一个神经元算出来。我会发现它简单得出奇——神经网络的全部神奇,都在于把这件小事重复上百万次:

one_neuron.pypython
import numpy as np

x = np.array([0.5, -1.0, 2.0])   # 三个输入
w = np.array([0.8,  0.2, -0.5])  # 三个权重(训练时会被调)
b = 0.1                          # 偏置

z = np.dot(w, x) + b             # ① 加权求和 + 偏置(就是向量点乘)
y = max(0.0, z)                  # ② 激活:ReLU —— 负数拍成 0

print(f"加权和 z = {z:.2f}")     # z = -0.70
print(f"激活后 y = {y:.2f}")     # y = 0.00(被 ReLU 压成 0)

读一遍:np.dot(w, x) 是加权求和(第 3 章的点乘);+ b 是偏置;max(0, z) 是激活函数 ReLU。这就是一个神经元的全部。一整层就是很多个这样的神经元并排(用矩阵一次算),一张网就是很多层串起来——原理一模一样,只是数量变大。

进阶挑战

改改看

①把三个神经元并成一层:把 w 换成一个 (3, 3) 的权重矩阵 W,用 W @ x + b 一次算出三个输出(这就是「一层」)。②把两层串起来:第一层的输出当第二层的输入,各带自己的 W 和激活——我就手写出了一个两层网络的前向传播。③去掉激活(直接用 z),想想为什么两层叠起来等于一层。

14常见误区 · 实际情况

表 3 · 五个新手误区
我可能以为实际情况
神经网络像人脑一样思考只是「加权求和 + 激活」重复很多层的数学函数,借了「神经元」这个名字而已。
单个神经元很复杂极简单:乘、加、压一下。复杂来自数量和层数,不是单个单元。
激活函数可有可无缺了它,再多层也塌成一条直线,学不了弯的规律。它是拐弯能力的来源。
反向传播是另一种学习法它只是「高效算梯度」的方法;学的动作还是第 6 章的梯度下降。
层越多总是越好太深会难训练、易过拟合。合适的深度 + 足够数据,比一味加深重要。

15自测 · 思考题

  1. 画一个神经元。用自己的话+一张草图,说出神经元的三步是什么。
    参考答案

    ①各输入乘权重求和 + 偏置;②过激活函数「压一下」;③输出一个数。

  2. 为什么要激活。如果所有神经元都不加激活函数,一个 100 层的网络等价于几层?
    参考答案

    等价于 1 层(纯线性叠加还是线性)。所以没激活,再深也白搭。

  3. 前向 vs 反向。一句话分别说清前向传播和反向传播在做什么。
    参考答案

    前向:数据从左往右算出预测;反向:误差从右往左传回、算出每个权重的梯度。

  4. 连回上一章。反向传播算完梯度之后,靠什么把参数真正调一小步?
    参考答案

    梯度下降(第 6 章):参数 = 参数 − 学习率 × 梯度。
