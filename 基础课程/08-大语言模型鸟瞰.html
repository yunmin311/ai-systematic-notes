大语言模型鸟瞰

这是基础课程的收官。我已经知道神经网络怎么算、怎么学;这一章把镜头拉到最热的应用:ChatGPT 这类大语言模型。它其实只做一件极简单的事——预测下一个词,一个接一个地接龙。让它显得「懂」的关键零件,是一个叫注意力的机制。本章只做鸟瞰,把骨架看清,细节留给深度课程。

图解骨架约 40 分钟,外部精读约 3~5 小时。全程用「切词、变数、看上下文、接龙」的直觉,不推公式。这一章的主线还是 3Blue1Brown 的动画。每出现一个新词,当场用白话解释。

读完这一章,我脑子里会立起来的骨架

  • Token——把文字切成一个个小块,每块给个编号
  • Embedding——每个 token 变成一串数(向量),意思近则向量近
  • 注意力——每个词按相关度「看」上下文,一词多义靠它定
  • Transformer——注意力 + 神经网络堆很多层,就是 GPT 的骨架
  • 预测下一个词——反复猜「下一个 token」,一个个接龙生成回答

4一句话本质

大语言模型只做一件事:给定前面的文字,预测下一个最可能的词(token),吐出来后接到末尾,再预测下一个——一个字一个字地接龙,直到成篇。

它不是在数据库里查答案,也没有「想法」。它在海量文本上训练,练成了一个超强的「下一个词概率预测器」。我问一个问题,它其实是在算「顺着这段话,接下来最像样的词是什么」,一个个接出来。之所以显得连贯、像懂,是因为为了把下一个词预测准,它在训练中不得不学会语法、常识、推理的模式。让它能「顾及上下文」来预测的核心零件,就是下面要讲的注意力。

先看第一步:一句话进模型前,怎么被切开、编号。

7Token:把文字切成块

Token词元:模型处理文字的最小单位。不是按字也不是按词,而是按常见子词切;每个 token 对应词表里的一个编号。

模型不认字,只认数。第一步就是把输入切成 token,再查词表换成编号。英文里常见词是一个 token、生僻词被拆成几块;中文常一两个字一个 token。为什么不直接按字或按词:按字太碎、按词词表爆炸,子词是折中。我用 API 时按 token 计费,一段中文大约每字 1~2 个 token——这就是那个 token。

编号只是身份证,不带含义。要让模型「懂意思」,得把编号变成向量。

8Embedding:把词变成向量

Embedding词向量:把每个 token 映射成一串数(向量)。训练后,意思相近的词,向量也相近——含义变成了空间里的位置。

光有编号不够,编号 88 和 89 没有含义上的远近。Embedding 给每个 token 一串学出来的数,让「狗」和「小狗」在这个多维空间里离得近、和「汽车」离得远。含义就这样被编码成了几何距离,模型才能做类比和推理。另外,Transformer 本身分不清词序,所以还会加上位置编码,告诉它「这个词排第几」——最终进模型的,是「词义向量 + 位置向量」。

现在到了让大模型「聪明」的核心零件——注意力。

9注意力:让词看懂上下文

注意力attention:处理每个词时,让它按相关度「看」句子里的其它词,把有用的信息加权吸收进来。一词多义、指代关系,全靠它从上下文定。

「它」指谁?「苹果」是水果还是公司?孤立地看一个词没法定,必须看上下文。注意力就是干这个:算出当前词和句中每个词的相关度,相关的多吸收、无关的少吸收,于是同一个词在不同句子里能有不同的理解。这是 Transformer 相对老方法最大的突破——一步就能让每个词照顾到全句,还能高度并行。名字里的「Attention」就是它。

它没有真的「理解」

注意力是数学上的加权求和,不是人类的理解。它极擅长捕捉「哪些词该一起看」的统计规律,但没有意图和常识保证——这也是大模型会一本正经胡说(幻觉)的根源之一。

把注意力和神经网络堆很多层,就成了 Transformer——GPT 的骨架。

10Transformer:把它们堆起来

Transformer:把「注意力 + 普通神经网络」打包成一个块,再把这种块叠很多层。每过一层,每个词的向量就被上下文打磨得更精准。GPT 里的「T」就是它。

一句话进来变成一串向量后,反复穿过很多层 Transformer 块:每层先用注意力让词互相看、再用神经网络各自加工。层层之后,每个词的向量都饱含了对全句的理解。GPT-3 有几十层、上千亿参数,全靠第 6、7 章那套梯度下降 + 反向传播,在海量文本上训出来。规模,是它能力的主要来源之一。

最后把整条链接上:模型是怎么一个词一个词把回答生成出来的。

11预测下一个词:接龙生成

生成 = 循环:把已有文字送进 Transformer,得到下一个词的概率,挑一个接到末尾,再把加长的文字送回去……一个词一个词地接,直到结束。

大模型的输出层给出的是「下一个 token 是词表里每个词的概率」。挑概率最高的(或按温度随机采样一个),接到句子末尾,然后把新的、更长的句子重新喂进去,预测再下一个。如此循环,回答就一个字一个字冒出来——这也是为什么 ChatGPT 的字是逐个蹦出来的。它本质是个接龙机,只是接得极其像样。

12组装:一次对话内部发生了什么

我在 ChatGPT 里打一句话、按下回车到它开始回答,内部大致这样走完全程——每一步都对应本章一块地基:

  1. 切成 token。我的问题被切成子词块、查词表换成编号。(第 7 节)
  2. 变成向量。每个 token 换成词向量,再加位置编码,得到一串带含义、带位置的向量。(第 8 节)
  3. 穿过很多层 Transformer。每层用注意力让词互相看、用神经网络加工;层层之后,每个词都「读懂」了全句上下文。(第 9、10 节)
  4. 预测下一个词。输出层给出「下一个 token 的概率」,挑一个接到末尾。(第 11 节)
  5. 循环。把加长后的文字重新送回第 3 步,再预测下一个词——回答就一个字一个字冒出来,直到模型输出「结束」。

整场对话,没有查数据库、没有「思考」,只有「切词 → 变向量 → 层层注意 → 预测下一个词 → 接龙」这一条链在飞快地转。看懂这条链,我对大模型的能力和边界(为什么强、为什么会胡说)就有了地基。

15自测 · 思考题

  1. 一句话本质。用一句话说清大语言模型到底在做什么。
    参考答案

    给定前面的文字,反复预测下一个最可能的词(token),接龙生成。

  2. 流程排序。把这几步排成正确顺序:预测下一词 / 切 token / 穿过 Transformer / 变成向量。
    参考答案

    切 token → 变成向量 → 穿过 Transformer → 预测下一词 → (循环)。

  3. 注意力。「他把苹果吃了」和「他买了苹果的股票」里的「苹果」,模型靠什么区分?
    参考答案

    注意力:根据上下文(吃 / 股票)给「苹果」不同的关注与理解,一词多义靠它定。

  4. 边界。既然 LLM 只是预测下一个词,为什么它会「一本正经胡说」?
    参考答案

    它优化的是「像不像下一句话」,不是「对不对」。当训练里没有可靠依据时,它照样会流畅地编一个最像样的答案。
