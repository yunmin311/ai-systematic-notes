实验室入口

讲义负责看懂,实验室负责跑通。每个实验都是分步的:一段代码、一句「应该看到什么」、一句「为什么」;跑完还有「自己改一改」和一张排错表。跑出来的数和页面上写的对不上,就是最值钱的时刻——排错表第一栏就是从那里开始。

两种跑法

方式 A · 页面内运行器:代码旁边有「▶ 运行」,用的是 Pyodide——跑在浏览器里的真实 Python,不是模拟输出。首次点击要下载运行时,约 10–20 秒,需要联网;用到 NumPy / Pandas / scikit-learn 时会自动装包。

方式 B · 本机终端:同样的代码放在 实验室/code/labNN/ 下,可以直接 python step1_xxx.py。本机更快,而且能改文件、能存结果。

lab-06 只能走方式 B:PyTorch 不在浏览器版 Python 里。装依赖 pip install torch numpy。
