实验室入口

讲义负责看懂,实验室负责跑通。每个实验都是分步的:一段代码、一句「应该看到什么」、一句「为什么」;跑完还有「自己改一改」和一张排错表。跑出来的数和页面上写的对不上,就是最值钱的时刻——排错表第一栏就是从那里开始。

两种跑法

方式 A · 页面内运行器:代码旁边有「▶ 运行」,用的是 Pyodide——跑在浏览器里的真实 Python,不是模拟输出。首次点击要下载运行时,约 10–20 秒,需要联网;用到 NumPy / Pandas / scikit-learn 时会自动装包。

方式 B · 本机终端:同样的代码放在 实验室/code/labNN/ 下,可以直接 python step1_xxx.py。本机更快,而且能改文件、能存结果。

lab-06 只能走方式 B:PyTorch 不在浏览器版 Python 里。装依赖 pip install torch numpy。

Stage 1 / 配套基础课程

读完对应章节再来跑。前两个不需要任何第三方库以外的东西。

lab-01 规则 vs 学习 同一个任务写两遍:一遍把规则写死,一遍让程序从数据里学出参数。 配 第 1 章 · 浏览器 + 本机 · 4 个脚本 lab-02 数组与表:形状、广播、分组 先故意制造一次形状报错再修好;一行 groupby 回答三个问题;看清缺失值不是 0。 配 第 3 · 4 章 · 浏览器 + 本机 · 3 个脚本 lab-03 第一个分类器:训练、评估、挪阈值 准确率 90% 的模型,63 个正样本漏掉 57 个。然后亲手挪阈值,看两个指标反向动。 配 第 5 章 · D02 · D05 · 浏览器 + 本机 · 3 个脚本
Stage 2 / 配套深度课程 · Track A 经典机器学习

这两个实验各演示一种「分数骗人」的方式——一种是自己骗自己,一种是写法骗了自己。

lab-04 过拟合现场:看着两条曲线分叉 树越长越深,训练分数涨到 1.000、测试分数掉到 0.767。再用两种刹车拉回来。 配 D05 · D10 · 浏览器 + 本机 · 2 个脚本 lab-05 数据泄露现场:分数是怎么被喂高的 纯噪声数据、随机标签,诚实分数 0.400,顺序搞错一步就冲到 0.867。 配 D06 · 浏览器 + 本机 · 2 个脚本

Stage 3 / 配套应用工程
