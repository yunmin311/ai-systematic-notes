线性回归全拆解

深度课程从最简单、也最透彻的模型开始:用一条直线去拟合数据。别小看它——机器学习的三件套「模型、损失、训练」在它身上第一次能被完整看清、甚至手算一遍。学透线性回归,后面所有模型(逻辑回归、神经网络、乃至大模型)都是在这套骨架上加零件。基础课第 5、6 章给了直觉,这一章把它拆到能自己写出来。

图解骨架约 40 分钟,动手 + 精读约 4~6 小时。所有概念都用基础课 第 5 章(模型/训练)、第 6 章(损失/梯度下降)作对照。

4一句话本质

线性回归:假设「结果 ≈ 各特征的加权和」,然后调权重,让预测值和真实值的平方误差最小——找到那条(或那个高维平面)最贴数据的线。它是「模型-损失-训练」三件套最干净的一次示范。

为什么从它开始:机器学习千变万化,但骨架永远是三步——先假设一个带参数的模型(这里是 y = w·x + b),再定义一个损失衡量「猜得多离谱」,最后调参数把损失压到最小(训练)。线性回归把这三步摆得最清楚:模型就是一条直线、损失就是「竖直距离的平方和」、训练就是把这条线转到最贴数据的角度。别的模型只是把「直线」换成更复杂的函数,三步骨架分毫不变。所以吃透它,等于拿到了理解一切模型的模板。

7什么是线性回归

线性回归假设:要预测的值 ≈ 输入特征的加权和再加一个偏置,写成 ŷ = w·x + b。w(斜率/权重)和 b(截距/偏置)是要学的两个旋钮;学习就是把这两个旋钮调到让直线最贴数据点。

举个具体例子:用「房子面积」预测「房价」。每个点是一套真实的房子(面积, 价格)。线性回归要找一条直线 价格 ≈ w×面积 + b:w 是「每平米大概值多少」,b 是「基础价」。找到这条线后,给一个新面积,代进去就能预测价格。"线性"的意思就是:关系是一条直线(不弯)。这既是它的简单之处,也是它的局限——真实世界很多关系不是直的(D02 起就会松开这个假设)。

「最贴数据」得能量化——这就要一把尺子:损失。

8损失:均方误差 MSE

用均方误差MSE当尺子:把每个点的残差(预测−真实)平方后求平均。这个数越小,直线越贴。训练就是找让 MSE 最小的 w、b。

为什么是「平方」而不是直接加差值?两个原因,都很实在:一是差有正有负,直接加会正负抵消(明明离得远,加起来却像很准),平方后全变正,不会互相抵消;二是平方放大大误差——离谱的点被惩罚得更狠,逼着直线优先照顾它们,不敢摆烂。这就是第 6 章说的「损失函数」在线性回归里的具体样子。它还有个好处:平方误差是个光滑的「碗形」,好优化(下一节的两条路都靠它)。

一眼记住

MSE = 所有(预测−真实)² 的平均。越小越好;0 = 完美穿过所有点(现实里几乎不可能,也不该追求,否则就是 第 5 章说的过拟合)。

尺子有了,怎么真的找到让它最小的 w、b?有两条路。

9求最优:解析解 vs 梯度下降

两条路殊途同归:解析解(最小二乘)——用一个公式一步算出最优 w、b,精确但只对线性这种简单模型管用;梯度下降——从随便一组 w、b 出发,顺着损失下降最快的方向一小步一小步挪,通用到能训练神经网络。

解析解:因为 MSE 是个碗形,数学上能直接解出碗底在哪(令导数为零,一个矩阵公式搞定)。优点是精确、一步到位;缺点是只有线性回归这类简单模型有这种「闭式公式」,复杂模型没有。梯度下降(第 6 章那套「下山」):站在碗壁上,看哪个方向最陡,朝反方向迈一小步,重复,直到滚到碗底。它慢一点、要调步长(学习率),但什么模型都能用——正因如此,它才是深度学习的通用引擎。学线性回归,两条都要懂:解析解让我看清「最优确实存在且可求」,梯度下降让我拿到通向后面所有模型的钥匙。

现实里输入往往不止一个特征——一元怎么长成多元。

10从一元到多元

预测房价通常不只看面积,还看地段、楼层、房龄……每个特征给一个权重:ŷ = w₁x₁ + w₂x₂ + … + b。一元时是「一条直线」,多元时是「一个高维平面」,但骨架完全一样:加权和 + 偏置,再用同一套损失和训练去调权重。

换个视角就更清爽:把所有权重排成一个向量 w、所有特征排成一个向量 x,预测就是它们的点积 w·x + b(第 3 章 NumPy 讲过点积)。特征从 1 个变成 100 个,代码和数学几乎不变,只是向量变长——这正是向量化的威力,也是为什么线性代数是机器学习的通用语言。每个权重 wᵢ 还有直观含义:「其它不变时,这个特征每增加一点,预测值变化多少」,所以线性回归天然「可解释」——这是它至今仍被大量使用的原因之一。

概念齐了。同一个线性回归,在三个抽象层各长什么样?

11三个版本:手算 / 手写 / 一行

理解一个算法,最好的办法是看它在不同抽象层的样子。同一件事——拟合一条直线——有三种写法,从繁到简:

12组装:手写梯度下降拟合直线

这段代码就是「模型-损失-训练」三件套的最小可运行版,每一块都标了对应第几节:

linreg_gd.pypython
import numpy as np

# 造一批「大致在一条直线上」的数据:真实规律 y ≈ 2x + 1(加点噪声)
X = np.array([1, 2, 3, 4, 5], dtype=float)
y = np.array([3.1, 4.8, 7.2, 8.9, 11.1])

w, b = 0.0, 0.0           # ⑦ 模型参数:先随便设成 0
lr = 0.01                 # ⑨ 学习率:每步迈多大
n = len(X)

for step in range(1000):                 # ⑨ 梯度下降:一步步逼近
    y_hat = w * X + b                     # ⑦ 模型:预测
    error = y_hat - y                     # 残差(预测 − 真实)
    loss = np.mean(error ** 2)            # ⑧ 损失:MSE

    # 损失对 w、b 的梯度(斜率):告诉我们往哪调、调多少
    grad_w = 2 * np.mean(error * X)
    grad_b = 2 * np.mean(error)
    w -= lr * grad_w                       # ⑨ 顺着下降方向挪一小步
    b -= lr * grad_b

    if step % 200 == 0:
        print(f"step {step:4d}  loss={loss:.3f}  w={w:.3f}  b={b:.3f}")

print(f"学到:y ≈ {w:.2f}x + {b:.2f}")     # 应接近 2x + 1

逐块对照:y_hat = w*X + b 是模型(⑦);np.mean(error**2) 是损失 MSE(⑧);grad_w/grad_b 加 w -= lr*grad_w 是梯度下降(⑨)——顺着让损失变小的方向挪一小步,重复一千次,w、b 就慢慢滑到碗底。跑起来会看到 loss 一路下降、w 趋近 2、b 趋近 1。这十几行,就是后面所有深度学习训练循环的胚胎。而生产里我只需版本③:

linreg_sklearn.pypython
from sklearn.linear_model import LinearRegression

model = LinearRegression().fit(X.reshape(-1, 1), y)   # ③ 一行搞定(内部用解析解)
print(model.coef_, model.intercept_)                  # w, b —— 和手写版结果一致

两版结果一致,但我现在知道那一行背后发生了什么——这就是自己写过一遍的价值。

进阶挑战

改改看

①把学习率 lr 调到 0.1 和 0.001,看损失下降变快还是发散(太大就会「冲过头」震荡)。②把训练轮数改成 50,看它还没到碗底就停会怎样(欠拟合)。③给数据加一个明显偏离的「离群点」,看平方误差怎么被它带偏——体会 MSE 对异常值敏感。④加一个特征(变成二元),把 X 换成两列,自己推广梯度公式。

14常见误区 · 实际情况

表 3 · 五个常见误区
我可能以为实际情况
线性回归太简单,没必要深究它是「模型-损失-训练」最干净的模板,吃透它=拿到理解一切模型的钥匙。

"线性"指模型很弱、没用它可解释(每个权重有明确含义)、快、稳,至今是很多场景的首选和基线。

15自测 · 思考题

  1. 一句话本质。线性回归在做什么?
    参考答案

    假设结果≈特征的加权和,调权重让预测与真实的平方误差最小,即找一条最贴数据的线,用于预测。

  2. 损失。为什么用平方误差而不是直接加残差?
    参考答案

    差有正负会抵消;平方消符号、还放大大误差(逼模型照顾离谱点);且平方损失光滑、好优化。

  3. 两条路。解析解和梯度下降各适合什么?
    参考答案

    解析解:一步精确,但只对线性这类有闭式解的简单模型;梯度下降:一步步逼近、要调步长,但通用,深度学习必用。

  4. 代码。第 12 节里 lr 太大会怎样?
    参考答案

    每步迈太大会冲过碗底来回震荡,甚至发散、损失越来越大,不收敛。
