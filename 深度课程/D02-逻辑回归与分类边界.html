逻辑回归与分类边界

名字里带"回归",干的却是分类的活——判断"是/否"。它是对 D01 线性回归的一次小改造:同一条 w·x+b 的直线不动,只在末尾套一个 S 形函数(sigmoid) 把输出挤成"属于某一类的概率",再把损失从平方误差换成更适合分类的交叉熵。直线就从"预测数值"变成了"划分类别的边界"。它简单、可解释,还是理解神经网络最后一层的钥匙。

图解骨架约 40 分钟,动手 + 精读约 4~6 小时。全程用 D01 作对照——我会看到分类不过是回归的一次改装。

读完这一章,我脑子里会立起来的骨架

  • 从回归到分类——预测数值 vs 预测类别,为什么不能直接拿线性回归分类

  • 决策边界——概率过 0.5 判正类;那条 w·x+b=0 就是边界
  • 交叉熵——分类为什么弃用 MSE,以及它怎么狠罚"自信地错"
  • 多分类——用 softmax 把两类推广到多类

4一句话本质

逻辑回归 = 线性回归 + sigmoid + 交叉熵。先算老一套的加权和 z = w·x+b,再用 sigmoid 把 z 挤成 0~1 的概率,概率过 0.5 就判正类;训练时用交叉熵当损失、照样梯度下降。直线还是那条,只是被赋予了"边界"的新身份。

关键的认知转变:D01 的输出 w·x+b 是个可大可小的数值(适合预测房价),但分类要的是"属不属于某类"——一个 0 到 1 的概率。直接拿 w·x+b 当概率不行(它能到 100 或 −50,没法当概率)。于是加一个 sigmoid 把它温柔地压进 0~1。至于损失,平方误差配 sigmoid 会让梯度下降走得很别扭(后面讲),换成交叉熵就顺了。就这两处改动,回归器摇身变分类器。理解这一点,我会发现很多"新模型"其实都是老骨架换零件。

7从回归到分类

回归预测一个连续数值(房价、气温);分类预测一个离散类别(是/否、猫/狗/鸟)。分类要的是"属于某类的概率",而线性回归的输出没有上下限,直接拿来当概率会出界、还对离群点极敏感——所以要改造。

具体为什么线性回归不适合分类:假设我把"是垃圾邮件=1,不是=0"当数值,用 D01 硬拟合。问题一,w·x+b 可能算出 3.7 或 −2,当"概率"讲不通;问题二,只要来一封"极其垃圾"的邮件(特征值很大),为了照顾它,整条拟合线会被硬生生带歪,把原本分对的样本判错。分类需要的是一个"温和地把分数转成概率、且不被极端值牵着走"的机制。sigmoid 正是为此而来。

这个"把分数转成概率"的零件,就是 sigmoid。

8sigmoid:把分数挤成概率

sigmoid 是一条 S 形曲线:输入任意实数,输出被挤进 0~1。z 很大 → 趋近 1(几乎肯定是正类);z 很小(很负)→ 趋近 0;z=0 → 正好 0.5(拿不准)。它把 D01 的加权和 z 平滑地翻译成"属于正类的概率"。

直觉上,sigmoid 做了两件好事:一是有界(永远在 0~1),输出天然能当概率;二是平滑单调,z 越大概率越高,且处处可导(梯度下降需要)。它中间陡、两端平——意味着"模型很有把握时(z 很大或很小),再变一点分数也几乎不改变判断",这符合直觉。逻辑回归的完整预测就是:概率 = sigmoid(w·x + b)。前半截和 D01 一模一样,只在最外面包了一层 S 形。

有了概率,怎么落到"判成哪一类"?这就引出决策边界。

9决策边界

规则很简单:概率 ≥ 0.5 判正类,否则判负类。而概率=0.5 恰好对应 z = w·x+b = 0——这个方程在特征空间里就是一条线(二维)或一个平面(高维),它就是决策边界:线一边判正、另一边判负。

所以 D01 那条直线并没有消失,它换了个身份:在回归里它是"预测值",在分类里它是"分界线"。w、b 决定这条线的位置和方向,训练就是把这条线挪到最能把两类分开的地方。注意:逻辑回归的边界是直的(线性),所以它只能分开"大致能用一条直线隔开"的两类;遇到犬牙交错的复杂边界,就需要更强的模型(树、神经网络)——这也是后面几章的动机。阈值 0.5 也不是铁律:医疗筛查宁可错杀不可放过,就把阈值调低,让更多样本判为"阳性"(这接到 D05 的精确率/召回率权衡)。

训练要一把损失尺子——但这次不能用 D01 的平方误差。

10交叉熵:狠罚"自信地错"

分类用交叉熵(对数损失)当损失,不用 MSE。核心特性:当模型很自信却判错时(如真实是正类、它给的概率却接近 0),损失会飙到极大——狠狠惩罚"自信地犯错",逼它别乱打包票。

为什么不用 MSE:一是 MSE 配上 sigmoid,损失曲面会变得"平坦难走",梯度下降经常卡住学不动;二是交叉熵天然衡量"两个概率分布差多少",和"输出概率"的任务严丝合缝。它的直觉是:我对正确答案给的概率越高,损失越小(给满 1 则损失为 0);给正确答案的概率越接近 0,损失越趋于无穷。这就把"要有把握,但错了别嘴硬"编进了训练目标。除了换损失,训练流程和 D01 一字不差——还是求梯度、还是梯度下降下山。

两类会了,类别更多怎么办?一步推广。

11多分类:softmax

类别多于两个(猫/狗/鸟)时,把 sigmoid 换成 softmax:给每个类别算一个分数,再统一归一化成"加起来等于 1"的一组概率,取最大的那个作预测。它是 sigmoid 的多类版,损失仍用交叉熵。

做法:每个类别有自己的一套 w、b,各算一个分数 z;softmax 把这几个 z 变成一组和为 1 的概率(分数高的拿走更多概率)。比如三类算出概率 [0.7, 0.2, 0.1],就判第一类。为什么要记住 softmax:它就是大模型"预测下一个词"的最后一步——词表里几万个词各算一个分数,softmax 归一成概率,再按概率采样。我在 第 8 章见过的"模型输出下一个词的概率分布",底层正是 softmax。小小的逻辑回归,一路通到 LLM。

12组装:训练一个分类器

先看 sigmoid 本身长什么样(几行),再用 scikit-learn 训练完整分类器:

sigmoid_demo.pypython
import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))       # ② 把任意 z 挤进 0~1

print(sigmoid(0))     # 0.5   —— z=0 拿不准
print(sigmoid(5))     # 0.993 —— 很大 → 几乎肯定正类
print(sigmoid(-5))    # 0.007 —— 很负 → 几乎肯定负类
logreg_sklearn.pypython
from sklearn.linear_model import LogisticRegression
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split

X, y = load_breast_cancer(return_X_y=True)          # 一个「良性/恶性」二分类数据集
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.2, random_state=0)

clf = LogisticRegression(max_iter=5000).fit(X_tr, y_tr)   # ①②④ 训练(内部就是本章那套)

print("准确率:", clf.score(X_te, y_te))              # 在没见过的数据上评估
print("头 3 个样本判正类的概率:", clf.predict_proba(X_te)[:3, 1])   # ② sigmoid 出来的概率
print("判成的类别:", clf.predict(X_te)[:3])          # ③ 概率过 0.5 → 类别

逐块对照:LogisticRegression().fit 内部做的就是本章全部——线性部分 + sigmoid + 交叉熵 + 梯度类优化;predict_proba 给出的正是 sigmoid 输出的概率(②);predict 是用 0.5 阈值把概率转成类别(③)。我会看到它在没见过的测试集上准确率相当高——而且因为是逻辑回归,我还能看 clf.coef_ 知道每个特征把判断往哪个方向推(可解释性,D01 的老优点)。

14常见误区 · 实际情况

表 2 · 五个常见误区
我可能以为实际情况
逻辑回归是回归算法名字带回归,实际做分类;"回归"指内部那段线性加权和。
可以直接拿线性回归输出当概率它没有 0~1 上下限、还被离群点带偏。要用 sigmoid 挤成概率。

15自测 · 思考题

  1. 一句话本质。逻辑回归是怎么从线性回归改造来的?
    参考答案

    线性部分 w·x+b 不变,末尾套 sigmoid 挤成 0~1 概率、过 0.5 判正类,损失从 MSE 换成交叉熵;训练仍是梯度下降。

  2. sigmoid。z=0、z 很大、z 很负分别输出什么?
    参考答案

    z=0 → 0.5(拿不准);z 很大 → 趋近 1;z 很负 → 趋近 0。

  3. 边界。决策边界在图上是哪条线、怎么来的?
    参考答案

    概率=0.5 对应 w·x+b=0 的那条线/面;一边判正、一边判负。逻辑回归的边界是直的。

  4. 损失。为什么分类用交叉熵不用 MSE?
    参考答案

    MSE 配 sigmoid 梯度易卡;交叉熵衡量概率分布差异、狠罚"自信地错",与输出概率的任务契合,训练更顺。
