决策树、随机森林与梯度提升

前两章的模型都用"一条直线"分界。这一章换一条完全不同的思路:不画线,而是一层层地问"是/否",把数据切成一块块——像玩"二十个问题"。这就是决策树:直观、可解释,但单棵容易过拟合。于是把很多棵树组合起来——随机森林(投票)和梯度提升(接力纠错)。后者(XGBoost/LightGBM)至今是表格数据上最能打的模型之一,Kaggle 常胜将军。

4一句话本质

决策树:用一连串"某特征 > 某值?"的是非问题,把数据一层层切开,切到每一块里样本足够"纯"(基本同一类),预测时顺着问题走到底、看落在哪块。单棵树聪明但爱钻牛角尖(过拟合);把很多棵树组合起来——投票(森林)或接力纠错(提升)——就又稳又准。

为什么它和前两章如此不同、又如此重要:线性/逻辑回归假设"世界大致是线性的",用一条直线分界;决策树不做这种假设,它直接按数据把空间切成方块,天然能拟合弯弯曲曲的关系,还不怕不同特征量纲不一样(面积用平方米、房龄用年,树完全不在乎)。代价是单棵树容易把训练集的噪声也学进去。集成(ensemble)是破解之道:三个臭皮匠顶个诸葛亮——很多棵各有小缺点的树合在一起,缺点互相抵消,整体又准又稳。这套"组合弱模型成强模型"的思想,是机器学习最实用的智慧之一。

先看一棵树本身:它就是一串问题。

7决策树是什么

决策树是一串嵌套的是非问题:从根节点问一个问题(如"面积 > 80?"),按答案往左或往右,再问下一个,直到走到叶子——叶子里存的就是预测(某个类别或某个数值)。预测一个新样本,就是顺着问题从根走到叶。

这就是"二十个问题"游戏:每问一个好问题,就把可能性砍掉一半。举例判断一套房贵不贵:先问"面积 > 100 吗?"——是,再问"地段是市中心吗?"——是,落到"贵"这个叶子。整棵树把特征空间切成了一块块矩形区域,每块给一个预测。最大的好处是可解释:我能一眼看出模型凭什么这么判(哪几个问题、什么阈值),这在很多需要说明理由的场景(信贷、医疗)极其宝贵——线性模型看权重,树模型看路径。

树怎么知道该先问哪个问题、阈值设多少?

8怎么分裂:让两边"更纯"

树在每个节点试遍所有特征和阈值,选那个能让分完后两边最"纯"的(每边尽量同一类)。"纯不纯"用基尼系数或信息增益衡量。这是一步步贪心:每次只挑当前最优的一刀,不回头。

"纯"的直觉:一刀切下去,如果左边全是"贵"、右边全是"便宜",这刀就切得好(很纯);如果两边还是混着,这刀就没啥用。基尼系数就是量"一块里有多混"的数——越接近 0 越纯。树在每个节点把每个特征的每个可能阈值都试一遍,挑让"总不纯度"下降最多的那刀,然后对切出来的两块递归重复,直到足够纯或到达停止条件。正因为它按特征逐个切,所以完全不受量纲影响——面积和房龄尺度差一百倍也无所谓,这是树相对线性模型的一大省心之处(D06 会看到线性/神经网络必须缩放特征,树不用)。

但一把刀接一把刀切到底,会切出问题。

9过拟合与剪枝

如果让树一直切到"每个叶子只剩一个样本",它就能在训练集上做到 100% 正确——但那是把训练集连噪声一起背下来了(第 5 章的过拟合),换新数据就露馅。对策:限制树的深度、要求叶子至少含几个样本、或事后剪枝,让它抓大规律、放过细枝末节。

这是树最大的软肋:它太灵活,不加约束就会长成一棵"死记硬背"的巨树,训练集完美、测试集稀烂。控制手段都很直观:max_depth(最多问几层问题)、min_samples_leaf(叶子里至少要有几个样本才准成立)、剪枝(先长满再砍掉贡献小的分支)。这和 D01 说的"训练损失为 0 不一定好"是同一个道理——我们要的是在没见过的数据上表现好。而随机森林和梯度提升,本质上就是用"组合很多棵树"这个更聪明的办法,来对抗单棵树的过拟合。

第一种组合法:让很多棵树投票。

10随机森林:很多棵树投票

随机森林bagging:训练很多棵树,每棵只看数据的一个随机子集 + 特征的一个随机子集,所以每棵都不一样、各有各的偏差。预测时让所有树投票(分类)或平均(回归)。个体的随机错误互相抵消,整体又稳又准。

核心直觉是"群体的智慧":一棵树可能因为看到某些噪声而判错,但如果几百棵树各自独立地看不同的数据片段,它们的错误方向各不相同,一投票就被平均掉了,剩下的是它们共同认同的真规律。关键在"随机"——正是每棵树看得不一样,才保证它们的错误不重复(否则一起错就没意义)。随机森林几乎不用调参就很能打、很难过拟合,是表格数据上最省心的强基线,拿到新数据集常常先跑它看个底。它属于 bagging(并联:很多树独立训练、平等投票)。

第二种组合法完全相反:不是并联投票,而是串联接力。

11梯度提升:一棵接一棵纠错

梯度提升boosting:树一棵接一棵地建,每棵专门去补前面所有树犯的错(拟合当前的残差)。像一群人接力改作业:第一版粗糙,第二个人专门修第一版的错,第三个再修剩下的……层层逼近。XGBoost、LightGBM 是它的高效实现,表格数据竞赛的常胜将军。

和森林的根本区别:森林是并联(树之间独立,同时训练、平等投票);提升是串联(树之间有先后,后一棵盯着前面的错来建)。这让提升往往更准——它专注啃硬骨头;但也更容易过拟合、更需要调参(学习率、树的数量、深度),因为它太努力去纠错,可能把噪声也纠进去。经验法则:要省心稳健用随机森林;要榨干精度、愿意调参,用梯度提升(XGBoost/LightGBM)。二者都建立在决策树这块地基上——先懂树,才懂它们为什么强。

把三种模型放一起,在同一份数据上比一比。

12组装:树 vs 森林 vs 提升

scikit-learn 里三种模型接口几乎一样,换个类名就行——正好对比它们的效果:

trees_compare.pypython
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier, GradientBoostingClassifier

X, y = load_breast_cancer(return_X_y=True)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.2, random_state=0)

models = {
    "决策树(不限深度)": DecisionTreeClassifier(random_state=0),           # ⑨ 易过拟合
    "决策树(max_depth=3)": DecisionTreeClassifier(max_depth=3, random_state=0),  # ⑨ 剪枝
    "随机森林":            RandomForestClassifier(n_estimators=200, random_state=0),   # ⑩ 投票
    "梯度提升":            GradientBoostingClassifier(random_state=0),    # ⑪ 接力纠错
}

for name, model in models.items():
    model.fit(X_tr, y_tr)
    tr = model.score(X_tr, y_tr)          # 训练集准确率
    te = model.score(X_te, y_te)          # 测试集准确率(才是真本事)
    print(f"{name:22s} 训练 {tr:.3f}  测试 {te:.3f}")

跑出来我会看到几件典型的事:不限深度的决策树训练集常常 1.000(背下来了)、测试集却明显更低——活教材式的过拟合(⑨);max_depth=3 的树训练集降一点、但测试集反而更稳;随机森林和梯度提升的测试集通常最高(⑩⑪),集成的威力。把 DecisionTreeClassifier 换成 ...Regressor、数据换成回归任务,同一套代码就做回归——树天生通吃分类和回归。

进阶挑战

改改看

①把决策树的 max_depth 从 1 调到 20,画出训练集和测试集准确率随深度的变化——我会看到经典的"过拟合剪刀差"。②看 RandomForestClassifier(...).feature_importances_,哪些特征最重要?对比 D02 逻辑回归的 coef_。③装上 xgboost 或 lightgbm,用 XGBClassifier 跑同一份数据,看能不能再高一点。④把 n_estimators(树的数量)从 10 加到 500,看森林的测试准确率怎么变(通常先升后平)。

15自测 · 思考题

  1. 一句话本质。决策树怎么做预测?
    参考答案

    用一串是非问题把数据切成块,预测时从根顺着问题走到叶子,叶子里的结果就是预测。

  2. 分裂。树按什么标准选分裂点?
    参考答案

    试遍特征和阈值,选让分完后两边最"纯"(基尼/信息增益)的那刀;贪心,每步只取当前最优。

  3. 森林 vs 提升。两者最大区别?
    参考答案

    森林并联:树独立、投票平均,稳、少调参;提升串联:后树补前树的错,更准但更需调参。

  4. 选型。什么时候优先用树模型?
    参考答案

    表格数据、要可解释、特征量纲混杂、想要强基线时;尤其梯度提升是表格竞赛常胜。
