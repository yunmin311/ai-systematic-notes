聚类与降维

前三章都是监督学习——数据带着"正确答案"(标签)当老师。这一章转向无监督学习:数据没有标签,让机器自己在里面找结构。两件最常用的事:聚类——把相似的样本自动聚成一堆堆(如给用户分群);降维——把几十上百个特征压到二三维,好可视化、也去噪。没有"正确答案"时,机器照样能学到东西——这一章讲清它怎么学。

4一句话本质

无监督学习:数据只有特征、没有标签(没人告诉我"正确答案"),目标是发现数据自身的结构。两大任务:聚类把样本按相似度分成几堆;降维把高维数据压到低维,同时尽量保住原来的结构。前者回答"有哪些自然的群",后者回答"这堆高维数据长什么样"。

和监督学习对照最清楚:监督学习像有标准答案的练习册——每道题(样本)都配好答案(标签),模型学"题→答案"的映射(预测房价、判断类别)。无监督学习像没有答案的一堆资料——没人告诉我对错,我只能自己找规律:哪些资料像一类(聚类)、能不能用更少的维度概括它们(降维)。它常用于探索(拿到新数据先聚类看看有几群)、预处理(先降维再喂给别的模型)、可视化(把高维压到二维画出来)。少了标签这根拐杖,评价好坏也更主观——这是无监督的特点,也是难点。

先把"无监督"和前三章的"监督"彻底分清。

7无监督学习是什么

监督学习:每个样本都有标签(答案),学"特征 → 标签"。无监督学习:样本只有特征、没有标签,学"数据自身的结构"。区别就一个字:有没有答案在旁边当老师。

为什么需要它:现实里绝大多数数据是没标签的——标注要花大量人力钱财。给一百万用户打上"高价值/低价值"标签很贵,但直接拿他们的行为数据聚类分群几乎免费,还常常能发现我没预设的群体。无监督学习正是榨取"未标注数据"价值的钥匙。它的两大用途——聚类(分堆)和降维(压维)——一个帮我发现群体,一个帮我看清全貌 / 给别的模型减负。顺带一提:大模型的"预训练"(D16)本质也是无监督的近亲——从海量无标注文本里自己找规律,不需要人逐句标注。

先看最经典的聚类算法:K-Means。

8K-Means:把数据分成 K 堆

K-Means:我先定要分几堆(K),它就找 K 个"中心点",反复做两件事——①把每个样本分给最近的中心 ②把每个中心挪到它那堆样本的正中间——来回迭代到不再变化。最后每个中心 + 它周围的样本,就是一堆(一个簇)。

这个"分配 → 更新"的循环特别好懂:一开始随机撒 K 个中心;每个样本看自己离哪个中心最近,就归到那堆(分配);然后每个中心搬到"自己这堆样本的平均位置"(更新);位置一变,有些样本的"最近中心"就变了,于是再分配、再更新……几轮后中心稳定下来,聚类完成。它简单、快、可扩展,是聚类的第一选择。局限也明确:得先指定 K(下一节解决)、只擅长找"团状(球形)"的簇、对初始位置和离群点敏感。但作为"拿到无标签数据先跑一下看看"的工具,它无可替代。

K 得自己定——定多少?不想定又怎么办?

9选 K 与层次聚类

K 不好定时,用肘部法则:把 K 从小到大试,画"K vs 簇内总离散度"曲线,曲线明显变缓的那个"肘部"就是不错的 K。若压根不想预设 K,用层次聚类:它从每个点各成一簇开始,不断把最近的两簇合并,生成一棵可以在任意高度"切一刀"决定簇数的树。

肘部法则的直觉:K 越大,每堆越小、堆内越紧凑(离散度越低),但 K 到一定程度后再加,收益就骤减——曲线从陡降变平缓,那个转折(肘)就是性价比最高的 K。它不给唯一答案,给一个合理区间。层次聚类换了思路:不预设 K,而是自底向上不断合并最近的簇,画成一棵树状图(dendrogram);我想要几簇,就在相应高度横切一刀。它还能揭示簇之间的"亲疏层级"(哪两群更像),信息比 K-Means 丰富,代价是更慢、不适合超大数据。没有唯一正确的簇数——这正是无监督"没有标准答案"的体现,K 的选择往往要结合业务判断。

聚类之外的另一大主力:把维度压下来。

10降维为什么

降维:把几十上百个特征压成两三个,同时尽量保住数据的结构。三个动机:可视化(人只能看二三维,高维得压下来才能画)、去噪 / 提效(去掉冗余特征,模型更快更稳)、对抗"维度灾难"(维度越高,数据越稀疏、距离越失真)。

"维度灾难"值得记一下:特征一多,样本在高维空间里就变得极其稀疏,"谁离谁近"这种判断开始失灵(所有点看起来都差不多远),很多算法性能因此崩坏。降维把数据投影到"最有信息量"的少数几个方向,既缓解这个问题,又让我能把上百维的数据画在一张二维图上用肉眼看结构——这在探索阶段极其有用。注意:降维会丢一部分信息(从 100 维压到 2 维不可能无损),目标是"丢掉最不重要的、保住最重要的"。这和聚类常常配合:先降维、再在低维空间聚类或可视化。

怎么"保住最重要的"?两种主流思路。

11PCA 与 t-SNE

PCA(主成分分析):找数据最"铺得开"(方差最大)的几个方向,把数据投影上去。线性、快、可解释,适合压维 + 去噪 + 喂给别的模型。t-SNE / UMAP:非线性,专为可视化——它努力让"原本挨得近的点,在二维图上也挨得近",能把复杂结构摊平成好看的分组图。

直觉对比:PCA 像给一团数据云找"最佳拍照角度"——从哪个方向看,这团云铺得最开、信息损失最小,就从那个方向拍(投影)。它保的是"全局的大方向",快且稳,常作为预处理。t-SNE/UMAP 目标不同:它不在乎全局距离对不对,只死磕"邻居关系"——原来是邻居的,压到二维也让它们做邻居;于是画出来常常是一坨坨清晰的分组,特别适合"看看数据里有没有天然的群"。代价:t-SNE 慢、结果随机、图上簇的大小和间距不能当真(只表示邻近、不代表实际距离)。经验:要压维喂模型用 PCA;要画图看分组用 t-SNE/UMAP。这套"把高维数据压成低维向量、还保住关系"的思想,正是理解 D13 Embedding 的直接铺垫——大模型也把词压成向量,常用 UMAP 降到二维给人看。

把聚类和降维放到一份数据上跑一遍。

12组装:聚类 + 降维可视化

用经典的鸢尾花数据:先 PCA 压到二维好画,再 K-Means 聚成三堆,看机器"没看标签"能不能自己分出三种花:

cluster_pca.pypython
from sklearn.datasets import load_iris
from sklearn.cluster import KMeans
from sklearn.decomposition import PCA

X, y_true = load_iris(return_X_y=True)     # y_true 只用来最后对答案,训练时不看

# ⑤ 降维:4 个特征 → 2 维,好画图
X2 = PCA(n_components=2).fit_transform(X)

# ⑧ 聚类:不看标签,自己分 3 堆
labels = KMeans(n_clusters=3, n_init=10, random_state=0).fit_predict(X)

# 看每个「机器分出的堆」里,真实花的种类分布(评估聚类合不合理)
import numpy as np
for c in range(3):
    print(f"簇 {c}: 真实种类分布 =", np.bincount(y_true[labels == c], minlength=3))
# 你会看到:三个簇大体对应三种花——机器没看答案也分出来了

逐块对照:PCA(n_components=2) 把 4 维压成 2 维(⑤,为了能画在平面上);KMeans(n_clusters=3) 不看 y_true 就把样本分成 3 堆(⑧)。最后拿 y_true 只是对答案:我会发现三个机器分出的簇,大体各自对应一种真花——它没被告诉任何标签,却重新发现了"这里有三种花"。这就是无监督的魔力。若把 X2 用散点画出来(matplotlib 一句 scatter),还能亲眼看到三团分开的点。

进阶挑战

改改看

①把 n_clusters 改成 2 和 5,用肘部法则(对每个 K 记 kmeans.inertia_ 画曲线)找"肘"在哪。②把 PCA 换成 TSNE(n_components=2),对比两张二维图——t-SNE 的分组通常更"抱团"。③先只用 PCA 画图、用真实标签 y_true 上色,直观看看这三种花本来分不分得开。④想想:如果我事先不知道有"三种花",肘部法则会不会也提示我选 K=3?

15自测 · 思考题

  1. 一句话本质。无监督学习和监督学习差在哪?
    参考答案

    有没有标签(答案)。监督学"特征→标签";无监督只有特征,找数据自身结构(聚类/降维)。

  2. K-Means。它反复做的两件事是什么?
    参考答案

    ①把每个样本分给最近的中心;②把每个中心挪到它那堆样本的平均位置。迭代到稳定。

  3. 选 K。肘部法则怎么用?
    参考答案

    试不同 K,画"K vs 簇内离散度"曲线,曲线明显变缓的"肘"处就是性价比高的 K。没有唯一答案。

  4. 降维。PCA 和 t-SNE 各适合什么?
    参考答案

    PCA:找最大方差方向,线性快,压维/去噪/喂模型;t-SNE/UMAP:非线性、保邻近,专为可视化看分组。
