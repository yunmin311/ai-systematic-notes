4一句话本质

评价模型的两条铁律:①一个数字(尤其准确率)会骗人,要看清它把哪种错误藏起来了;②永远在"模型没见过的数据"上打分,别用训练集给自己发奖状。前者靠混淆矩阵拆出精确率/召回率等,后者靠训练/验证/测试划分和交叉验证。

为什么这章比模型本身还重要:一个模型再花哨,如果我用错了尺子去量,就会自信地把烂模型推上线、把好模型误杀。两类典型翻车:一是被单一指标骗——只看准确率,没发现它在关键的少数类上全错(垃圾邮件、癌症筛查、欺诈检测,少数类才是要抓的);二是自己给自己打分——用训练过的数据评估,分数虚高,一上线就现原形(过拟合的表现)。这一章就是给我一套"审判模型"的工具和纪律,让我的判断可信。这套思维,和应用工程 A06 评估 LLM 是同一种科学精神。

先看那个最常见、最坑人的陷阱:唯准确率论。

7准确率的陷阱

准确率 = 判对的样本占比。它在类别不平衡时会严重误导:如果 99% 的样本是同一类,一个"永远猜多数类"的废物模型准确率就有 99%——数字很漂亮,却对真正要抓的那 1% 毫无用处。

现实里最重要的问题往往天然不平衡:垃圾邮件是少数、欺诈交易是少数、癌症患者是少数——而这些少数恰恰是我最想抓住的。这时准确率就成了糖衣:模型只要"随大流全判多数类"就能刷出高分,却把关键的少数类全漏了。所以看到高准确率,第一反应应该是警惕:它是不是把少数类的错误藏起来了?要拆穿它,得把"判对/判错"按类别摊开看——这就是混淆矩阵。

拆穿准确率的工具,是一张四格表。

8混淆矩阵:一切指标的源头

混淆矩阵把预测结果摊成四格:真的正、判成正(TP);真的负、判成正(FP,误报);真的正、判成负(FN,漏报);真的负、判成负(TN)。所有分类指标都是从这四个数算出来的。

记住两个"错"最关键:FP(误报)= 把好的当坏的抓了(把正常邮件扔进垃圾箱、把好人当欺诈拦下);FN(漏报)= 把坏的放过了(垃圾邮件溜进收件箱、真欺诈没拦住)。不同场景里这两种错的代价天差地别:垃圾邮件过滤最怕 FP(误删重要邮件),癌症筛查最怕 FN(漏诊)。准确率把这两种错混在一起、还被大量的 TN 稀释,所以看不清;混淆矩阵把它们分开摆出来,我才知道模型到底错在哪、错得起不起。先看混淆矩阵,再谈任何单一指标——这是评估分类模型的第一动作。

从四格里,拆出最实用的两个指标。

9精确率与召回率

精确率precision=在"判为正"的里面,有多少真的是正(抓得准不准);召回率recall=在"真的是正"的里面,有多少被抓回来了(抓得全不全)。两者常此消彼长,F1 是它们的调和平均,给一个折中的单数。

用垃圾邮件记:精确率高=我扔进垃圾箱的,基本都真是垃圾(很少误删好邮件,FP 少);召回率高=真正的垃圾邮件,基本都被我拦住了(很少漏网,FN 少)。它俩通常拉扯:我把判定标准放宽(逮住更多垃圾,recall↑),就容易误伤好邮件(precision↓);反之收紧标准,precision↑ 但会漏掉一些 recall↓。选哪个看代价:癌症筛查要 recall 高(宁可多召回去复查,绝不能漏诊 FN);垃圾拦截要 precision 高(宁可放过几封垃圾,也别误删老板的邮件 FP)。拿不准就看 F1(precision 和 recall 都高时才高)。这直接续上 D02 的"阈值不是铁律"——调阈值,本质就是在 precision 和 recall 之间滑动。

不想只盯一个阈值?ROC/AUC 给我全景。

10ROC / AUC:阈值的全景

ROC 曲线把阈值从严到松滑一遍,画出"抓得全(召回)"与"误报率"如何此消彼长的整条曲线;AUC(曲线下面积)用一个 0~1 的数概括模型整体的分辨能力:越接近 1 越强,0.5 相当于瞎猜。

为什么有用:precision/recall 是某一个阈值下的表现,而 ROC 一次性展示所有阈值下的权衡——让我看清"这个模型在各种松紧设定下都表现如何",再据此挑一个合适的工作点。AUC 则把整条曲线压成一个数,方便快速比较两个模型谁整体更能分(且不受阈值和类别比例影响,常用于不平衡数据)。直觉解读:AUC=0.9 意思约等于"随便拿一个正样本和一个负样本,模型给正样本打更高分的概率是 90%"。用法:比较模型整体能力看 AUC;真要上线定一个阈值,回到 precision/recall 按业务代价选。

最后,也是最容易被忽视的:在哪份数据上打分。

11验证纪律:别用训练集打分

铁律:永远在模型"没见过"的数据上评估。基本做法是把数据切成训练 / 验证 / 测试三份——训练集学、验证集调参和选模型、测试集最后只用一次报告真实水平。更稳的是交叉验证:轮流拿不同片段当验证,取平均,少受"恰好切得好/坏"的运气影响。

为什么必须如此:用训练过的数据评估,等于开卷考自己出的题,分数虚高、毫无参考价值(过拟合的模型尤其能骗我)。交叉验证(K 折)把数据分成 K 份,每次留一份当验证、其余训练,轮 K 次取平均——既充分利用数据,又让评分更稳。超参搜索(网格搜索/随机搜索)则在交叉验证的框架里,自动试很多组参数(如树的深度、正则强度)挑最好的。还有个隐形杀手叫数据泄露:不小心让"未来的信息"或"测试集的信息"渗进训练(比如在划分前就对全量数据做标准化、或用了含答案的特征),会让离线分数好得离谱、上线却崩——务必先划分、再在训练集上拟合预处理。这套纪律,就是让我的评估数字"上线后还作数"的保证。

把这套评估落到代码:一份报告 + 交叉验证 + 调参。

12组装:科学地评估一个模型

scikit-learn 把这套流程收得很顺——一份分类报告看清各指标,交叉验证 + 网格搜索科学选参:

evaluate.pypython
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split, cross_val_score, GridSearchCV
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import classification_report, confusion_matrix

X, y = load_breast_cancer(return_X_y=True)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.2, random_state=0)   # ⑪ 先划分

clf = RandomForestClassifier(random_state=0).fit(X_tr, y_tr)
pred = clf.predict(X_te)

print(confusion_matrix(y_te, pred))          # ⑧ 四格:先看错在哪
print(classification_report(y_te, pred))     # ③ 精确率/召回率/F1 一次看全

# ⑪ 交叉验证:不靠一次划分的运气,看平均 + 波动
scores = cross_val_score(clf, X_tr, y_tr, cv=5, scoring="f1")
print("5 折 F1:", scores.mean().round(3), "±", scores.std().round(3))

# ⑪ 超参搜索:在交叉验证框架里自动挑最佳参数
grid = GridSearchCV(RandomForestClassifier(random_state=0),
                    {"n_estimators": [100, 300], "max_depth": [None, 5, 10]},
                    cv=5, scoring="f1").fit(X_tr, y_tr)
print("最佳参数:", grid.best_params_, " 最佳 F1:", grid.best_score_.round(3))

逐块对照:confusion_matrix 先摊开四格看错在哪(⑧);classification_report 一次给出每类的精确率/召回率/F1(③),比单看准确率诚实得多;cross_val_score(..., cv=5) 用 5 折交叉验证给出平均分和波动(⑪,±后面的数越小越稳);GridSearchCV 在交叉验证里自动试参数组合、挑最佳(⑪)。关键纪律:train_test_split 一开始就把测试集隔离,调参全程只在训练集内的交叉验证上做,测试集留到最后report一次——这样报出的分数才"上线后还作数"。

进阶挑战

改改看

①把 scoring 从 "f1" 换成 "precision" 和 "recall",看最佳参数会不会变——体会"用什么尺子,就选出什么模型"。②人为制造不平衡(只留 5% 的正类),对比"准确率"和"F1/召回率"谁还看得出模型好坏。③用 roc_auc_score(y_te, clf.predict_proba(X_te)[:,1]) 算 AUC。④故意在 train_test_split 之前对全量数据做标准化,想想这为什么算数据泄露、会带来什么假象。

15自测 · 思考题

  1. 陷阱。为什么 99% 准确率可能是废物模型?
    参考答案

    数据不平衡时(99% 一类),"全猜多数类"就有 99% 准确率,却漏掉全部要抓的少数类。

  2. 两种错。FP 和 FN 分别是什么、各怕在什么场景?
    参考答案

    FP 误报=好的错抓(垃圾过滤最怕,误删好邮件);FN 漏报=坏的放过(癌症筛查最怕,漏诊)。

  3. P vs R。精确率和召回率各答什么问题?
    参考答案

    精确率:判为正的里多少真对(准不准);召回率:真的正里抓回多少(全不全)。常此消彼长,F1 折中。

  4. 验证。为什么不能用训练集打分?交叉验证好在哪?
    参考答案

    训练集打分是开卷考自己出题,虚高。交叉验证轮流留验证取平均,更稳、少受切分运气影响。
