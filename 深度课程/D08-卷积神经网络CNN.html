卷积神经网络 CNN

D07 给了我一台训练发动机——那个五步循环。这一章只做一件事:把循环里的"模型"换成一个会"看"图像的网络,训练循环一字不改。为什么图像要专门的网络?因为把图片摊平成一长串数字丢给全连接网络,既参数爆炸、又丢掉了像素之间的空间关系。卷积神经网络(CNN)用一个小窗口滑过整张图、共享同一套权重来提取局部特征,既省参数又保住了空间结构——它是 2012 年引爆深度学习的那类模型,也是我做手写数字识别(P3)要用的网络。

4一句话本质

卷积神经网络:用一个小窗口(卷积核)滑过整张图,用同一套权重在每个位置提取局部特征,再层层堆叠、逐级从"边缘"看到"整体"。它靠"参数共享"和"保留空间结构"两招,把图像识别做得又省又好。

为什么全连接网络对图像不行:一张 1000×1000 的彩色图有三百万个像素,摊平后第一层每个神经元就要三百万个权重,几层下来参数量天文数字——训不动、也极易过拟合。更糟的是,摊平这一下就把"相邻像素本来挨在一起"的空间关系彻底打散了,可图像的意义恰恰藏在空间关系里(眼睛在鼻子上方、边缘是相邻像素的突变)。CNN 的破解办法是:不给每个像素配独立权重,而是设计一个小小的卷积核(比如 3×3),让它滑过整张图的每个位置,在哪儿都用同一套权重——这叫"参数共享",一下把参数从百万级压到几十个。而且它天然按空间局部处理,空间结构完好保留。这就是 CNN 又省参数、又懂图像的秘密。

先看清 CNN 的核心动作:卷积到底在图上做了什么。

7卷积 convolution

拿一个小窗口(卷积核,如 3×3),从图的左上角开始,一格一格滑过整张图;每滑到一处,就把窗口盖住的那 9 个像素和核里的 9 个权重逐个相乘再加起来,得到一个数——所有位置的结果拼成一张特征图。同一个核在每个位置用同一套权重,这就是参数共享。

直觉:一个卷积核就是一个"局部模式探测器"。比如某个 3×3 核的权重排成"左暗右亮",它滑过图时,在有"竖直边缘"的地方就会算出很大的值、在平坦处算出接近 0——于是它输出的特征图,高亮的正是图里所有竖直边缘的位置。一层里通常有很多个核(如 32 个),各自探测不同模式(横边、竖边、某种角、某种纹理),输出 32 张特征图。我不用手工设计这些核里的权重,它们和普通网络的权重一样,是训练时自动学出来的——D07 的循环会帮我学。关键就记两点:局部(每次只看一小块)+ 共享(同一套权重扫全图),前者保住空间结构,后者把参数压到极小。

卷积之后,通常紧跟一个"缩小图"的动作:池化。

8池化 pooling

池化就是下采样(缩小尺寸):把特征图按小块(如 2×2)分组,每块只留一个代表值——最常用最大池化(取块内最大值)。作用:让特征图变小(省算力)、保留最强的响应、并让识别对"位置的小移动"更稳健(数字歪一两个像素也不影响)。

为什么取最大值:卷积特征图上,某处值大就代表"这块检测到了那个模式"。2×2 最大池化把每个小块压成"这块里最强的那个响应",尺寸直接减半、算力大降,而"到底有没有这个特征"的信息基本没丢。附带的好处叫平移不变性:即使目标在图里挪动几个像素,最大值往往还落在同一个池化块里,输出几乎不变——所以 CNN 对"数字写偏一点、猫在画面左边还是右边"这类小变化不敏感。池化没有需要学的参数,就是个固定的缩小操作。卷积(提特征)+ 池化(缩尺寸)常常成对出现,反复叠加。

把卷积+池化叠很多层,会发生一件神奇的事:特征逐级变抽象。

9感受野与层级特征

越往深层,一个神经元能"看到"的原图范围越大(感受野变大),它检测的模式也越抽象:浅层看边缘和颜色块,中层看纹理和部件(眼睛、轮子),深层看整体(人脸、汽车)。这套"从局部到整体"的层级,是网络自己从数据里学出来的,不用人设计。

为什么会这样:第一层卷积核只看原图的 3×3,只能发现最基础的东西——某个方向的边、某种颜色过渡。第二层的卷积核看的是"第一层的特征图",相当于间接看到了原图更大的一块(感受野变大),于是能把"几条边"组合成"一个角、一段弧";再深一层,又把"角和弧"组合成"眼睛、轮子";最深层把这些部件组合成"完整物体"。这正呼应 第 1 章说的"深度学习自己逐层提炼特征"——CNN 把这句话变成了看得见的图像层级。这也是为什么 CNN 需要"深"(多层):层数给了它从边缘一路搭到整体的台阶。

把这些零件按顺序摆好,就是一个能分类的完整 CNN。

10一个完整 CNN 的结构

典型结构:[卷积 → 激活 → 池化] 反复几组(负责"提特征、缩尺寸"),最后把特征图摊平、接一两层全连接(负责"根据特征做分类")。前半段是 CNN 特有的"看图"部分,后半段和第 7 章的普通网络一样。

为什么这样分两段:前半段的卷积+池化,把一张大图逐步浓缩成一小叠"高层特征图"(比如从 28×28 缩到 7×7、但通道从 1 变成 64)——这时每个数字都不再是原始像素,而是"这里有没有某个高层部件"的强弱。到这一步,识别任务就退化成了 第 7 章那种"给定一组特征、判断是哪一类"的普通分类,于是把特征图摊平、接全连接层,最后用 D02 的 softmax 输出各类别的概率。整套东西从头到尾就是一串层,照样丢进 D07 的五步循环去训练。下一节把它写成代码。

把结构落成 PyTorch 代码,套进 D07 的循环——这就是手写数字识别器。

11组装:一个识别手写数字的小 CNN

下面用 PyTorch 搭一个小 CNN(识别 28×28 的手写数字,10 类)。注意:训练它,就是把这个 model 塞进 D07 那段五步循环,其余一字不改:

small_cnn.pypython
import torch.nn as nn

class SmallCNN(nn.Module):
    def __init__(self):
        super().__init__()
        # 前半段:卷积 + 激活 + 池化,负责"看图、提特征"
        self.features = nn.Sequential(
            nn.Conv2d(1, 16, kernel_size=3, padding=1),  # 1 通道(灰度)→ 16 张特征图
            nn.ReLU(),
            nn.MaxPool2d(2),                             # 28×28 → 14×14
            nn.Conv2d(16, 32, kernel_size=3, padding=1), # 16 → 32 张特征图
            nn.ReLU(),
            nn.MaxPool2d(2),                             # 14×14 → 7×7
        )
        # 后半段:摊平 + 全连接,负责"根据特征分类"(和第 7 章一样)
        self.classifier = nn.Sequential(
            nn.Flatten(),               # 32×7×7 摊成一长串
            nn.Linear(32 * 7 * 7, 128),
            nn.ReLU(),
            nn.Linear(128, 10),         # 10 个输出 = 10 个数字类别
        )

    def forward(self, x):
        x = self.features(x)            # 先看图
        return self.classifier(x)       # 再分类

model = SmallCNN()
# 训练:把这个 model 放进 D07 的五步循环即可,损失用 nn.CrossEntropyLoss()(分类)

逐块对照第 10 节:self.features 就是"[卷积→ReLU→池化]×2",把 1×28×28 的图浓缩成 32×7×7 的高层特征;self.classifier 把它摊平、接全连接,输出 10 个类别分数。nn.Module 是 PyTorch 里"自定义模型"的标准写法:__init__ 里定义有哪些层,forward 里写数据怎么流过它们。训练时,损失换成分类专用的 nn.CrossEntropyLoss()(D02 的交叉熵),其余 D07 五步一字不改。这就是项目 P3——我现在有了它的全部零件。

进阶挑战 · 上手做 P3

训练一个真的手写数字识别器

①用 torchvision.datasets.MNIST 下载手写数字数据集(一行代码),用 DataLoader 切批。②把上面的 SmallCNN 塞进 D07 的五步循环,损失用 CrossEntropyLoss,训练几个 epoch。③在测试集上算准确率(D05),小 CNN 通常能到 98%+。④拿掉两个池化层看准确率和训练速度怎么变,体会池化的作用。跑通它,我就完成了项目 P3、也真正"训练"出了一个能看图的网络。

14自测 · 思考题

  1. 为什么不摊平。图像为什么不直接摊平喂全连接网络?
    参考答案

    两点:①参数爆炸(每像素一套权重,百万级);②摊平打散了像素的空间关系,而图像意义正藏在空间结构里。CNN 用局部连接+参数共享解决。

  2. 卷积做了什么。一句话说清卷积在图上的动作。
    参考答案

    一个小窗口(核)滑过整张图,每处把窗口内像素与核权重相乘求和得一个值,拼成特征图;同一套权重扫全图(参数共享),权重由训练学出。

  3. 池化的作用。最大池化有哪些好处?
    参考答案

    缩小尺寸省算力、保留每块最强响应、带来对小位移的稳健(平移不变性)。它没有可学参数。

  4. 层级特征。为什么说"浅层看边缘、深层看整体"?
    参考答案

    越深的层感受野越大、看到的原图范围越大,于是把浅层的边组合成部件、再组合成整体——网络自动学出从局部到整体的层级。
