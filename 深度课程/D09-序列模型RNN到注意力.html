序列模型:RNN 到注意力

CNN 让网络学会处理有空间结构的数据(图像)。但还有一大类数据是按顺序展开的:一句话里的词、一段时间的股价、一串语音——它们的意义藏在"先后顺序和前后依赖"里(把"我不喜欢它"打乱就全变味了)。这一章讲怎么处理这类序列数据:先看 RNN(循环神经网络)怎么"带着记忆"一个一个地读,再看它撞上了什么墙,以及为什么它最终被注意力机制取代。这是全 Track B 最关键的转折——注意力,正是通向大模型(Track C)的那道门。

图解骨架约 30 分钟,精读约 3~5 小时。这一章重"直觉和脉络"胜过"代码细节"——注意力的逐步手算留到 Track C 的 D14,这里先把"它解决了什么、凭什么赢"想透。

读完这一章,我脑子里会立起来的骨架

  • 序列数据——顺序本身就是信息,不能像图像那样随便处理
  • RNN——带着一个"记忆"(隐状态)逐个读词,把前文信息一路带下去
  • RNN 的两堵墙——长依赖记不住(梯度消失)、只能串行、跑得慢
  • 注意力 attention——一步看全序列,按"相关度"给每个词加权,想看谁看谁
  • 从 RNN 到 Transformer——注意力取代循环,为什么是一次范式革命

4一句话本质

处理序列有两条路:RNN 像人读书——从左到右一个字一个字读,脑子里存一份"记忆"(隐状态)边读边更新;注意力像开卷答题——处理某个词时,一步就能回头扫全篇、按相关度只挑重要的几处重点看。注意力用"直接连接任意两个位置"甩开了 RNN 的两堵墙,成了大模型的地基。

为什么序列特殊:图像可以整张一起看,但序列的意义依赖顺序和距离——"下雨了所以我带了伞"里,"带伞"要依赖很前面的"下雨"。处理它,得有办法把"前面的信息"带到"后面"。RNN 的办法是"接力棒":存一份记忆,读一个词就更新一次,把浓缩的前文一路传下去。这很符合直觉,但接力棒传得越远、早期信息越容易被冲淡(第 8 节)。注意力换了个思路:干脆让每个词都能直接去看序列里任意其他词,不用接力——谁相关就重点看谁。这一下解决了"传太远记不住",还因为"所有词可以同时算"而能大规模并行、训得飞快。这两点,把它推上了大模型的王座。

先说清楚:为什么序列数据要特殊对待。

7序列数据:顺序就是信息

序列 = 一串按顺序排列、且顺序有意义的数据:句子(词的序列)、股价(时间点的序列)、语音(声音帧的序列)。它和图像的关键区别是:处理它必须尊重顺序、并且能把"前面的信息"带到"后面"——因为一个词的含义常常依赖它前面(甚至很前面)的词。

两个直觉:顺序不能乱。"猫追狗"和"狗追猫"用的词一模一样,意思却相反——顺序本身携带信息,这是序列区别于"一袋子特征"的根本。依赖可能很长。"我在法国长大,……(中间一大段),所以我说一口流利的法语"——要正确填出"法语",模型得记住很前面的"法国"。所以处理序列的模型,核心考验就是:能不能把远处的相关信息,准确地带到当前位置。RNN 和注意力,就是对这个考验给出的两种不同答卷。

第一种答卷,最符合"人怎么读书"的直觉:RNN。

8RNN:带着记忆逐个读

RNN(循环神经网络)像人从左到右读句子:维护一份隐状态(hidden state)当"记忆",每读入一个词,就把"这个词 + 上一刻的记忆"揉在一起、更新出新的记忆,一路传下去。到句尾,这份记忆就浓缩了整句的信息。LSTM/GRU 是 RNN 的改良版,专门为了"记得更久"。

把它想成传接力棒:每个位置做一次相同的运算——输入"当前词 + 手里的棒(旧记忆)",输出"新的棒(新记忆)",再递给下一个位置(见图 2)。这样前文信息就顺着接力一路带到后面。它天然尊重顺序(必须从左往右一个个来),也确实能处理任意长的序列。但接力有个毛病:传得越远,早期信息越容易被后来的一次次更新冲淡、稀释——句子一长,开头的"法国"传到结尾常常就模糊了。这就是下一节的第一堵墙。LSTM(长短期记忆网络)加了几道"门"来决定"记什么、忘什么",能明显记得更久,是深度学习早期处理文本、语音的主力。

RNN 的接力棒,撞上了两堵怎么也绕不过的墙。

9RNN 的两堵墙

墙一:长依赖记不住。信息靠接力一路传,传得越远越模糊(专业叫"梯度消失"),句子一长开头就忘了——LSTM 缓解但没根治。墙二:只能串行、慢。必须读完第 1 个词才能读第 2 个,天生没法并行,数据一大训练就慢得让人绝望。

这两堵墙都源自"接力"这个机制本身。墙一:每传一步,早期信息就被揉进一次新运算、稀释一点,传几十步后几乎荡然无存;反过来训练时,误差要沿着这条长链一路传回开头去调参数,信号越传越弱(梯度消失),开头的参数几乎学不动。墙二更致命于"大规模":GPU 的威力在于并行,可 RNN 规定"第 t 步必须等第 t−1 步算完",这条串行链把并行的门堵死了——训练一个大语料上的大模型,慢到不可接受。业界急需一种"既能连接任意远的位置、又能大规模并行"的机制。2017 年,注意力给出了答案。

答案:不接力了,让每个词直接去看它想看的任何词。

10注意力 attention

注意力的思路:处理某个词时,让它一步就"看"到序列里所有词,并给每个词打一个"相关度"分,然后按分数加权地把它们的信息汇总过来——相关的重点看、无关的几乎不看。没有接力、没有距离衰减:任意两个词都是"直接连接"。而且所有词可以同时算,天生适合 GPU 并行。

一个直观例子:理解"它"指代谁——"猫抓老鼠,因为它饿了"。人读到"它"会自动回看,判断"它=猫"。注意力做的就是这件事:处理"它"时,给"猫""老鼠"等每个词算一个相关度,发现"猫"最相关(权重最大),于是把"猫"的信息重点汇进"它"的表示里(见图 3)。这套机制里有三个角色——Query(我在找什么)、Key(每个词的标签)、Value(每个词的内容):用"我的 Query"去和"各词的 Key"比对算出相关度,再按相关度加权汇总各词的 Value。这里只需记住"按相关度加权、想看谁看谁"这个直觉;Q/K/V 到底怎么相乘、怎么归一化,留到 Track C 的 D14 一步步手算。关键是:它一举打穿 RNN 的两堵墙——任意距离直连(不再健忘)、全部并行(不再慢)。

把注意力堆起来、彻底扔掉接力棒,就得到了 Transformer——大模型的地基。

11从 RNN 到 Transformer

2017 年一篇论文《Attention Is All You Need》做了件狠事:把 RNN 的循环结构整个拿掉,只用注意力(加一些前馈层)堆成网络——这就是 Transformer。它任意距离直连、可大规模并行,于是能在海量文本上训练出超大模型。今天所有大语言模型(GPT、Claude)都是 Transformer。

一张表把两条路看清:

表 1 · RNN vs 注意力(Transformer)
维度RNN / LSTM注意力 / Transformer
怎么传信息接力棒(逐步传记忆)任意两词直接连接
长依赖传远了会忘(梯度消失)再远也是"一步直达"
能否并行不能,必须串行能,全部同时算(GPU 友好)
训练大模型慢,难以扩大快,能堆到千亿参数
今天的地位基本退居特定小场景所有大语言模型的地基

需要提醒的是:注意力也不是没有代价。"每个词都看所有词",计算量随序列长度平方增长——序列一长就很贵,这也是"上下文窗口有上限"的根源之一(D17 会讲省钱的办法)。但瑕不掩瑜:能并行、能连长依赖这两条,让它成了大模型时代的绝对主角。至于注意力内部 Q/K/V 到底怎么算、Transformer 一整块长什么样——那正是 Track C 的内容,我现在已经站在它的门口了。下面给一段"RNN 长这样"的代码,让我对序列模型代码有个手感;真正的注意力代码留到 Track C。

rnn_glance.pypython
import torch
import torch.nn as nn

# 一个最简单的序列模型:LSTM(RNN 的改良版)+ 一个分类头
# 例:输入一句话(词向量序列),判断它是好评还是差评
class TextClassifier(nn.Module):
    def __init__(self, vocab_size, embed_dim=64, hidden=128, num_classes=2):
        super().__init__()
        self.embed = nn.Embedding(vocab_size, embed_dim)   # 词 → 向量(第 8 章)
        self.lstm  = nn.LSTM(embed_dim, hidden, batch_first=True)  # 带记忆逐个读
        self.head  = nn.Linear(hidden, num_classes)        # 用最后的记忆做分类

    def forward(self, x):                # x: 一批句子(每句是词编号序列)
        e = self.embed(x)                # 每个词变成向量
        out, (h, c) = self.lstm(e)       # LSTM 一路读完,h 是最后的"记忆"
        return self.head(h[-1])          # 拿最后记忆分类

model = TextClassifier(vocab_size=10000)
# 训练它?还是 D07 那五步循环,损失用 CrossEntropyLoss——一字不改

13常见误区 · 实际情况

表 3 · 五个常见误区
我可能以为实际情况
RNN 已经没用、不必了解它是理解"为什么会有注意力"的必要台阶;在小型/流式场景仍有用武之地。

14自测 · 思考题

  1. 序列为何特殊。为什么序列数据不能像图像那样处理?
    参考答案

    顺序本身是信息("猫追狗"≠"狗追猫"),且含义常依赖很远的前文,必须能把前面的信息准确带到后面。

  2. RNN 的记忆。RNN 靠什么把前文带到后面?
    参考答案

    隐状态(记忆):每读一个词,用"当前词+上一刻记忆"更新出新记忆,像接力棒一路往后传。

  3. 两堵墙。RNN 的两个致命短板是什么?
    参考答案

    ①长依赖记不住(传远了被稀释=梯度消失);②只能串行、无法并行,训练大模型太慢。

  4. 注意力凭什么赢。注意力用哪两点甩开 RNN?
    参考答案

    ①任意两词直接连接(不接力,再远也一步直达,不健忘);②所有词同时算,可大规模并行(GPU 友好、能训超大模型)。
