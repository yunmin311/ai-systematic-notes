迁移学习与微调

前四章我学会了从零训练并调好一个深度模型。但现实很骨感:好模型往往要几百万张标注数据 + 一堆 GPU 训好几天,而我手头常常只有几百张图、一块普通显卡。这一章讲破局之道——不从零训,站在别人训好的大模型肩膀上:拿一个在海量数据上预训练好的模型,借用它已经学会的通用特征,只用我的一点点数据"微调"出自己的模型。这是今天绝大多数深度学习项目的真实做法,也正是"拿开源大模型微调出专用助手"(Track C)背后同一个思想。学完它,Track B 深度学习就全通了。

图解骨架约 25 分钟,动手约 3~4 小时。核心就一句话:别人训好的特征,拿来直接用。这一章教我怎么用、以及"冻多少、调多少"怎么定。

读完这一章,我脑子里会立起来的骨架

  • 为什么不从零训——数据不够、算力不够、也没必要
  • 预训练模型——别人在海量数据上训好、学到了通用特征
  • 特征复用(冻结)——把预训练模型当"现成的特征提取器"
  • 微调 fine-tuning——解冻部分层,用小学习率在我的数据上继续训
  • 怎么选策略——数据量 × 相似度,决定"冻多少、调多少"
从哪来 · 到哪去

接前面:用的还是 D07 的训练循环 + D10 的调参技巧,只是模型换成"预训练模型 + 新头";复用"浅层学通用特征"续 D08。通向后面:这正是 Track C 里"拿预训练大语言模型微调"(D16)的同一套思想,只是从图像换成了文本、规模更大。

  • 想做一个实际的图像/文本任务,但数据只有几百上千条的人。

4一句话本质

迁移学习:把一个在海量数据上训好的模型,当作我任务的起点,而不是从随机权重从头学。因为它前面那些层学到的"边缘、纹理、形状"等特征是通用的——我只需在这个坚实的地基上,用自己的一点点数据,把最后判断的部分改造成我要的。省数据、省算力、效果还常常更好。

为什么行得通:D08 讲过 CNN 是"浅层看边缘、深层看整体"。一个在 ImageNet(上百万张图、一千个类别)上训好的模型,它浅层学到的边缘/纹理/颜色探测器,对任何图像任务都通用——不管我要认的是猫狗、皮肤病还是零件缺陷,第一步都得先看边缘和纹理。既然别人已经用海量数据把这些通用特征学得又好又稳,我何必用自己那几百张图从零重学一遍(还多半学不好、极易过拟合)?聪明的做法是借用:保留它学好的特征层,只把最后"做最终判断"的那一小块换成我的任务专属、用我的数据训。这就是迁移学习省数据、省算力还效果好的根源。文本领域完全同理——大语言模型就是在海量文本上"预训练"出通用语言能力,再微调到具体任务(Track C)。

7为什么不从零训

从零训练一个好模型有三道坎:要海量标注数据(几十万起,我多半没有)、要大量算力(训好几天的 GPU,我多半租不起)、还极易过拟合(数据少、参数多,模型直接背答案)。迁移学习一次绕过这三坎:通用特征别人已经替我学好了,我只补最后一小步。

算笔账就懂了:一个像样的图像模型有几千万参数,要把它们从随机值学到位,需要的数据量和算力都是天文数字——这是大公司才玩得起的游戏。而我的真实任务(认某种零件缺陷、分某类医学影像)往往只有几百到几千张标注图。用这么点数据从零训一个大模型,结果必然是灾难性过拟合:训练集背得滚瓜烂熟、新数据一塌糊涂(D10)。迁移学习把问题重新框定:我要学的不是"从像素到答案的一切",而只是"在别人已经提炼好的高层特征之上,做我这个任务的最后判断"——这一步需要的数据和算力,就小得多、也现实得多。

巨人是谁:预训练模型到底是什么。

8预训练模型

预训练模型 = 别人已经在某个大数据集上训练好、并公开权重的模型。图像界的经典是在 ImageNet(128 万张图、1000 类)上训好的 ResNet 等;文本界就是在海量网页文本上训好的大语言模型。它们的前面几层学到了通用的低/中层特征,这些特征换个任务照样有用——这正是能"迁移"的原因。

关键要理解"它带来的是什么":一个 ImageNet 预训练模型,浅层是一堆训练好的边缘/纹理/颜色探测器,中层是形状/部件探测器,深层才是"这是不是某个 ImageNet 类别"的判断。前两部分(通用特征)对我几乎任何图像任务都直接可用;只有最深那部分(专为 ImageNet 的 1000 类做判断)和我的任务无关,需要替换。所以迁移的标准动作是:保留前面的特征层、换掉最后的"分类头"——换成一个匹配我类别数的新层(比如我只分 3 类,就换一个输出 3 的层)。用 torchvision.models.resnet18(weights=...) 一行就能把这样一个巨人搬进来。文本同理:预训练大模型带来的是通用语言理解,我只需在它之上微调出具体任务。

借用有两种深浅:只借不改(冻结),还是借了再改(微调)。

9特征复用(冻结)与微调

两种用法,深浅不同。特征复用(冻结):把预训练模型的特征层冻住(训练时不更新它们),只把它当一个"现成的特征提取器",单独训练我新换的头——快、省、数据少时最稳。微调(fine-tuning):解冻部分(或全部)层,用一个很小的学习率在我的数据上继续训——让通用特征也朝我的任务微调一点,数据够时效果更好。

怎么理解"冻结":把某些层的参数标记为"不参与梯度更新"(requires_grad=False),训练时它们保持预训练学到的值不变,只有我新加的头在学。这样需要学的参数极少,几百张图也能训得稳、还快。微调则更进一步:允许预训练层也被更新,但必须用很小的学习率(如 1e-4 甚至更小)——因为那些权重已经很好了,大步一走就会把学好的特征"抖坏"(灾难性遗忘)。常见的稳妥流程是两段式:先冻结、只训新头几轮让它站稳,再解冻、用小学习率整体微调几轮精修。到底冻多少、要不要微调,取决于下一节的两个因素。

冻多少、要不要微调,由两个因素定,一张表说清。

10怎么选策略:数据量 × 相似度

两个问题定策略:我的数据有多少?我的任务和预训练数据像不像? 数据少 + 很像 → 只训新头(冻结全部特征层);数据多 + 不太像 → 微调更多层甚至全部。核心权衡:数据越少越要多冻(防过拟合),任务越不像越要多调(通用特征不够用)。

四种情形:数据少 + 相似(如少量猫狗图,ImageNet 里就有猫狗)——最省心:冻结全部特征层,只训一个新头。数据少 + 不相似(如少量医学影像)——两难:数据少不敢大改,但特征又不太对口;折中办法是冻住浅层(通用边缘纹理仍有用)、只微调靠后几层 + 新头。数据多 + 相似——可以微调整个网络,用小学习率,效果通常最好。数据多 + 不相似——微调全部、甚至考虑训练更久;数据够多时迁移带来的主要是"更好的起点、更快收敛"。一个万能起手式:先全冻、只训头看个基线,再逐步解冻靠后的层观察验证集有没有变好——简单、安全、可控。

11组装:加载 ResNet、换头、微调

下面用 torchvision 的预训练 ResNet18 做迁移:冻住特征层、换掉最后的分类头成我的 N 类,只训这个头。训练?还是 D07 那五步:

transfer_resnet.pypython
import torch
import torch.nn as nn
from torchvision import models

# 1. 加载预训练模型(一行搬来"巨人")
model = models.resnet18(weights=models.ResNet18_Weights.DEFAULT)

# 2. 冻结所有特征层:标记为不更新(特征复用)
for p in model.parameters():
    p.requires_grad = False

# 3. 换掉最后的分类头:原来输出 1000 类 → 换成我的 N 类
num_classes = 3                      # 假设我只分 3 类
model.fc = nn.Linear(model.fc.in_features, num_classes)
# 新换的 fc 层默认 requires_grad=True,所以只有它会被训练

# 4. 优化器只优化"需要更新的参数"(也就是新头),用小学习率
optimizer = torch.optim.Adam(
    [p for p in model.parameters() if p.requires_grad], lr=1e-3)
loss_fn = nn.CrossEntropyLoss()

# 5. 训练:还是 D07 的五步循环(此处略),只训新头,几百张图也能训得又快又好
# 想进一步微调?把第 2 步部分层改回 requires_grad=True、再用更小的 lr=1e-4 续训

逐块对照本章:第 1 步 resnet18(weights=...) 把"巨人"搬来(第 8 节);第 2 步 requires_grad=False 就是"冻结"(第 9 节),让特征层保持预训练的值;第 3 步换 model.fc 就是"换头"(图 2),输出改成我的类别数;第 4 步优化器只收 requires_grad=True 的参数——也就是只训新头,又快又稳。要从"特征复用"升级成"微调",只需把靠后几层解冻、再用更小的学习率续训(第 9 节的两段式)。就这么几行,我就用几百张图和一块普通显卡,站上了别人几百万张图训出来的肩膀。

14自测 · 思考题

  1. 为什么不从零训。说出从零训的三道坎。
    参考答案

    要海量标注数据、要大量算力、且数据少时极易过拟合。迁移学习靠借用通用特征一次绕过这三坎。

  2. 为什么能迁移。预训练模型的什么东西是"通用、可迁移"的?
    参考答案

    浅/中层学到的通用特征(边缘、纹理、形状),换个图像任务照样有用;只有最深的任务专属分类头需要替换。

  3. 冻结 vs 微调。两者区别?微调为什么要小学习率?
    参考答案

    冻结=特征层不更新、只训新头(数据少时稳);微调=解冻部分层继续训。小学习率是因为预训练权重已很好,大步会破坏学好的特征(灾难性遗忘)。

  4. 选策略。数据很少但任务和预训练不太像,该怎么做?
    参考答案

    冻住浅层(通用边缘纹理仍有用),只微调靠后几层 + 新头;并配好正则化(D10)防过拟合。
