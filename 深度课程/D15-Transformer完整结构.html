Transformer 完整结构

D14 把注意力这块发动机拆开算过了。但发动机不等于整车:真实的 Transformer 在注意力外面还套了三样必需品——前馈层(每个位置各自再想一想)、残差连接和层归一化(让几十层能训得动)。这四件拼成一个块(block),再把块堆几十层,前面接 Embedding、后面接一个输出层,就是 GPT 的完整骨架。这一章把它装起来,并逐块读懂论文里那张著名的结构图。

图解骨架约 30 分钟,精读 + 动手约 4~5 小时。读完这一章,再看任何大模型的结构图和参数配置(层数、隐藏维度、头数),都能对上号。

这一章要立起来的骨架

  • 一个块的四件套——多头注意力 + 前馈 + 残差 + 层归一化
  • 前馈层 FFN——注意力负责"交流",前馈负责"各自消化"
  • 残差 + 归一化——深到几十层还能训动的两个关键补丁
  • 堆成模型——N 层块 + 输入嵌入 + 输出层,以及参数量从哪来
  • 三种架构——只用解码器(GPT 类)/ 只用编码器 / 编解码器,各适合什么
从哪来 · 到哪去

接前面:注意力来自 D14;输入向量来自 D13;残差/归一化的动机续 D10(训练稳定性)。通向后面:这副骨架造好后要灌进海量数据才有能力——那是 D16 预训练与 RLHF;它跑起来要花多少钱、怎么变快,是 D17。

4一句话本质

Transformer:把「注意力(词与词交流)+ 前馈(每个词各自消化)」打包成一个块,加上残差和归一化让它能被堆得很深,然后堆 N 层。每往上一层,每个词的表示就被全句信息刷新一次、再自己加工一次;几十层之后,最后那个位置的向量已经浓缩了理解全文所需的一切,拿去预测下一个词。

为什么是"交流 + 消化"这个节奏:注意力擅长横向搬运信息(把相关词的内容汇进来),但它本质是加权平均,表达能力有限——一堆加权平均叠起来还是线性的。前馈层补的正是这一块:它对每个位置单独做一次"放大 → 非线性 → 压回"的变换,给模型真正的非线性拟合能力。于是一层的节奏是:先横着交流一次,再各自纵向想一想。这个"交流—消化"的循环重复几十次,信息就在词与词之间充分混合、逐层抽象——浅层的块处理语法和邻近关系,深层的块处理语义和长程指代,这与 CNN 的层级特征是同一种思想,只是从"局部像素"换成了"全句词元"。

先把一个块拆开看清楚:四件套,固定顺序。

7一个块的四件套

一个 Transformer 块 = 多头注意力 → 残差+归一化 → 前馈层 → 残差+归一化。数据进来先横向交流(注意力),接一次残差和归一化;再纵向各自加工(前馈),再接一次残差和归一化。进去什么形状,出来还是什么形状——所以能一层叠一层。

"形状不变"这一点很关键:每个块的输入是 [词数 × 维度],输出也是 [词数 × 维度],于是可以像搭积木一样无限堆。每一层都在做同一件事,只是参数不同、关注的东西不同。另外注意顺序细节:原论文把归一化放在残差之后(Post-LN),现在主流大模型多改成放在每个子层之前(Pre-LN,即 x + Attn(LN(x)))——因为 Pre-LN 训练更稳、更容易堆到几十上百层。看新模型代码时若发现 LN 位置和论文图不同,不是画错了,是这个改良。

四件套里,前馈层最容易被忽略,但它占了大部分参数。

8前馈层:各自消化

前馈层(FFN)= 对每个位置各自独立做的一个两层小网络:先把维度放大(通常 4 倍),过一次非线性激活,再压回原维度。它不看别的词——横向交流是注意力的活,它只负责把这个位置刚收到的信息加工一遍。

三个要点。一、为什么必需:注意力本质是加权平均,叠再多层表达力也有限;FFN 提供真正的非线性变换(第 7 章的激活函数),模型的"拟合能力"主要来自这里。二、为什么放大 4 倍:先升到更高维空间做变换、再压回来,能表达更复杂的函数——类似先摊开再折叠。三、参数大户:一个块里,FFN 的参数量通常是注意力部分的两倍左右,整个大模型一大半参数在前馈层里。所以谈"这个模型多少 B 参数",主要就是在谈这些前馈矩阵有多大。近年很流行的 MoE(混合专家)正是在这里做文章:准备很多套 FFN(专家),每个词只激活其中一两套——参数总量巨大但每次只算一小部分,这是当下把模型做大又不让推理成本爆炸的主流路子。

还剩两个"补丁"——没有它们,几十层根本训不动。

9残差连接与层归一化

残差连接:把子层的输入原样抄一份加到输出上(输出 = x + 子层(x))。好处是梯度可以顺着这条"高速公路"直接传回浅层,深网络不再因为梯度消失而训不动(D09 说的那堵墙)。层归一化:把每个位置的向量重新拉回"均值 0、方差 1"的规整状态,让每层拿到的数据分布稳定、训练更快更稳。

把残差想成"保底":这一层就算什么都没学好(子层输出接近 0),信息也能原封不动传下去,不会越传越糟——这让"加深"变成一件安全的事,是能从几层堆到上百层的直接原因。层归一化则是 D10 里 BatchNorm 的近亲,区别是它按每个样本自己的那一行做归一化(不跨样本),因此不受批大小影响,更适合长度不一的文本。这两个补丁本身不"学知识",却是深层 Transformer 能训出来的前提——它们是脚手架,不是发动机,但没有脚手架楼盖不起来。

四件套齐了,把它堆起来,顺便看清参数从哪来。

10堆成模型:配置表怎么读

完整模型 = Embedding(D13)+ N 个块 + 输出层。模型卡片上的三个数正好对应:层数 N(堆几个块)、隐藏维度 d(每个词向量多长)、头数 h(每层注意力开几个头)。输出层把最后一层的向量映射回词表大小,softmax 后就是"下一个词的概率表"(第 8 章第 ⑤ 站)。

拿一组典型配置感受一下:早期 GPT-2 小号是 12 层 / 768 维 / 12 头,约 1.2 亿参数;大一些的开源模型常见 32 层 / 4096 维 / 32 头,约 70 亿参数。参数大头在两处:每层的前馈矩阵(约 8d² 每层)和注意力的四个投影矩阵(约 4d² 每层),再加上嵌入矩阵(词表 × d,几万×几千也是上亿)。一个实用的估算:总参数 ≈ 12 × N × d²。用 32 层、4096 维代进去:12×32×4096² ≈ 64 亿,和"7B"这个标称量级对得上。会这个估算,以后看到任何模型的配置,心里就有数了。

同一套积木,有三种搭法,对应三类模型。

11三种架构

只用解码器(decoder-only):带因果掩码、专做"续写下一个词"——GPT、Claude 等所有主流大语言模型都是这一类。只用编码器(encoder-only):双向看全句、擅长理解与分类(BERT 类,也是很多 RAG 里 embedding 模型的底子)。编码器-解码器:一半读原文、一半写译文,适合翻译摘要这类"输入输出成对"的任务(原论文就是这种)。

表 2 · 三种架构对照
架构怎么看句子擅长代表
只用解码器只能看左边(因果掩码)生成、对话、续写GPT / Claude 等主流 LLM
只用编码器双向看全句分类、检索、句向量BERT 及各类 embedding 模型
编码器 + 解码器编码器读全文,解码器带掩码生成翻译、摘要原论文、T5

为什么生成式模型选了"只用解码器":任务本身就是"根据前文写下一个词",不需要一个单独的编码器;而且结构简单、易于扩大规模——事实证明,把 decoder-only 堆大 + 喂海量数据,能力就会持续上涨(这正是 D16 讲的规模化路线)。所以今天用的每一个大模型,几乎都是"带掩码的注意力块堆几十层"这一个东西。

最后用一段代码把整块装出来——真的就这么短。

12组装:一个块 + 一个迷你模型

把四件套写成代码,再堆成一个能预测下一个词的迷你 GPT 骨架。注意它有多短——大模型的复杂在规模和数据,不在结构:

mini_transformer.pypython
import torch
import torch.nn as nn

class Block(nn.Module):
    """一个 Transformer 块:注意力 → 残差归一 → 前馈 → 残差归一(Pre-LN 写法)"""
    def __init__(self, d, heads):
        super().__init__()
        self.ln1  = nn.LayerNorm(d)
        self.attn = nn.MultiheadAttention(d, heads, batch_first=True)  # D14 的四步
        self.ln2  = nn.LayerNorm(d)
        self.ffn  = nn.Sequential(          # 前馈:放大 4 倍 → 非线性 → 压回
            nn.Linear(d, 4 * d), nn.GELU(), nn.Linear(4 * d, d),
        )

    def forward(self, x, mask=None):
        h = self.ln1(x)
        x = x + self.attn(h, h, h, attn_mask=mask, need_weights=False)[0]  # ①+② 残差
        x = x + self.ffn(self.ln2(x))                                      # ③+④ 残差
        return x                            # 形状不变,所以能继续往上堆

class MiniGPT(nn.Module):
    def __init__(self, vocab=50000, d=768, heads=12, layers=12, maxlen=1024):
        super().__init__()
        self.tok = nn.Embedding(vocab, d)          # D13:词 → 向量
        self.pos = nn.Embedding(maxlen, d)         # D13:位置编码
        self.blocks = nn.ModuleList([Block(d, heads) for _ in range(layers)])
        self.lnf = nn.LayerNorm(d)
        self.head = nn.Linear(d, vocab)            # 输出层 → 词表上的分数

    def forward(self, ids):                        # ids: [批, 词数]
        n = ids.shape[1]
        x = self.tok(ids) + self.pos(torch.arange(n, device=ids.device))
        mask = torch.triu(torch.ones(n, n, device=ids.device) * float('-inf'), 1)  # 因果掩码
        for blk in self.blocks:
            x = blk(x, mask)                       # 交流 + 消化,重复 N 次
        return self.head(self.lnf(x))              # softmax 后就是「下一个词的概率表」

m = MiniGPT()
print(sum(p.numel() for p in m.parameters()) / 1e6, "M 参数")   # 约 1.2 亿,和 GPT-2 小号同量级

逐块对照本章:Block 就是图 2 的四件套(两处 x = x + … 正是残差);MiniGPT 里 tok+pos 是 D13,blocks 是堆叠,head 是输出层;triu(…, 1) 那行是 D14 的因果掩码。整个 GPT 骨架不到 40 行——真正难的是后面两章的事:用什么数据、花多少钱训它(D16),以及怎么让它跑得起、跑得便宜(D17)。训练它?还是 D07 那五步循环。

15自测 · 思考题

  1. 四件套。一个块里有哪四个部件、什么顺序?
    参考答案

    多头注意力 → 残差+层归一化 → 前馈层 → 残差+层归一化。进出形状相同,故可堆叠。

  2. 前馈层。有了注意力为什么还要它?
    参考答案

    注意力是加权平均、表达力有限;FFN 对每个位置单独做"放大→非线性→压回",提供真正的非线性拟合能力,并且是参数大头。

  3. 两个补丁。残差和层归一化各解决什么?
    参考答案

    残差:给梯度一条高速公路、保底不丢信息,让深堆变安全;层归一化:稳定每层输入分布,训练更快更稳(按每个样本自己归一,不跨批)。

  4. 配置表。"32 层 / 4096 维 / 32 头"什么意思?参数量大概多少?
    参考答案

    堆 32 个块、词向量 4096 维、每层 32 个注意力头。按 12Nd² 估算:12×32×4096²≈64 亿,即 7B 量级。
