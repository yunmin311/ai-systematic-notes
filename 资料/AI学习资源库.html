AI 学习资源库 · 策展

这不是链接堆,是一份筛过的清单:全网公认最好的免费资源,按「怎么用」分层。每章的「外链策展」都从这里取料;也能直接拿它当地图,自己挑一条主线走。

怎么用这份清单

先看②可视化建直觉 → 选③里一条系统课从头跟 → ④免费书当字典深挖 → ⑤官方文档动手查 → ⑥论文留到以后。不要贪多:一条主线走完,胜过十个网站各看两页。

所有链接于 2026-08-16 核实在线;死了就记住名字搜一下。会过时的(具体模型/跑分)只住在链接里,换掉链接即可。

1可视化 · 交互(设计背景先看这些)

抽象概念先靠图和动画建立直觉,再去啃系统课。这一档最适合设计背景。

  • 3Blue1Brown · 深度学习系列视频 · 入门 · 天花板

    神经网络、梯度下降、反向传播、GPT、注意力,全用动画讲。本课程 06/07/08 的默认主线,几乎必看。B 站有中文字幕。

  • StatQuest(Josh Starmer)视频 · 单概念讲透

    手绘讲每一个机器学习/统计概念,「我终于看懂了」的最高频推荐。挑「Machine Learning Fundamentals」列表。

  • R2D3 · 机器学习可视化入门交互 · 入门

    用滚动动画讲决策树怎么从数据学出规律,全网最美的 ML 入门可视化,专治「过拟合」这种抽象词。

  • Jay Alammar · Illustrated 系列图解 · 进阶

    The Illustrated Transformer / GPT-2,MIT、Cornell 课程都在用的图解经典。看懂 Transformer 结构靠它。

  • Distill.pub交互 · 进阶

    用可交互图讲机器学习研究(t-SNE、特征可视化、动量等)。做得极精,适合想真懂一个点时深读。

  • Setosa · Explained Visually交互 · 入门

    PCA、马尔可夫链、图像卷积核……每个都能拖着玩,把硬概念变得可摸。

  • Seeing Theory(布朗大学)交互 · 概率统计

    概率与统计的可视化入门,机器学习的数学底子。想补统计直觉看它。

  • TensorFlow Playground交互 · 动手

    浏览器里拖一个神经网络实时训练,加层、改激活,看决策边界变化。玩十分钟胜过读半天。

  • ML-Tokyo · 交互工具合集聚合 · 索引

    一大批 ML/DL/数学交互工具的清单,上面几个不够时来这里翻。

2系统课程(选一条主线从头跟)

建完直觉,挑一条从头到尾跟完。别混着跳。

  • Andrej Karpathy · Neural Networks: Zero to Hero视频+代码 · 进阶 · 极力推荐

    从零手写:自动求导 → 语言模型 → 分词器 → 一个能跑的 GPT,每行都讲。现代 AI 教育里最受推崇的免费资源,深度课程 D 段的主心骨。配套代码。

  • fast.ai · Practical Deep Learning视频+notebook · 入门~进阶

    「先做出来、再讲原理」的免费实战课,数学要求低,几节课就能训出能跑的模型。

  • Google · 机器学习速成课交互课程 · 入门

    结构清楚、有交互可视化,约 15 小时;本课程 05/06 的主线。

  • 吴恩达 · 机器学习(中文字幕)视频 · 入门 · 中文

    全球公认的经典入门课,系统、稳。想要中文系统主线选它。

  • Hugging Face · LLM 课程课程+代码 · 进阶

    Transformers 端到端:架构、分词器、微调、LoRA/RLHF,由造这些库的人写。做大模型应用绕不开。

  • Stanford CS231n(计算机视觉) · CS224n(NLP)大学课 · 进阶

    深度学习在视觉/语言两条线的经典高校课,讲义公开。想系统深挖某一支时用。

3免费书(当字典 / 系统深挖)

不必通读;卡住时查、想深挖时读。全部免费在线。

  • Dive into Deep Learning(d2l.ai)书+可跑代码 · 进阶

    整本书就是可运行的 Jupyter notebook,每个概念从代码搭起,500+ 高校在用。现代最全的免费深度学习书。

  • Understanding Deep Learning(Simon Prince)书 · 理论 · 图多

    图极好、讲理论清楚的免费 PDF。想真正理解「为什么这么设计」时读。

  • Neural Networks and Deep Learning(Nielsen)书 · 入门直觉

    经典入门小书,把神经网络的直觉讲得很透。配合第 7 章看。

  • The Little Book of Deep Learning(Fleuret)书 · 精简 · 手机可读

    一本掌上大小的深度学习浓缩册,通勤翻。

  • Mathematics for Machine Learning(mml-book)书 · 数学地基

    机器学习需要的线代/微积分/概率,免费 PDF。数学卡壳时补这本,不必啃完。

  • Python Data Science Handbook(VanderPlas)书+notebook · 数据工具

    NumPy / Pandas / Matplotlib / scikit-learn 的权威手册,免费 notebook。第 3、4 章的加深与字典。

4官方文档(动手时查)

写代码卡住,先查官方,别先搜二手博客。

  • NumPy · Pandas · scikit-learn文档 · 数据/经典ML

    数组、表格、经典机器学习三件套的官方文档与用户指南,都有很好的入门教程。

  • PyTorch Tutorials文档 · 深度学习

    官方教程,从张量到完整训练循环。深度课程 D07 起动手时的主参考。

  • Hugging Face 文档文档 · 大模型

    Transformers / Datasets / Tokenizers 等库的文档;调用和微调开源模型的入口。

  • FT · Visual Vocabulary(图表词汇)参考 · 数据可视化

    《金融时报》的「什么场景用什么图」速查,做数据可视化(D06/项目)时的设计参考——正好强项。

5做出能用的 AI 应用 · 应用工程 ★

这一层直接对应索引 Stage 3——把 AI 真正用起来、把 agent 搭好治好。想推进治理体系、看懂 harness/底层框架,重点看这一节(尤其 MCP、Agent 设计、ReAct)。

  • Chip Huyen · AI Engineering(书 + 免费资源)书 · 综合 · 应用工程主线

    用现成大模型搭应用的系统方法论:prompt、RAG、微调、agent、评估、成本全覆盖,2025 最热的应用工程书。GitHub 有免费配套资源清单。整个 Stage 3 的总主线。

  • Full Stack · LLM Bootcamp(免费)视频 · 端到端 · 免费

    从 prompt 到搭应用到上线(LLMOps)的免费训练营讲座,专讲「做出能用、能上线的 LLM 应用」。

  • Prompt Engineering Guide(DAIR)指南 · Prompt/上下文

    最全的 prompt、上下文工程、RAG、Agent 技法合集,300 万人学过。配 A01。另可看 Anthropic 官方 prompt 指南。

  • Model Context Protocol(MCP)协议 · 工具 · harness ★

    把工具和数据源标准化地接到模型的开放协议——agent harness 的关键拼图,和治理/底层框架方向直接相关。配 A02/A05。

  • Anthropic · Building Effective Agents必读 · Agent 设计 ★

    分清「工作流」和「agent」、给出一套可复用的 agent 设计模式,做 agent 前几乎必读的一篇。配 A04/A05。

  • Hugging Face · AI Agents 课程(免费带证书)课程 · Agent · 免费

    从零到会搭 agent 的实战课,覆盖 smolagents / LangGraph / LlamaIndex 三个框架。想动手做 agent 从这条走。

  • ReAct:Reasoning + Acting(论文/范式)范式 · agent loop 底层

    「想一步 → 做一步 → 看结果 → 再想」交替的 agent 基本范式,理解 agent loop 底层逻辑的钥匙。配 A05;想看更前沿的框架用 LangGraph。

  • LlamaIndex(RAG 框架)框架 · RAG

    几十行搭一个「喂自己文档 → 检索 → 问答」的 RAG 应用。配 A03 / 项目 P5;另有 LangChain。

  • OpenAI Cookbook代码配方 · 实战

    调 API 的实用配方:embedding 检索、函数调用、结构化输出、流式。动手时直接抄改。

  • LLM 评估指南(Evidently)指南 · 评估/可观测

    怎么判断 AI 应用「真的变好了」:evals、指标、回归测试、可观测。配 A06——没有评估的应用等于盲开。

6钻进模型内部 · 深度学习与大模型(Track B / C)

这一层对应深度课程 Track B(D07–D11)与 Track C(D12–D17)——从训练循环、CNN,一直到注意力手算、Transformer 结构、预训练与推理成本。每条都注明配哪一章。

  • PyTorch · Learn the Basics官方教程 · Track B 主线

    六步入门:张量 → 数据集 → 建模型 → 自动求导 → 优化循环,顺序几乎就是 D07 的骨架。跟完就能自己写训练脚本。配 D07。

  • Karpathy · Let's build GPT from scratch视频 · 从零写 GPT ★

    两小时从空白文件写出一个能训练的 GPT,业内公认最好的实战课之一。配 D14/D15——看懂结构后跟着敲一遍,理解会上一个台阶。另有同作者的 Tokenizer 专题(配 D12)。

  • The Illustrated Transformer图解 · 注意力/结构 ★

    逐图拆解自注意力、多头、编解码结构,全网引用最多的图解长文。配 D09/D14/D15;同作者的 Illustrated Word2vec 配 D13。

  • 动手学深度学习(d2l,中文免费)教材 · 中文 · 按需查

    中文免费教材,CNN、RNN、注意力都有图有代码。别通读,按章查:卷积配 D08、循环网络配 D09、注意力配 D14。

  • 斯坦福 CS231n 笔记讲义 · 深读 · 英文

    CNN 与训练技巧的经典讲义。ConvNets 配 D08、Training 配 D10、Transfer Learning 配 D11。

  • 3Blue1Brown · 神经网络系列视频 · 有中文字幕 · 建直觉

    顶级数学动画:梯度下降、反向传播、以及近年新增的注意力与 Transformer 几集。配 06/07 章与 D14——先看它建画面感,再读文字最省力。

  • Hugging Face · Tokenizers 课课程 · 可切中文 · 分词

    三种切分粒度、BPE 算法、怎么训练自己的 tokenizer。配 D12;动手配 在线分词器,把自己的提示词切一遍看真实 Token 数。

  • Karpathy · State of GPT演讲 · 三阶段流水线 ★

    把「预训练 → 指令微调 → 奖励模型 → RLHF」整条生产链讲清的经典演讲。配 D16;细节补 HF 的 RLHF 图解。

  • HF · LLM 推理优化指南文档 · 推理/KV cache/量化

    推理瓶颈、KV cache、量化、注意力优化的系统说明。配 D17;要自建服务再看 vLLM(PagedAttention)。

  • HF PEFT · LoRA 指南文档 · 微调 · 个人可做

    只训不到 1% 的参数就能微调大模型,一张消费级显卡够用。配 D16 第 11–12 节;真要动手时按它调 r / alpha / target_modules。

  • The Annotated Transformer(哈佛)代码精读 · 论文↔实现

    把原论文逐段配上可运行 PyTorch 代码。配 D15——想把「读懂结构图」升级成「读懂实现」时用它。

7奠基论文(桥 · 以后再啃)

现在不用啃数学:先看摘要 + 那张结构图,建立「哦原来是它」的印象;等深度课程对应章再逐符号读。这些是不变的地基。

  • Attention Is All You Need(2017)论文 · Transformer

    提出 Transformer,今天所有大模型的地基。先看摘要 + 第 3 节结构图;配 08 章与 D14/D15 读。

  • Deep Residual Learning · ResNet(2015)论文 · 深度视觉

    残差连接让网络能堆到上百层,现代计算机视觉的基石。配 D08(CNN)读。

  • ImageNet / AlexNet(2012)论文 · 深度学习起点

    点燃这轮深度学习热潮的那篇。当历史与直觉读,看它为什么是转折点。

  • BERT(2018)论文 · 预训练

    「预训练 + 微调」范式的代表作。配 D16(预训练/微调)读。

  • GPT-3 · Language Models are Few-Shot Learners(2020)论文 · 大模型涌现

    规模带来「少样本/零样本」能力的转折,理解今天 LLM 的路标。

  • Adam 优化器(2014)论文 · 训练

    今天最常用的优化器。配 06(梯度下降)/ D10(优化器)读,理解「怎么把步子迈得又快又稳」。

  • Word2Vec(2013)论文 · 词向量

    「把词变成向量、意思近则向量近」的起点,Embedding 的开山之作。配 08 章 / D13(向量检索)读。

  • Chain-of-Thought(2022)论文 · 推理

    「让模型把中间步骤写出来」显著提升推理,分步思考的源头。配 A01 / A04 读。

  • PPO(2017)论文 · 强化学习 / 对齐

    RLHF(基于人类反馈的强化学习)最常用的算法,ChatGPT 式对齐的底层。配 D17(对齐)读;更新的路线看 DPO(2023)。

  • DDPM · 扩散模型(2020)论文 · 生成

    今天文生图(Stable Diffusion 等)的地基:「加噪再一步步去噪」。想看更早的对手看 GAN(2014)。

  • CLIP · 图文对齐(2021)论文 · 多模态

    用海量图文对把「图」和「文字」放进同一个向量空间,多模态与文生图的地基。当直觉读。

想要「全清单 + 最前沿」?一个持续更新的论文库

上面是不变的地基(精挑,够入门)。想按主题一路追到最前沿(FlashAttention、MoE、扩散变体、推理加速、Agent RL、CUDA kernel……),用这个别人维护、持续更新的清单:Treasure-Questions · 宝藏论文链接大全。会变的前沿交给它维护、我们只留地基——这正是本课的策展原则:过时了换链接,不改正文。
