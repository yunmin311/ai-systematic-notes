课程首页—术语表

资料 · 随章节持续增补

术语表

所有在课程里正式出现过的术语,按章节归档。每条 = 标准名 + 英文 + 一句白话。 忘了某个词的意思,先来这里,再决定要不要回讲义重读。

1第 1 章 · 人工智能全景与学习环境

人工智能Artificial Intelligence, AI§10 概念一

让计算机完成过去认为需要人类智能的任务。是目标/总称,不是一种具体技术。

机器学习Machine Learning, ML§10 概念二

不由人写规则,而是给程序看大量例子,让它自己找出输入和输出之间规律的方法。

深度学习Deep Learning, DL§10 概念三

机器学习的子类:模型专指层数很多的神经网络,能自己从原始数据里逐层提炼特征。

神经网络Neural Network§10 概念三

把大量简单的「乘加计算单元」一层层叠起来构成的模型。「深度」指层数多。

生成式 AIGenerative AI§10 概念四

输出不是「选类别」而是「产出内容」(文字/图像/音频)的深度学习模型。

大语言模型Large Language Model, LLM§10 概念四

生成式 AI 里专管文字的:反复预测「下一个词」,逐词把回答续写出来。GPT、Claude 都是。

模型model§10 概念二

一个内部含有若干可调数值的数学函数:输入进去、输出出来,数值调好后输出接近正确答案。

参数parameter§10 概念二

模型内部那些可调整的数值,由训练自动确定。本章模型 1 个参数,GPT 上千亿个。

训练training§10 概念二

用数据自动调参数的过程:预测 → 量差距 → 朝差距变小的方向调,反复循环。

推理inference§11

用训练好的模型做预测,参数不再变动。每次问 ChatGPT 都是一次推理。

损失函数loss function§12.2

给「当前参数的预测有多离谱」打分:越差分越高;训练目标就是把它压到最小。

均方误差Mean Squared Error, MSE§12.2

最常用的损失之一:所有样本「误差的平方」的平均值。

梯度下降gradient descent§13(体感版,第 6 章正式讲)

找损失最低点的方法:每一步朝「损失变小的方向」挪一点参数,反复走。

Token(词块)token§11

模型处理文字的最小单位,通常是一个词或半个词,切完后用编号表示。

幻觉hallucination§15(D10 详讲)

大模型一本正经生成不真实内容的现象——因为它按概率生成,不检索事实库。

过拟合overfitting§15(第 6 章详讲)

模型把训练数据死记硬背得很好,对没见过的新数据反而表现差。

终端 / 命令行terminal / command line§8

用文字跟电脑对话的窗口:输入命令,它执行并打印结果。

虚拟环境virtual environment, venv§8

与系统隔离的独立 Python 运行环境:装的库只属于这个项目,删掉文件夹即彻底卸载。

标量scalar§12.2

就是一个单独的数(区别于列表/数组/矩阵)。

外推extrapolation§18 练习 2(第 5 章详讲)

让模型预测「训练数据范围之外」的输入。模型敢答,但可信度另说。

2第 2 章 · Python 基础

变量variable第 2 章

给一个值起的名字,后面用名字就能取到值;可以随时重新赋成别的值。

列表 / 字典list / dict第 2 章

列表按顺序装一串值(用位置取);字典按「键→值」装(用名字取)。两种最常用的容器。

循环loop第 2 章

让同一段代码对一批数据反复执行,如 for 逐个遍历列表。训练循环就是它的放大版。

函数function第 2 章

一段起了名、可反复调用的代码:给它输入(参数),它算完返回输出。

报错 / 回溯exception / traceback第 2 章

程序出错时打印的信息;最后一行说错在哪、是什么错。读懂它是 debug 的第一步。

3第 3 章 · NumPy 数组与形状

数组ndarray第 3 章

NumPy 里装同类型数字的多维网格,是一切张量运算的基本容器。

形状shape第 3 章

数组每个维度的长度,如 (3, 2) = 3 行 2 列。形状对不上是最常见的报错来源。

轴axis第 3 章

数组的维度方向:二维里 axis=0 沿行(往下),axis=1 沿列(往右)。求和/求平均要指定轴。

向量化vectorization第 3 章

不写 for 循环,直接对整个数组做运算——又快又短,是 NumPy 的核心用法。

广播broadcasting第 3 章

形状不同的数组做运算时,NumPy 自动把小的「撑开」对齐再逐元素算的规则。

4第 4 章 · Pandas 表格数据

Series / DataFrameSeries / DataFrame第 4 章

Series = 带标签的一列;DataFrame = 一整张表(多列 Series 拼起来),Pandas 的两个主角。

缺失值NaN / missing value第 4 章

表里空着的格子(记作 NaN)。喂模型前必须处理:填补或删除,否则计算会出错或被污染。

选取loc / iloc第 4 章

从表里取子集:loc 按标签名取,iloc 按整数位置取。

分组聚合groupby第 4 章

先按某列把行分堆,再对每堆算统计(求和/平均/计数)——「按类别汇总」的标准操作。

5第 5 章 · 机器学习核心概念

监督学习supervised learning第 5 章

训练数据带「正确答案」(标签),让模型学输入到答案的映射。分类和回归都属于它。

无监督学习unsupervised learning第 5 章

数据没有答案,让模型自己找结构,如聚类分堆、降维。

特征 / 标签feature / label第 5 章

特征 = 喂给模型的输入列(x);标签 = 想让它预测的答案列(y)。

分类 / 回归classification / regression第 5 章

预测「哪一类」(离散,如垃圾邮件与否)= 分类;预测「多少」(连续,如房价)= 回归。

训练集 / 验证集 / 测试集train / validation / test set第 5 章

数据切三份:训练学参数、验证调超参、测试只在最后估真实水平。混用会自欺。

泛化generalization第 5 章

模型在「没见过的新数据」上也表现好的能力,是机器学习真正追求的目标。

6第 6 章 · 训练的本质

学习率learning rate第 6 章

每一步朝损失变小方向挪多远的步长。太大越过谷底震荡,太小学得极慢。

训练循环training loop第 6 章

反复跑:前向预测 → 算损失 → 反向求梯度 → 更新参数。深度学习的心脏。

批量 / 小批量batch / mini-batch第 6 章

一次拿多少条数据算一步更新。小批量在速度和稳定之间折中,是主流做法。

梯度下降gradient descent§13 / 第 6 章 / D01

找损失最低点的方法:每步朝「坡度最陡的下坡方向」挪一点参数。另见第 1 章、D01。

7第 7 章 · 神经网络入门

神经元neuron第 7 章

网络的基本单元:把若干输入各乘一个权重、加起来、加偏置,再过激活函数。

权重 / 偏置weight / bias第 7 章

神经元里可训练的参数:权重决定各输入的重要性,偏置整体平移。训练就是在调它们。

激活函数activation function第 7 章

加在神经元输出上的非线性函数(如 ReLU),没有它多层网络会塌缩成一层。

前向传播forward propagation第 7 章

数据从输入层逐层「乘加 + 激活」算到输出层,得到预测。

反向传播backpropagation第 7 章

把输出的误差从后往前逐层传,算出每个参数该怎么改——训练神经网络的关键算法。

8第 8 章 · 大语言模型鸟瞰

词向量 / 嵌入embedding第 8 章 / A03 / D13

把 Token(或一段文字)表示成一长串数字,含义相近的向量距离也近。检索和理解的基础。

注意力attention第 8 章(D14 手算)

让模型在处理某个词时,按相关度「看」前文里的其他词。Transformer 的核心机制。

TransformerTransformer第 8 章(D15 拆结构)

由注意力 + 前馈层堆叠成的网络结构,现代所有大语言模型的骨架。

上下文窗口context window第 8 章 / A01

模型一次能读入的最大 Token 数。超了就要截断或检索,是 RAG 和长文档处理的根本约束。

9应用工程 · A01–A07

提示词promptA01

发给模型的全部文字(任务说明 + 上下文 + 例子)。把任务讲清、给对例子,输出就稳。

少样本示例few-shotA01

在提示词里给几个「输入→期望输出」的范例,让模型照着格式和风格答。

结构化输出structured outputA02

让模型稳定吐出程序能直接解析的格式(通常是 JSON),把「聊天」变成「驱动程序」。

函数调用 / 工具调用function calling / tool useA02

模型不直接答,而是按约定格式请求「调用某个工具」,程序执行后把结果喂回去。Agent 的地基。

RAG 检索增强生成Retrieval-Augmented GenerationA03

回答前先从资料库检索相关片段拼进上下文,让模型「带着资料答」——少编、可更新、能给出处。

切块chunkingA03

把长文档切成小段再做向量化,方便按需检索。切多大、怎么切直接影响检索质量。

向量检索vector searchA03

把问题也变成向量,在库里找「距离最近」的几段文本——按语义找,而非按关键词。

Agent(智能体)agentA04

能自己决定「下一步调哪个工具」的程序:模型—工具—状态反复循环,直到把任务办完。

ReActReason + ActA04

Agent 的经典范式:交替「想一步(推理)」和「做一步(调工具)」,拿到结果再想下一步。

工作流 vs Agentworkflow vs agentA04

步骤固定、路线已知用工作流(可控);步骤要模型临场决定才用 Agent(灵活但难控)。

harness(底层框架)harnessA05

包在模型外面、真正驱动一次 agent 运行的框架:拼上下文、调工具、跑循环、兜底。日常用的 Claude Code 就是一个 harness。

agent loopagent loopA05

harness 的主循环:发上下文给模型 → 模型要调工具 → 执行 → 结果拼回上下文 → 再发,直到完成或触顶。

MCPModel Context ProtocolA05

一套让模型统一发现和调用外部工具/数据源的开放协议,免得每个工具各写一套接法。

多 Agent 编排multi-agent orchestrationA05

把大任务拆给多个各有分工的 agent 并行/接力完成,再由一个协调者汇总。

评测集eval setA06

一批「输入 + 期望结果」的固定样例,每次改动后重跑,用来客观判断应用有没有变好。

模型当裁判LLM-as-judgeA06

用另一个模型按评分标准给输出打分,替代人工逐条评判——快,但要防它自己的偏差。

提示注入prompt injectionA06

攻击者把恶意指令藏进模型会读到的内容里,诱导它无视原任务。RAG/Agent 的头号安全风险。

后端代理backend proxyA07

前端不直接连模型 API,而是先经过自己的后端——密钥不外泄、能限流缓存记日志的唯一关口。

流式输出streamingA07

模型边生成边一段段返回,用户立刻看到字往外蹦,而不是干等整段答案。

限流 / 缓存rate limiting / cachingA07

限流挡住短时间内过多请求(防超支/滥用);缓存把重复问题的答案存下来直接复用(省钱省时)。

10深度课程 · 经典机器学习 D01–D06

线性回归linear regressionD01

用一条直线(ŷ = w·x + b)拟合数据,预测连续值。模型-损失-训练三件套最干净的示范。

逻辑回归logistic regressionD02

线性回归 + Sigmoid + 交叉熵,输出「属于某类的概率」——最基础的分类模型。

SigmoidsigmoidD02

把任意实数压进 0~1 的 S 形函数,常用来把分数变成「一个类的概率」。

SoftmaxsoftmaxD02

把一组分数变成「和为 1 的概率分布」,用于多分类;也是 LLM 预测下一词的最后一步。

交叉熵cross-entropyD02

分类任务最常用的损失:衡量预测的概率分布和真实标签差多远,越准越小。

决策边界decision boundaryD02

特征空间里把不同类别分开的那条线/面。模型学的其实就是这条边界怎么画。

决策树decision treeD03

用一连串「是/否」问题层层切分数据来做预测的模型,直观但容易过拟合。

随机森林random forestD03

训练很多棵不同的树,让它们投票取平均(bagging)——比单棵稳得多。

梯度提升gradient boostingD03

一棵接一棵地训练,每棵专门纠正前面的残差(boosting)。XGBoost/LightGBM 是表格数据之王。

集成学习ensembleD03

把多个弱模型组合成一个强模型:并联投票=bagging,串联纠错=boosting。

聚类clusteringD04

无监督地把相似样本自动分成若干堆,如 K-Means。事先不知道有哪些类。

K-MeansK-MeansD04

最常用的聚类算法:反复「就近归堆 → 重算堆中心」,直到稳定。需要事先定 K(几堆)。

降维dimensionality reductionD04

把很多特征压成少数几个,保留主要信息,便于可视化和去噪。

PCA / t-SNEPCA / t-SNED04

两种降维:PCA 找方差最大的几个方向(线性、快);t-SNE 专为「把高维数据画到二维看分布」。

混淆矩阵confusion matrixD05

一张表列出「真/假 × 阳/阴」四种情况的数量,是所有分类指标的来源。

精确率 / 召回率precision / recallD05

精确率=报阳里真阳的比例(准不准);召回率=真阳里被抓到的比例(全不全)。常此消彼长。

F1 分数F1 scoreD05

精确率和召回率的调和平均,一个数兼顾两者,类别不平衡时比准确率靠谱。

ROC / AUCROC / AUCD05

ROC 曲线在不同阈值下权衡真阳率与假阳率;AUC 是曲线下面积(0.5=瞎猜,1=完美)。

交叉验证cross-validationD05

把数据轮流切成 K 份、每份都当一次测试集,取平均分——比单次划分更可信地估水平。

超参数hyperparameterD05

不是训练学出来、而是事先设定的旋钮(学习率、树深、K 值),用验证集或网格搜索来调。

数据泄露data leakageD05 / D06

测试集的信息偷偷混进了训练,导致离线分数虚高、上线暴跌。防它是评估的头号纪律。

特征工程feature engineeringD06

喂模型前对原始数据的加工:补缺失、编码、缩放、构造新特征——常比换模型更能提分。

独热编码one-hot encodingD06

把类别(红/黄/蓝)变成一组只有 0/1 的列,让模型能处理非数字的特征。

特征缩放feature scalingD06

把不同量纲的特征拉到相近范围(标准化/归一化),否则大数值特征会压过小数值的。

流水线PipelineD06

把预处理和模型串成一条链,只在训练集上「学」变换规则再套到测试集——从流程上杜绝数据泄露。

11深度课程 · 深度学习 D07–D11

框架framework(PyTorch)D07

把「张量运算 + 自动求导 + 数据加载 + 训练循环」标准化的工具库,让人只管搭网络、不用手推导数。

张量tensorD07

PyTorch 版的多维数组:用法像 NumPy,但能搬上 GPU、且会记录运算以支持自动求导。

自动求导autogradD07

框架在前向时记下计算图,调用 loss.backward() 就自动算出所有参数的梯度——反向传播的自动化版本。

训练循环五步training loopD07

前向 → 算损失 → 梯度清零 → 反向 → 更新。深度学习所有模型都在这个循环里训,换模型不换循环。

数据加载器DataLoaderD07

把数据集切成小批量、每轮打乱、按需喂给训练循环的工具。

卷积convolutionD08

用一个小窗口(卷积核)滑过整张图,每处把窗口内像素与核的权重相乘求和,得到特征图。同一套权重扫全图。

参数共享parameter sharingD08

卷积核在图像每个位置用同一套权重,把参数量从百万级压到几十个,是 CNN 又省又好的关键。

池化poolingD08

下采样:把特征图按小块只留一个代表值(常取最大)。缩小尺寸、保留最强响应、并带来对小位移的稳健。无可训练参数。

感受野receptive fieldD08

一个神经元能「看到」的原图范围。越深的层感受野越大,所以浅层看边缘、深层看整体。

循环神经网络RNND09

处理序列的老办法:维护一个隐状态(记忆),每读一个词就用「当前词 + 旧记忆」更新它,像传接力棒。

长短期记忆网络LSTMD09

RNN 的改良版,用几道「门」决定记什么忘什么,能记得更久;但只是缓解长依赖问题,没有根治。

优化器optimizerD10

决定「拿到梯度后参数具体怎么挪」的算法。Adam = 动量 + 自适应学习率,默认首选。

正则化regularizationD10

一切「给模型加约束/干扰,逼它别死记硬背」的手段:Dropout、权重衰减、早停、数据增强。

DropoutdropoutD10

训练时每步随机「关掉」一部分神经元,逼网络别依赖个别单元;测试时全部打开(靠 model.eval() 切换)。

批归一化BatchNormD10

在网络中间把每层输入拉回「均值 0、方差 1」,让训练更快更稳——D06 的特征缩放搬进了网络内部。

学习率调度lr schedulerD10

训练过程中动态调学习率:先小步热身、中途大步、后期减小精修。

迁移学习transfer learningD11

不从零训练,而是拿别人在海量数据上训好的模型当起点,借用它已学会的通用特征。

预训练模型 / 基座pretrained / base modelD11 / D16

别人已在大数据集上训练好并公开权重的模型。图像界如 ResNet,文本界即大语言模型的基座。

冻结freezeD11

把某些层标记为不参与梯度更新,只训练新加的部分。数据少时最稳。

微调fine-tuningD11 / D16

解冻部分或全部层,用很小的学习率在自己的数据上继续训练,让通用特征朝任务微调一点。

12深度课程 · 大模型内部 D12–D17

分词器TokenizerD12

一本「文字↔编号」的对照词典 + 一套切分规则,把字符串翻译成模型唯一能处理的整数序列。训练前定死,之后不能换。

子词subwordD12

介于字符和整词之间的切分粒度:常见词整块保留、罕见词拆成常见片段。词表可控且永不遇生词,是今天的主流。

BPE 字节对编码Byte Pair EncodingD12

最主流的子词算法:先全拆成字符,反复把「最常相邻的一对」合并成新块,直到词表达到设定大小。

词表vocabularyD12

所有 Token 与编号的对照表,现代模型常几万到二十几万条。它既是模型的入口也是出口。

嵌入矩阵embedding matrixD13

模型第一层的可训练查找表:行数 = 词表大小,列数 = 向量维度。查 Token 编号就是取出对应那一行。

余弦相似度cosine similarityD13

比两个向量的方向夹角(不比长度),取值 −1~1。RAG 的向量检索算的就是它。

位置编码positional encodingD13

把「排第几」也编码成向量加到词向量上。因为注意力同时看所有词、天生不分先后,顺序要另外喂进去。

Q / K / VQuery / Key / ValueD14

同一个词向量乘三个不同可训练矩阵得到的三种角色:Q=我在找什么、K=我是什么、V=我能提供什么信息。

自注意力self-attentionD14

句子里每个词都当一次查询方,对全句做一遍「打分 → 缩放 → softmax → 加权求和」,得到参考全句后的新表示。

多头注意力multi-head attentionD14

同时用多套 Q/K/V 从不同角度看全句(一头盯主谓、一头盯指代…),最后拼接融合。

因果掩码causal maskD14

在 softmax 前把「未来位置」的分数设为负无穷,保证预测第 t 个词时不偷看后文。生成式模型逐词输出的原因。

前馈层feed-forward network, FFND15

对每个位置各自独立做的两层小网络(放大 → 非线性 → 压回)。提供真正的非线性表达力,也是参数大头。

残差连接residual connectionD15

把子层输入原样加到输出上(x + 子层(x))。给梯度一条高速公路,让网络能堆到几十上百层。

层归一化LayerNormD15

把每个位置的向量拉回规整分布,稳定训练。按每个样本自己归一,不跨批,适合长度不一的文本。

Transformer 块Transformer blockD15

多头注意力 → 残差归一 → 前馈 → 残差归一。进出形状相同,所以能堆 N 层。堆起来就是 GPT 骨架。

只用解码器架构decoder-onlyD15

带因果掩码、专做「续写下一个词」的结构。今天所有主流大语言模型都是这一类。

预训练pretrainingD16

在海量文本上用「预测下一个词」训练,顺带学到语法、事实与推理。产物是只会续写的基座模型。千万美元级。

指令微调SFT, Supervised Fine-TuningD16

用几万条「指令 → 理想回答」的示范继续训练,把「续写」变成「照指令做事」。改的是行为方式,不是知识。

对齐 / RLHFalignment / RLHFD16

用人类对回答的排序偏好训练奖励模型,再用强化学习让模型倾向高分回答。教的是「分寸」,也是安全与价值观注入的主要环节。

DPO 直接偏好优化Direct Preference OptimizationD16

RLHF 的简化版:跳过奖励模型,直接用偏好数据一步优化,更简单也更稳。

LoRA 低秩适配LoRAD16

冻住原权重,只在每层旁插入两个小矩阵学「改动量」,可训练参数常不到 1%,一张消费级显卡就能微调大模型。

自回归生成autoregressiveD17

每跑一遍网络只产出一个 Token,拼回输入再跑。所以回答逐字蹦出、无法并行、越长越慢。

预填充 / 解码prefill / decodeD17

推理的两阶段:预填充一次并行读完提示词(吃算力);解码逐个生成(每步都要读一遍全部权重,吃显存带宽)。

KV cacheKV cacheD17

把已算过的 K/V 缓存复用,避免每步重算前文,计算量从平方降到线性。代价是缓存占显存并随上下文长度线性膨胀。

量化quantizationD17

把权重从 16 位压成 8 位甚至 4 位存储。显存近似按比例下降、生成更快,精度略损。7B 模型 4-bit 约需 3.5 GB。

13项目 · P1–P7

数据体检data profilingP1

建模之前先摸清数据的六件事:规模、缺失、类型、分布、异常、关系。目的不是修数据,是先知道数据到底长什么样——多数返工都能追溯到这一步没做。

切块重叠chunk overlapP5

相邻两个文本块之间故意留一段重复内容。块切小了检索准、但容易把一句话拦腰截断;留一点重叠能保住跨块的语义,代价是索引略大。

工具说明书JSON schema(工具侧)P6

工具的两面之一:一面是真正干活的 Python 函数,另一面是给模型看的 JSON 描述(名字、参数、含义)。模型靠这份说明书决定「该调哪个、传什么参数」,写不清楚它就乱调。

步数上限max_stepsP6

给 agent loop 设的最大轮数。没有它,模型一旦在两个动作之间来回打转,就会一直烧钱到天亮——这是最小 harness 里最不能省的一个兜底。

最小闭环minimum loopP4

先跑通「发一句、收一句」再谈别的功能。它的价值是让错误暴露在最薄的一层:闭环没通时,问题只可能在鉴权、网络或调用参数这三处。

消融实验ablationP3

每次只去掉一个部件(比如去掉 Dropout、去掉池化层)再跑一遍,对比指标变化。用来亲手验证「这个部件到底有没有用」,而不是照着结论信。

后端关口backend gatewayP7

前端与模型之间唯一的那一道:密钥只在这里注入、限流与缓存只在这里做、请求只在这里记日志。把「唯一关口」做实,前端就永远碰不到密钥。

监控四块表four monitoring dashboardsP7

上线之后要盯的四类数:用量与成本、延迟、失败与报错、答案质量。少了任何一块,都只能在用户投诉之后才知道出了问题。

平台托管 / 无服务器PaaS / serverlessP7

把代码推上去、在后台设好环境变量,平台给一个公网网址。不用自己管机器,代价是可控性低、冷启动有延迟。适合入门和流量不大的应用。

14AI 使用 · U01–U07

工具回执tool resultU01

工具执行完之后由程序回传给模型的那段结果。它是模型判断「自己做没做成」的唯一依据——回执被裁剪、被重试盖掉或压根没调工具,那句「已完成」照样会被生成出来。

默认脸 / 分布中心mode / distribution centerU01

不给具体约束时,产出会收敛到「语料里最常见的那种写法」。再叠加对齐训练奖励「多数人觉得还行」,两股力量一起把输出推向安全平均值。所以默认脸不是偷懒,是必然。

前提确认premise checkU01

开工前先让它用一句话说清材料是什么(几页、什么结构),确认无误再往下。模型内部没有「我不确定」的信号能中断生成,前提错了后面全错、且读起来毫无异常,所以这一步必须单独一轮。

假绿灯false greenU01

不表现为失败、而表现为成功的那种错。它最贵的地方在于:后续所有工作都接着这个不存在的地基往下做,等发现时返工量已经滚了几轮。

缓存前缀prompt cache prefixU02

厂商提示缓存只缓存「从第一个 Token 开始连续不变的那一段」。所以改动位置越靠前、失效的部分越多——稳定的规则放开头、变动的东西放末尾,是硬规矩不是风格。

中段衰减lost in the middleU02

注意力对超长序列中间部分的权重系统性偏低:开头结尾记得牢,中间容易被略过。第 20 轮说的一条约束,到第 80 轮时正落在衰减区里。

规则强度阶梯rule strength ladderU03

同一条规则放的位置决定强度,差好几个数量级:①口头说 ②写进规则文件 ③自动注入 ④脚本校验 ⑤执行前硬拦截。前三层只是提高概率,后两层才是保证。

可写面writable surfaceU06

会被写到的那一份东西:一个工作目录、暂存区、一条分支、一份共享配置,甚至一个编号池。冲突发生在「两个写者和同一个面」之间,所以判冲突要看面,不看是谁。

转发块handoff blockU06

把一个对话的结论交给另一个对话时用的固定格式。三条硬规矩:不预填未拍板的决定、不代写提出者的原话、块要自足(接收方看不到这边的上下文)。

映射表mapping tableU05

动手前先交的那张表,四列:参考里的项 / 实测值 / 本次要落到哪 / 怎么判定。判定方式那一列写不出来的项,说明还没拆到位。表没过不许开工。

核心样本core sampleU05

挑那个「做对了别的就都好办」的样本(最复杂的模块、最难的一段)先做到逐项判定通过,再复制到其余部分。先铺后改的返工量通常是先样后铺的十倍以上。

快照snapshotU04

动正本之前先留的一份可回滚的副本。失败代价高的活(批量重命名、数据迁移)先在副本上跑一遍、比对结果,确认无误再对正本执行。

待验单pending verification listU07

把「脚本过了、但还有必须人看的部分」单独列的一张单子。它可以进下一批,但不销账——让「还没验」这件事有地方待着,而不是被压进「完工」里悄悄消失。

抽样错觉sampling illusionU07

抽查三处都对就当全过了。批量产出里的错误常常是成片的而不是随机的,三处全落在好的那一片是常事。能全量就全量,不能全量就明说「这是抽查,抽了几处」。
