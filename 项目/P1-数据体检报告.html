3分步搭建

体检分六步,每步回答一个问题。建议一步一跑——每步都能立刻看到结果,不要写完整个脚本才运行。

第 1 步 · 规模与首视:这份数据长什么样

体检.pypython
import pandas as pd

URL = "https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv"
df = pd.read_csv(URL)          # 换成自己的数据就写本地路径:pd.read_csv("我的数据.csv")

print("① 规模:", df.shape)      # (行数, 列数)
print(df.head(3))               # 先看三行真实的样子,别急着统计
print(df.dtypes)                # 每列是什么类型
检查点

能打印出 (891, 12) 和前三行——说明数据读进来了。永远先 head() 看几行真实数据,再做任何统计:很多问题(错位的列、混进表头的行)一眼就能看出来。

第 2 步 · 缺失:哪里有窟窿

体检.py(续)python
miss = df.isna().sum()                       # 每列缺多少个
miss = miss[miss > 0].sort_values(ascending=False)
pct  = (miss / len(df) * 100).round(1)       # 缺失比例更有意义
print("② 缺失:")
for col in miss.index:
    print(f"   {col:12s} 缺 {miss[col]:4d} 个 ({pct[col]}%)")
检查点

看到 Cabin 缺了 77%、Age 缺 20%。这一步的判断比数字重要(D06):缺 77% 的列基本没救,考虑删;缺 20% 的关键列要想办法填,别直接扔掉行。

第 3 步 · 类型:哪些是数值、哪些其实是类别

体检.py(续)python
num_cols = df.select_dtypes(include="number").columns.tolist()
txt_cols = df.select_dtypes(exclude="number").columns.tolist()

# 陷阱:有些列是数字,但本质是类别(如 Pclass 舱位等级 1/2/3)
maybe_cat = [c for c in df.columns if df[c].nunique() <= 10]
print("③ 类型:数值", len(num_cols), "列 | 文本", len(txt_cols), "列")
print("   疑似类别列(取值 ≤10 种):", maybe_cat)
检查点

能列出疑似类别列(Sex、Embarked、Pclass、Survived)。这一步防的是最隐蔽的错误:Pclass 存的是 1/2/3,但"三等舱"不是"一等舱的三倍",直接当数值喂模型就错了(D06 的类别编码)。

第 4 步 · 分布:每列的数值都长什么样

体检.py(续)python
print("④ 分布:")
print(df[num_cols].describe().round(2))      # 计数/均值/标准差/四分位/极值

# 均值和中位数差得远 = 分布偏斜(被极端值拉歪)
for c in ["Age", "Fare"]:
    mean, med = df[c].mean(), df[c].median()
    skew = "右偏(有大额离群)" if mean > med * 1.2 else "大致对称"
    print(f"   {c}: 均值 {mean:.1f} / 中位数 {med:.1f} → {skew}")
检查点

发现 Fare 的均值(32)远大于中位数(14)——典型右偏。这解释了一条实用经验:D06 说填缺失值优先用中位数,正是因为均值容易被这类极端值带偏。

第 5 步 · 异常:有没有离谱的值

体检.py(续)python
def outliers(s):
    """IQR 法:落在 [Q1-1.5IQR, Q3+1.5IQR] 之外的算离群点"""
    q1, q3 = s.quantile(0.25), s.quantile(0.75)
    iqr = q3 - q1
    return s[(s < q1 - 1.5 * iqr) | (s > q3 + 1.5 * iqr)]

print("⑤ 异常:")
for c in ["Age", "Fare"]:
    o = outliers(df[c].dropna())
    print(f"   {c}: {len(o)} 个离群点,最大 {o.max() if len(o) else '-'}")

# 还要查逻辑异常:不合常理的值(年龄为负、票价为 0…)
print("   票价为 0 的:", (df["Fare"] == 0).sum(), "条")
检查点

找出 Fare 的离群点(最大 512),以及 15 条票价为 0 的记录。关键判断:离群 ≠ 错误。512 的票价可能是真的头等舱套房;票价 0 可能是船员或免票。体检只负责发现,处理要结合业务判断——这正是 D01 里"一条脏数据毁模型"的现实版。

第 6 步 · 关系:哪些列和目标有关

体检.py(续)python
print("⑥ 关系:")
# 类别列 → 看分组均值
for c in ["Sex", "Pclass"]:
    rate = df.groupby(c)["Survived"].mean().round(3) * 100
    print(f"   按 {c} 分组的存活率(%):\n{rate.to_string()}")

# 数值列 → 看相关系数(-1~1,绝对值越大关系越强)
corr = df[num_cols].corr()["Survived"].drop("Survived").round(2)
print("   与 Survived 的相关系数:\n", corr.sort_values(ascending=False).to_string())
检查点

看到女性存活率 74% vs 男性 19%——这是整份数据里最强的信号。这一步的产出直接决定下一个项目(P2)该用哪些特征。注意:相关不等于因果,体检只说"这两列一起变化",不说谁导致谁。

4跑起来:配上图,导出报告

最后把结论配上图、导出成一个能发给别人的 HTML。四张图对应体检的四个维度:

体检.py(续)python
import matplotlib
matplotlib.use("Agg")                        # 不弹窗,直接存文件
import matplotlib.pyplot as plt
plt.rcParams["font.sans-serif"] = ["Microsoft YaHei"]   # 中文不显示成方块
plt.rcParams["axes.unicode_minus"] = False

fig, axes = plt.subplots(2, 2, figsize=(11, 8))
df["Age"].hist(bins=30, ax=axes[0][0]);            axes[0][0].set_title("年龄分布")
df["Fare"].plot(kind="box", ax=axes[0][1]);        axes[0][1].set_title("票价箱线图(看离群)")
df.groupby("Sex")["Survived"].mean().plot(kind="bar", ax=axes[1][0]); axes[1][0].set_title("性别 vs 存活率")
df.isna().sum().sort_values().plot(kind="barh", ax=axes[1][1]);       axes[1][1].set_title("各列缺失数量")
plt.tight_layout()
plt.savefig("图表.png", dpi=120)

# 导出 HTML 报告:结论 + 图 + 数据预览
html = f"""<!DOCTYPE html><html><head><meta charset="utf-8">
<style>body{{font-family:'Microsoft YaHei';max-width:900px;margin:40px auto;line-height:1.7}}
table{{border-collapse:collapse}}td,th{{border:1px solid #ddd;padding:6px 10px}}</style>
</head><body>
<h1>数据体检报告</h1>
<p>规模:{df.shape[0]} 行 × {df.shape[1]} 列</p>
<h2>关键结论</h2>
<ul>
  <li>Cabin 缺失 {df['Cabin'].isna().mean():.0%},建议整列删除</li>
  <li>Age 缺失 {df['Age'].isna().mean():.0%},建议用中位数填充</li>
  <li>性别与存活强相关:女 {df[df.Sex=='female'].Survived.mean():.1%} vs 男 {df[df.Sex=='male'].Survived.mean():.1%}</li>
</ul>
<h2>图表</h2><img src="图表.png" width="100%">
<h2>数据预览</h2>{df.head(10).to_html()}
</body></html>"""
open("报告.html", "w", encoding="utf-8").write(html)
print("→ 已生成 报告.html(含 4 张图)")

5常见坑

表 1 · 五个必踩的坑
现象原因与解法
图里中文全是方块 □□□matplotlib 默认字体不含中文。加上 plt.rcParams["font.sans-serif"]=["Microsoft YaHei"](Mac 用 PingFang SC)。
读 CSV 报 UnicodeDecodeError文件不是 UTF-8(国内导出的常是 GBK)。用 pd.read_csv(f, encoding="gbk") 试。
SettingWithCopyWarning在切片上直接改值。先 .copy() 再改,或用 df.loc[条件, 列] = 值。
数值列被读成文本(不能算均值)列里混了 "N/A"、"—" 之类。用 pd.to_numeric(df[c], errors="coerce") 转,转不动的自动变 NaN。
只看了 describe 就下结论均值会骗人(第 4 步的右偏)。一定要配图看分布,以及先 head() 看真实几行。
