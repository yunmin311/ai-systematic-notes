3分步搭建

第 1 步 · 数据管道

训练.pypython
import torch
import torch.nn as nn
from torch.utils.data import DataLoader
from torchvision import datasets, transforms

dev = "cuda" if torch.cuda.is_available() else "cpu"

tf = transforms.Compose([
    transforms.ToTensor(),                       # 图片 → 张量,像素缩到 0~1
    transforms.Normalize((0.1307,), (0.3081,)),  # 标准化(D06 的特征缩放,用 MNIST 的统计量)
])

train_set = datasets.MNIST("./data", train=True,  download=True, transform=tf)
test_set  = datasets.MNIST("./data", train=False, download=True, transform=tf)
train_loader = DataLoader(train_set, batch_size=128, shuffle=True)   # D07:切批 + 打乱
test_loader  = DataLoader(test_set,  batch_size=512)

print(f"设备: {dev} | 训练集 {len(train_set)} 张 | 测试集 {len(test_set)} 张")
x, y = next(iter(train_loader))
print("一批的形状:", x.shape)      # torch.Size([128, 1, 28, 28]) = 批×通道×高×宽
检查点

打印出 [128, 1, 28, 28]。形状意识很重要(第 3 章):1 是通道数(灰度图只有 1 个通道,彩色是 3),28×28 是像素——这正是 D08 那个 SmallCNN 的输入。

第 2 步 · 模型:D08 的小 CNN

训练.py(续)python
class SmallCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.features = nn.Sequential(                    # 前半段:看图、提特征
            nn.Conv2d(1, 16, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),   # 28×28 → 14×14
            nn.Conv2d(16, 32, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),  # 14×14 → 7×7
        )
        self.classifier = nn.Sequential(                  # 后半段:根据特征分类
            nn.Flatten(),
            nn.Linear(32 * 7 * 7, 128), nn.ReLU(),
            nn.Dropout(0.25),                             # D10:正则化,防过拟合
            nn.Linear(128, 10),                           # 10 个数字类别
        )

    def forward(self, x):
        return self.classifier(self.features(x))

model = SmallCNN().to(dev)
print(sum(p.numel() for p in model.parameters()), "个参数")   # 约 22 万
检查点

约 22 万参数——比 D15 那个迷你 GPT 小三个数量级,却足以把手写数字认到 99%。任务难度决定模型大小,不是越大越好。

第 3 步 · 五步训练循环

训练.py(续)python
import time

loss_fn   = nn.CrossEntropyLoss()                                  # 分类用交叉熵(D02)
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)          # D10:默认先用 Adam
hist = {"loss": [], "acc": []}

def evaluate():
    model.eval()                                   # 评估模式:Dropout 关掉(D10 的必修)
    right = 0
    with torch.no_grad():                          # 评估不需要梯度,省显存和时间
        for xb, yb in test_loader:
            pred = model(xb.to(dev)).argmax(1)     # 取概率最大的那个类别
            right += (pred.cpu() == yb).sum().item()
    return right / len(test_set)

for epoch in range(1, 6):
    model.train()                                  # 训练模式:Dropout 生效
    t0, total = time.time(), 0.0
    for xb, yb in train_loader:
        xb, yb = xb.to(dev), yb.to(dev)
        pred = model(xb)                           # ① 前向
        loss = loss_fn(pred, yb)                   # ② 算损失
        optimizer.zero_grad()                      # ③ 梯度清零(D07:别忘)
        loss.backward()                            # ④ 反向
        optimizer.step()                           # ⑤ 更新
        total += loss.item() * len(xb)
    acc = evaluate()
    hist["loss"].append(total / len(train_set)); hist["acc"].append(acc)
    print(f"epoch {epoch}  训练损失 {total/len(train_set):.3f}  测试准确率 {acc:.1%}  ({time.time()-t0:.0f}s)")

torch.save(model.state_dict(), "模型.pt")
检查点

第一轮就能到 97%+,五轮后约 99%。那五行带 ①–⑤ 注释的,就是 D07 的五步循环,一字未改——换成任何模型、任何数据,这五步都一样。这就是"底盘"的意思。

第 4 步 · 看曲线、看错例

训练.py(续)python
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from collections import Counter
plt.rcParams["font.sans-serif"] = ["Microsoft YaHei"]
plt.rcParams["axes.unicode_minus"] = False

# 训练曲线
fig, ax = plt.subplots(1, 2, figsize=(11, 4))
ax[0].plot(hist["loss"], marker="o"); ax[0].set_title("训练损失"); ax[0].set_xlabel("epoch")
ax[1].plot([a*100 for a in hist["acc"]], marker="o"); ax[1].set_title("测试准确率(%)")
plt.tight_layout(); plt.savefig("训练曲线.png", dpi=120)

# 找出所有错例,统计最容易混的组合
model.eval(); wrong = []
with torch.no_grad():
    for xb, yb in test_loader:
        p = model(xb.to(dev)).argmax(1).cpu()
        for i in (p != yb).nonzero(as_tuple=True)[0]:
            wrong.append((xb[i][0], yb[i].item(), p[i].item()))

pairs = Counter((t, g) for _, t, g in wrong).most_common(3)
print("--- 最容易认错的 ---")
for (t, g), n in pairs:
    print(f"真 {t} → 猜 {g} ({n} 次)", end=" | ")

# 画 10 个错例
fig, axes = plt.subplots(2, 5, figsize=(10, 4.5))
for axx, (img, t, g) in zip(axes.ravel(), wrong[:10]):
    axx.imshow(img, cmap="gray"); axx.set_title(f"真{t} 猜{g}", fontsize=10); axx.axis("off")
plt.tight_layout(); plt.savefig("错例.png", dpi=120)
print("\n→ 已保存 模型.pt / 训练曲线.png / 错例.png")
交付

打开 错例.png——这是整个项目最值得看的一张图。我会发现很多错例连人也难辨认(写得潦草的 9 和 4)。这给了一个重要判断力:剩下那 1% 的错误里,有相当一部分是数据本身的模糊,不是模型不够努力。

4跑起来之后:该看什么

  1. 训练损失和测试准确率的关系:损失一直降、准确率却不再涨,就是开始过拟合了(D10 的曲线诊断)。这个项目里 Dropout 已经压住了大部分。
  2. 和基线比:随机猜是 10%;一个不带卷积的全连接网络约 97~98%;CNN 到 99%。那 1~2 个百分点,正是"卷积保住了空间结构"带来的(D08)。
  3. 试试自己写的数字:用画图软件写一个数字、存成 28×28 灰度图,喂进模型看它认不认得。常常认不准——因为我的笔迹和 MNIST 的分布不同,这就是真实世界里"分布偏移"的第一课。

5常见坑

表 1 · 六个常见坑
现象原因与解法
损失不降 / 一直是 2.3 左右2.3 ≈ ln(10),说明模型在瞎猜。检查:忘了 optimizer.zero_grad()?学习率太大?忘了 loss.backward()?
测试准确率比训练时低很多忘了 model.eval()——Dropout 还开着(D10 的经典坑)。
形状报错 mat1 and mat2 shapes...Flatten 后的维度和 Linear 对不上。两次池化后是 32×7×7;改了结构就要跟着改这个数。
CPU 上慢得难受把 batch_size 调大(256/512)、epoch 减到 3;或去 Colab 用免费 GPU。
下载数据集失败网络问题。多试几次,或手动下载 MNIST 放进 ./data 目录。
自己写的数字认不准不是 bug:MNIST 的字是居中、白底黑字、特定粗细。要认自己的字,得做同样的预处理(居中、反色、缩放)。

6进阶

  • 做消融实验:把两个 MaxPool2d 去掉、或把 Dropout 去掉,各跑一次,记下准确率和耗时——亲手验证 D08/D10 里那些结论。
  • 加数据增强:在 transforms 里加 RandomRotation(10),看泛化是否变好(D10 的正则化四件套之一)。
  • 换个更难的数据集:datasets.FashionMNIST(衣服鞋包,同样 28×28),准确率会掉到 92% 左右——难度立刻显现。
  • 试试迁移学习:用 D11 的方法,拿预训练 ResNet 微调一个真实彩色图像分类任务(如猫狗)。
